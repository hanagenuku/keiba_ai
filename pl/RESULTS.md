## 結論

**1,044配置を測って、現行既定より良い配置が見つかった。第2段（市場フリーXGB）へ進む。**

| 配置 | 3着内AUC 探索 | 3着内AUC 検証 | 1着AUC 探索 | 1着AUC 検証 |
|---|---|---|---|---|
| 現行既定 LR0.30 / DAMP0.05 / SHR0.02 / DECAY400 | 0.6976 | 0.7098 | 0.6935 | 0.7014 |
| **調整後 LR0.80 / DAMP0.30 / SHR0.15 / DECAY550** | **0.7037** | **0.7172** | **0.7094** | **0.7165** |
| 差 | **+0.0061** | **+0.0074** | **+0.0159** | **+0.0151** |

**1着を当てる力のほうが伸びが大きい**（+0.015）。θ は元々「複勝を当てる」ために
最適化された覚えはないので、これは素直な改善と読める。

取り込み基準は3つとも満たした。

| 基準 | 結果 |

| 探索期順位と検証期順位の相関が正 | ✅ **r = +0.994**（1,044配置） |

## 🔴 途中で私が計測器を壊した（1件・修正済み）

`pl/build_theta.py` の SQL を `ORDER BY date, race_id, place` と書いた。
本番 `build_from_history` からコピーしたためだが、**そちらは更新にしか使わないのに対し、
私の実装は同じ行順で特徴量（θ順位）も作っていた**。θ が同値の馬（13.8%）で
安定ソートが入力順を保つので、**順位がそのまま着順順に並んだ**。

これは **2026-08-08 に「AUC +0.037 / 回収率115%」と誤報告した事故と完全に同型**。
当時 CLAUDE.md に「同じ特徴量を別実装で作って値を突合せよ」と書いたが、
今回は**その突合を、同じ行順を渡した参照実装との間で行ったので通過してしまった**。

発覚したのは **単勝回収率が 162.8% と出た**ため（North Star #8: 異常に良い数字を疑う）。

| | corr(θ同値行の順位, 着順) |
|---|---|
| 壊れていた版 | — （2026-08-08 の同型事故では +0.8678） |
| **修正後（今回）** | **+0.1717** |
| 本番パイプライン（2026-08-08 実測） | +0.1694 |

修正後は本番の健全値と一致する。**関門5「θ同値行で順位が着順を漏らしていないこと」を
今後の標準にする。**

### 汚染の範囲（正直に）

- **主指標（z のAUC）は無事**。AUC は連続値 z で測っており、同値はタイとして
  中間順位で処理されるため、順位の並べ方が入らない。修正前後で数字が完全に一致した
- **θ 自体も無事**。更新は `sorted([(place, name)…])` で行うので行順に依存しない
- 🔴 **汚染されたのは「順位AUC」と「回収率」の2つだけ**。両方測り直した

## パラメータの主効果（探索期AUCの平均）

| | 値ごとの平均 |
|---|---|
| LR | 0.10:0.6896 → 0.30:0.6952 → **0.80:0.7017** → 1.6:0.6987 → 2.4:0.6916 |
| EXP_DAMP | 0.00:0.6915 → 0.05:0.6943 → **0.30:0.7027** → 0.80:0.7007 → 1.2:0.6991 |
| PRIOR_SHRINK | 0.00:0.6928 → 0.02:0.6940 → **0.15:0.7018** → 0.30:0.6998 |
| DECAY_DAYS | 150:0.6943 → **400:0.6992** → 750:0.7009 → 無減衰:0.6887 |

**4軸とも内部に最適点を持つところまでグリッドを3回広げた**（端で止めていない）。
上位12配置はAUCの差が 0.0006 以内の平坦な高原で、尖ったピークではない＝頑健。

### 事前の見立ては3つとも外れた（隠さず記録する）

| 予想 | 実際 |
|---|---|
| DECAY は 700〜無減衰 が良い | ❌ **無減衰が最悪**（0.6887）。400〜550 が最良 |
| EXP_DAMP=0 でも変わらない | ❌ 0.05 → **0.30 で +0.011**。効いていた |
| 一番効くのは LR | △ LRの幅 0.0121 / DECAYの幅 0.0122 で同程度 |

**現行既定は4軸すべてで最適から外れていた。**「一度も振っていない」と自分で
コメントに書いたまま1年放置していた部品が、実際に外れていた。
