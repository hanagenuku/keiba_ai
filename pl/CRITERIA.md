# P-1: PLレーティング θ のハイパーパラメータ調整（事前登録）

作成日: 2026-09-08。**結果を見る前に確定。**

## 位置づけ — 今回から基準を2種類に分ける

これまで全ての測定に「採用基準」（本番に入れて金を賭けてよいか）を当てていたため、
1回の測定で +0.002 しか出ないと線ごと打ち切りになり、20セッション積み上げても
否定の表しか残らなかった。**改善は積み上げでしか起きない**ので、基準を分ける。

| | 目的 | 今回当てるか |
|---|---|---|
| **取り込み基準** | 開発モデル（市場を見ないモデル）に部品を入れるか | ✅ **これを当てる** |
| **採用基準** | 本番モデルを差し替えて実際に賭けるか | ❌ 積み上げ終わってから一度だけ |

**線を閉じるのは (a) 機序として不可能と確定したとき (b) 独立に2回失敗したとき のみ。**
1回の未達は「優先度を下げる」に留める。

## なぜ θ から始めるか

- 2026-08-08 のオラクル診断: 126特徴量 AUC 0.7706 に対し、
  **「その馬の真の複勝率」を1個知るだけで 0.8740**。θ はその量に最も近い代理
- θ の上乗せは アンカー入り +0.0020 に対し **市場フリー +0.0046（2.3倍）**
- `src/features/pl_rating.py:117` に「ハイパーパラメータは**一度も振っていない**」と
  自分で書いたまま1年放置されている。一番効いている部品が未調整

## 測るもの

`data/history.db`（164,328頭 / 11,973レース / 2023-01-07〜2026-09-06）。

θ は **各レースの開始前の値**で記録する（本番 `field_features` と同じく更新前）。
高速再実装 `pl/build_theta.py` を使うが、**本番 `PLRatings` と全164,328行を突合し、
θ最大差 5e-06（round(...,5) の丸めのみ）・順位差 0 を確認済み**（North Star #8）。

### 期間

| | 期間 | 用途 |
|---|---|---|
| 助走 | 2023-01-07 〜 2024-06-30 | θ を育てるだけ。評価に使わない |
| **探索期** | 2024-07-01 〜 2025-06-30 | **ここだけ見てグリッドから選ぶ** |
| **検証期** | 2025-07-01 〜 2026-09-06 | 選んだ後に一度だけ見る |

### 指標

- **主**: `rl_f_pl_rating_z`（レース内でのθのz値）単独で **3着内** を当てる AUC
- 副: 同 1着 AUC / θ絶対値の AUC / 複勝回収率（North Star #9 のため必ず併記）

θ単独のAUCは「θの質」の代理であって、モデルへの上乗せそのものではない。
だから**これは第1段（グリッドを絞る）専用**とし、絞った後に第2段で
本番同型の市場フリーXGBに載せて測る。

## グリッド

| パラメータ | 候補 | 現行 |
|---|---|---|
| LR | 0.10 / 0.20 / 0.30 / 0.50 / 0.80 | 0.30 |
| EXP_DAMP | 0.00 / 0.02 / 0.05 / 0.10 / 0.20 | 0.05 |
| PRIOR_SHRINK | 0.00 / 0.01 / 0.02 / 0.05 | 0.02 |
| DECAY_DAYS | 150 / 250 / 400 / 700 / 無減衰 | 400 |

500通り。**現行既定を必ず含める**（比較の基準線）。

## 関門（結果を見る前に置く。壊れ方を作って実際に止まるか確かめる）

1. **対照群**: θ をレース内でシャッフルした系列で AUC ≈ 0.500 になること。
   ならなければ計測器が壊れている
2. **助走の除外**: 探索期・検証期のAUCが、助走期間を含めた場合と別に出ること
3. **多重比較**: 500通りを探索期で見て選ぶので、選抜は探索期のみ。
   検証期は**選んだ後に一度だけ**見る。検証期を見てから選び直さない
4. **順位の持ち越し**: 探索期AUCの順位と検証期AUCの順位の相関を出す。
   相関が 0 付近なら「グリッドが何も選べていない」＝ P-1 は情報を持たない

## 取り込み基準（第1段 → 第2段へ進めるか）

- 探索期で現行既定を上回る配置が存在する
- **かつ** その配置が検証期でも現行既定を上回る（符号一致）
- **かつ** 関門4の順位相関が正

3つ満たせば、上位3配置＋現行既定を第2段（市場フリーXGB・3窓×3シード）へ送る。

## 第2段の取り込み基準（開発モデルに入れるか）

- 3窓中2窓でプラス **かつ** 平均が負でない

⚠ **この基準は意図的に緩い。** +0.002 でも入れる。5つ積んで +0.01（回収率2pt）を
狙う設計。厳しい採用基準は、積み終えて本番に差し替える瞬間にだけ当てる。

## 事前の見立て（外れても隠さず記録する）

- DECAY_DAYS=400 は短すぎると見ている。3.5年で exp(-1278/400)=0.041 まで縮み、
  古い実績がほぼ消える。**700〜無減衰のほうが良い**と予想する
- EXP_DAMP=0.05 は 20走で step が半分になる。競走馬の平均キャリアは短いので
  効いていない可能性が高い。**0 でも変わらない**と予想する
- 一番効くのは **LR** だと予想する
