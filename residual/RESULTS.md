## 1. 🔴 前回の測定を訂正する（GPTの指摘は正しかった）

前回 mispricing §2 で「AI強気は実質人気薄（オッズ中央値52.2 vs 一致10.0）」と報告したが、
これは **市場の勝率→3着内率の換算を `q3 = q × 3.0` と線形にしていたため**だった。

Harville公式で正しく変換すると（ΣP(3着内)=3.0000 を検算済み）、絵が変わる：

```
残差帯          人気の中央値
弱気 -20pt以下      2.0      ← 人気馬
-10〜-5            9.0
一致 -2〜+2         9.0
+5〜+10            3.0      ← 人気馬
+10〜+15           3.0      ← 人気馬
強気 +20pt以上      8.0
```

**「AIが強気な馬＝人気薄」は成り立たない。** 中程度に強気な帯（+5〜+15）は**人気馬**。
前回の報告は換算の産物だった。GPTの「AI能力と変換方法が混ざっている」という指摘は正しく、
原因は softmax T=3.5 ではなく**この線形換算**のほうだった。

## 3. 🔴 副産物：本番の `cal_prob` が校正できていない（新規の欠陥）

関門3で発覚。**AIが「45%」と言った馬は、実際には29%しか3着内に来ていない。**

```
予測帯        N     予測平均   実測    ズレ
0.00-0.10   3271   0.034   0.090   +0.056   ← 過小
0.10-0.20    903   0.148   0.216   +0.068   ← 過小
0.20-0.30    633   0.250   0.264   +0.014
0.30-0.40    667   0.359   0.264   -0.095   ← 過大
0.40-0.50   1773   0.456   0.289   -0.166   ← 過大（最大の帯）
0.50-0.65    764   0.528   0.467   -0.061
0.65-1.01    364   0.736   0.618   -0.118
```

比較として、市場（Harville）の校正はこう：

```
0.00-0.10   0.056 → 0.058  (+0.003)
0.30-0.40   0.347 → 0.350  (+0.003)
0.65-1.01   0.779 → 0.683  (-0.096)   ← Harvilleの既知の性質（人気馬を過大）
```

**市場は 0.10〜0.50 の帯でほぼ完璧に校正されているのに、AIは最大 −0.166 ズレている。**

⚠ CLAUDE.md 2026-08-21 に「`cal_prob` の水準が下がった（平均予測 0.191 に対し実測 0.230）」
という記録があるが、実際は**水準のズレではなく傾きのズレ**（低い側は過小・高い側は過大）。
Isotonic校正器は学習期間で作られたもので、**本番の分布に合っていない**。

🔑 **これはアプリに表示している数字が間違っているという意味**で、
今回の検証とは別に対処すべき欠陥。ただし North Star #9 のとおり
**直しても回収率が上がる保証はない**（順序は単調変換で変わらないので、
買い目の選択には影響しない。影響するのは表示と穴マーク閾値 `cal_prob>=0.15`）。
