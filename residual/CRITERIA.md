## 🔴 まず、前回（mispricing §2）の測定に欠陥があったことを認める

前回 `gap = log(p_AI / q3)` を作る際、市場の勝率 q から3着内率 q3 を

```python
q3 = min(0.999, q * 3.0)      # ← 線形換算。誤り
```

で作っていた。これは**系統的に歪む**：

| 馬 | 市場勝率 q | `q*3` | 真の3着内率（Harville） | ズレ |
|---|---|---|---|---|
| 1番人気 | 0.35 | 1.05→0.999 | 約0.75 | **過大** |
| 人気薄 | 0.02 | 0.06 | 約0.09 | **過小** |

その結果 `gap = log(p_AI/q3)` は **人気馬で機械的に負・人気薄で機械的に正**になる。

🔑 **前回「AI強気＝実質人気薄（オッズ中央値52.2 vs 一致10.0）」と報告したが、
その現象は私の換算が作っていた可能性がある。** GPTの指摘（AI能力と変換方法が混ざっている）は正しい。
ただし原因は softmax T=3.5 ではなく、この線形換算のほう。

## 今回の設計

### ① 市場確率を実オッズから正しく作る

```
q_win  = (1/オッズ) / Σ(1/オッズ)          市場の勝率（控除率を除去）
q_top3 = Harville(q_win)                  ← 線形換算をやめる
```

Harville は本プロジェクトが `calc_harville_probs` で既に使っている式。
P(i が3着内) = Σ over 1着/2着/3着 の順列。

### ② AI確率は既に校正済みのものを使う（そして校正を検証する）

`race_predictions.cal_prob` は XGB出力 → **Isotonic回帰で校正済み**の個馬独立3着内確率。
校正器は学習期間だけで作られており、これらは本番の予想なので**完全OOS**。

⚠ GPTの懸念「softmax T=3.5 で平坦化」は `win_prob`（勝率）の話で、
`cal_prob`（3着内確率）は平坦化を経由していない。**今回は cal_prob だけを使う。**

**校正の検証を関門に置く**：cal_prob の帯ごとに実測3着内率を出し、対角線に乗るか。

### ③ 残差を作る

```
resid = logit(p_AI) − logit(q_top3)
```

正なら「AIは市場より上方修正すべきと言っている」。

### ④ 事前に固定した閾値でROIを測る（本命）

**閾値は結果を見る前に固定する。後から選ばない。**

## 合格基準（結果を見る前に固定）

1. **単調性**：残差が大きい帯ほど回収率が高い、という順序が成り立つ
2. **どれかの帯で検証期のROIが100%超**、かつ **日ブロックbootstrapのCI下限>100%**
3. **3本抜きでも100%超**
4. **探索期と検証期で符号が一致**
5. **N>=200**

**1（単調性）が成り立たなければ、そこで打ち切る。** 単調でないなら、
どこかの帯が100%を超えても多重比較の産物。

## 計測器の関門（結果を見る前に置く）

1. **Harville の検算**：Σ P(i が3着内) がレース内で **3.00 ± 0.01** になるか
2. **市場の校正**：q_top3 の帯ごとの実測3着内率が対角線に乗るか（市場は正しいはず）
3. **AIの校正**：cal_prob の帯ごとの実測3着内率が対角線に乗るか
4. `Σ(1/オッズ)` 1.20〜1.35 のレースだけ使う
