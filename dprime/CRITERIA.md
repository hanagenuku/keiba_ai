## 🎯 主目的は「裁定」ではなく「もう一つの市場予測」（2026-09-09 ユーザー指示で確定）

> 複勝市場とワイド市場の参加者が完全に同じ情報・同じ判断をしているとは限らないので、
> 「ワイドから推定した馬Aの3着内確率」と「複勝市場が示している馬Aの3着内確率」の間に、
> 安定した情報差があるのかを見たい。

つまり両プールを同時に買う裁定ではなく、**ワイド盤を第二の市場予測として使い、
複勝の値付けに足りない分を測る**。この向きが重要な理由:

- AIが市場に足せるのは実測 **+0.0009**（新馬のオラクルでも +0.0035）
- しかし**別の市場**が足せる量は一度も測っていない
- 市場と情報源が重ならない入力はパドックしか無いと整理してきたが、
  「別プールの群衆」も重ならない可能性がある

⚠ 裁定として使う場合はパリミュチュエルなので自分の投票が価格を動かす。
   第二の予測として使う場合はその制約が無い（複勝を1点買うだけ）。

## この検証の強み（他の否定済み施策と質が違う点）

1レースで3着内に入るのは必ず3頭。したがって次が**厳密に**成立する:

    Σ_{B≠A} P(A,B がともに3着内) = 2 × P(A が3着内)

- **予測モデルが要らない**（AUCも学習も出てこない）
- **控除率の推定が要らない**（正規化定数がどちらも厳密に3と分かっている）

2026-08-17 の展開検証で計測器を9回壊した原因は「確率の推定」だった。
ここにはその弱点が構造的に存在しない。

## 🔴 適用範囲のガード（最初に効かせる）

**8頭立て以上のレースに限定する。**

| 出走頭数 | 複勝の払戻対象 | ワイドの払戻対象 |
|---|---|---|
| 4頭以下 | 発売なし | — |
| 5〜7頭 | **2着以内** | 3着以内 |
| 8頭以上 | 3着以内 | 3着以内 |

7頭以下では複勝が「2着内」なので恒等式の右辺が別物になる。
ここを混ぜると、実在しないズレを測って「不整合を発見した」と誤報告する。

## Step 1 — ワイドオッズが正常取得できるか（盤の健全性）

モデルを使わずに盤だけで検算できる。n頭立てなら:

    Σ_{pairs} P(2頭とも3着内) = C(3,2) = 3   （厳密）

控除率 t_wide = 0.225 なら **Σ_{pairs} 1/o_AB ≈ 3 / (1 - 0.225) = 3.871**。
同様に複勝（8頭以上）は **Σ_A 1/o_A ≈ 3 / (1 - 0.20) = 3.750**。
単勝盤の Σ(1/o) ≈ 1.25 と同型の検査（2026-08-15 C-2 で実際に壊れた盤を検出した手法）。

チェック項目:
- [ ] 組番が C(n,2) 通り揃っているか（取消馬を除く）
- [ ] 各オッズが 1.0 倍以上か
- [ ] **ワイドは範囲表記（min〜max）で出る**ので min/max を別々に保持したか
- [ ] Σ(1/o) が理論値の ±15% に入るか（min / max / 中点の3通りとも出す）

判定:
- ❌ 盤が壊れている（Σ が理論値から大きく外れる・組が欠ける）→ **打ち切り**
  半端に残すと 2026-08-15 の「全16頭が2.1倍」と同じ事故になる

## Step 2 — 複勝との整合性（恒等式そのもの）

控除率を推定せず、**両方とも合計3に正規化**して比べる:

    P_w(A,B) = (1/o_AB) / Σ_{pairs}(1/o) × 3
    P_p(A)   = (1/o_A)  / Σ_A(1/o)      × 3
    q_A      = Σ_{B≠A} P_w(A,B) / 2        ← ワイド盤から導いた3着内確率

Σ_A q_A = 3 は代数的に自動で成立する（検算に使う。ズレたら実装が壊れている）。

    乖離 d_A = q_A − P_p(A)

レースごとに **Σ_A |d_A| / 2**（全変動）と **max_A |d_A|** を出す。

⚠ **複勝オッズが範囲表記であることが最大の交絡。**
   min / max / 中点の3通りすべてで d を計算し、3通りとも同じ符号・同じ桁でなければ
   「範囲表記の扱いの産物」であって市場の不整合ではない。

## Step 3 — ワイド由来の確率が複勝市場に「追加情報」を持つか

⚠ ここが本題。Step 2 までは価格の話で、情報の話ではない。

実際の3着内（0/1）を目的変数にして、**入れ子のモデルを2本**比べる:

    N1: P_p(A) だけ                      ← 複勝市場が言っていること
    N2: P_p(A) + q_A（または d_A）        ← ワイド市場を足す

見る量: **AUC / LogLoss / Brier**、および `d_A` の5分位ごとの実測3着内率。

### 先に置く対照群（結果を見る前に固定）

| 対照 | 何を潰すか | 通過条件 |
|---|---|---|
| **同一レースの時間差2スナップショット** | 取得タイミングによる変動 | 時間差由来の \|d\| が本命の \|d\| より小さい |
| **複勝オッズの min / max / 中点** | 範囲表記の扱い | 3通りとも同符号・同じ桁 |
| **頭数帯（8-11 / 12-15 / 16-18）** | 組数が増えると誤差が縮むか | 縮む向きが自然（縮まなければ実装を疑う） |
| **プラセボ**: `q_A` をレース内でシャッフル | 「レース内の分布」だけの効果 | N2 の上乗せが消える |

⚠ プラセボはリーク検出には使えない（North Star #8）。ここでは
   「レース単位の構造だけで説明がつくか」を潰すためだけに使う。

判定:
- ❌ N2 − N1 が Brier/LogLoss/AUC のいずれでも改善しない、または
  対照群のどれかで消える → **打ち切り**。記録は
  「**ワイドと複勝は整合している（市場は一貫している）**」
  これは失敗ではなく **市場が一貫しているという知見**
- ✅ 上乗せが対照群を明確に超える → Step 4 へ

## Step 5 — 実際の馬券収益につながるか（North Star #9）

⚠ 最後の関門。**Step 4 までは予測の話で、取り分の話ではない。**

`d_A > 0`（ワイド側が複勝より高く3着内を見ている馬）を**複勝で1点買う**。
両方向（`d_A < 0` 側）も必ず対照として出す。

事前登録した5基準（**すべて満たさなければ不採用**）:

1. N ≥ 300頭
2. 複勝回収率 > 100%
3. 前半・後半とも > 100%
4. 上位3本の配当を抜いても > 100%
5. 日ブロック bootstrap の 95%CI 下限 > 100%

⚠ 構造的な制約（基準を満たしても残る）:
- 2026-08-03「最終オッズを完全に知っていても最良の帯で回収94.5%」がここにも効く
- ワイド盤も複勝盤も締切直前まで動くので、いつの盤で `d_A` を作るかで結果が変わる。
  **本番でユーザーが押す時点（締切直前）の盤で測ること**（North Star #10）
