## ❌ Step 1 — 順位の精度（取り込み基準を割った）

```

P0 補正なし           0.7685     0.7787   ← 最良

対照 シャッフル         0.7648     0.7755
```

✅ **向き自体は雑音ではない。** P1 > シャッフル > 符号反転 の並びは、

## 判定と対応

**pace_bonus を既定OFFにした**（`PACE_BONUS=1` で復帰）。
2026-09-01 の error_tags・2026-07-28 の rank_matrix_filter と同じ扱い。

| | |
|---|---|
| 実装 | `engine.py` の RELATIVE_WEIGHT ブロック |
| テスト | `tests/test_pace_bonus_off.py` 4件。**相対混合が順位を変えないこと**も固定した（この前提が崩れると今回の判断の土台が消えるため） |
| 画面への影響 | RL順位が19.1%の馬で変わる。軸は1.0%のレースでのみ変わる。「推」印の出方が変わる |

🔑 **RL列がモデルの順位そのものになる。** これまでは手書きの未検証な項が
19%の馬を静かに並べ替え、「推」印まで作っていた。
2026-08-18②（画面の「AI xx%」が逆向きの手書き式だった）・
2026-08-07⑥（ROI予測150%のべた書き）と同じ「画面に出ている数字が測られていない」型。

⚠ **7番ジャスティンシカゴのような印は、これで出なくなる。**
あの印は pace_bonus が作ったもので、モデル自身は11位と言っていた。
