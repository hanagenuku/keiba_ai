| # | 壊した内容 | 気づいた経路 |
|---|---|---|
| 1 | 対照を「**複勝の当否**をレース内でシャッフル」にした | 偶然の通過数が**中央値94軸**（本物の40より多い）と出た。offset は元の y を予測するので、y だけ入れ替えると offset が大きく外れ、raw と相関する特徴量が「offset のズレを直す係数」として一斉に有意になる。正しい対照は**特徴量の側**をシャッフルすること（(y, raw) の対応は保つ）→ 中央値0 |
| 2 | 予測確率の**10分位で層別**して統制したつもりだった | 層の中でも予測確率は動くので、予測確率と相関する特徴量が全部残る。連続統制（raw を3次まで自由化）に変えると 50軸 → 26軸 |
| 3 | **選択汚染**: 上位軸を「確認期の p<0.05 も条件に入れた集合」から選び、確認期で AUC を評価していた | 事前登録した「探索期だけで選ぶ」を自分で破っていた。探索期だけで選び直しても +0.0128 は残ったが、**破ったこと自体が問題** |

あのままなら「**偶然より少ない軸しか残らない＝差は無い**」と**逆の結論**を報告していた。

# H-M2: 「AIが推す人気薄」が当たるレース条件はあるか（2026-09-13・意図を取り違えていたので測り直し）

前回は「5番人気以下の**全馬**」を見ていた。ユーザーの意図は
**「買う単位＝AIが推している人気薄1点」で、当たるレースの条件を探す**だった。

## 買う単位（1レース1点）
- **U1**: そのレースの5番人気以下のうち AI順位が最上位の馬
- **U2**: U1 かつ **AI順位 < 市場人気**（＝写真の7番のような形）

```
U2  探索期 896点  複勝20.5% 回収66.4%   |  確認期 1,029点  複勝21.5% 回収78.8%
```

## ❌ 1軸（27セル）— 差別化できない

```
                    探索期        確認期
クラス 未勝利         71.1%   →   72.6%
クラス 新馬          20.3%   →   64.4%
距離 〜1400m        62.5%   →   88.6%
距離 2201m〜        67.6%   →  119.6%   ← N=68/52
芝ダ ダート          60.3%   →   84.9%
馬場 重             97.3%   →   73.4%
競馬場 阪神          87.1%   →   88.0%
AIの自信 低          76.4%   →   97.8%
AIの自信 高          66.2%   →   53.8%
```
- **探索期で100%を超えたセル: 0個**
- 探索期ROIと確認期ROIの**順位相関 Spearman ρ = −0.020（P=0.923）**
- U1 でも ρ = −0.247（P=0.214）

## ❌ 2軸の組み合わせ（142セル）— さらに悪い

```
順位相関 Spearman ρ = −0.013（P=0.876）
探索期で100%超 2個 → そのうち確認期も100%超 0個

探索期トップ5の行き先
  芝 × 阪神              N= 64  118.4%  →  N= 38   37.6%
  16頭〜 × 阪神           N= 50  101.6%  →  N= 40   88.0%
  1401-1800m × 阪神     N= 67   99.7%  →  N= 30   89.0%
  16頭〜 × 自信低          N= 39   97.4%  →  N= 58  159.1%
  未勝利 × 芝             N=116   97.2%  →  N=198   55.2%
```

**帰無（同じセル定義のまま配当だけ入れ替え・2,000回）**:
探索期2軸184セル（N≥30）で 100%超は **実測3個 / 期待8.3個（5〜95%点 3〜14）**。
→ **偶然の範囲。むしろ期待を下回る。**

🔑 前の帰無は142セルを**独立に**引いていて期待14.1個と出たが、実際のセルは
同じデータの**重なった部分集合**なので過大評価。セル定義を保ったまま配当だけを
入れ替える形に直した（計測器の作り直し4件目）。

## 唯一の候補: 「AIの自信が低いレース（混戦）」— それでも基準未達

両期間・両単位で最良だった唯一のセル。

```
              探索期    確認期   3本抜き   日ブロックCI(確認期・38開催日)
U1 AI最上位    74.8%   95.3%   83.8%   [74, 121]
U2 写真7番型    76.4%   97.8%   84.0%   [72, 129]
```
事前登録した基準（確認期>100% / 3本抜き>100% / CI下限>100%）を**すべて未達**。
27セル中の1個でもある。

⚠ ただし向きは一貫していて、**AIの自信が高いレースほど悪い**（U2: 高66.2%→53.8%）。
これは本文前半の「AIの自信 Q4 が最低」・2026-09-08 Phase4「AI集中度が高いほど
市場との差が開く」と同じ向き。**混戦のほうが人気薄の取り分が残る**、という形。
🔴 それでも100%には届かない。

## 判定

**レースの条件では差別化できない。** 決め手は個別セルの数字ではなく
**探索期→確認期の順位相関が ρ≈0** であること。つまり
**「どの条件が当たるか」を事前に選ぶ手段が無い**。

同じ形の否定はこれで5回目:
2026-08-05（コース×距離）/ 08-15②（人気×RLマトリクス25マス）/
08-24 F-3（246セル）/ 08-24 F-4（Δの条件別41セル・r=−0.001）/ 今回（ρ=−0.020）。

🔑 ユーザーの発想（「差別化できればその条件だけ買えばいい」）は論理として正しい。
**成り立たないのは前提のほうで、条件別ROIの順位が期間をまたいで保存されない。**

# H-M3: 「混戦度」で切って連系まで通す（2026-09-13）

当たり429件の顔つきで最もはっきりしたのが**混戦**なので、それを軸に回収率まで測った。

```
当たった429レースの構造（中央値）
  AI最上位の勝率      14.2%      AI上位3頭の合計   33.9%
  AI確率のエントロピー   2.60       出走頭数         14
  逃げ脚質            1頭        先行脚質          2頭（25-75%点とも幅ゼロ）
よく出る組み合わせ
  未勝利×1401-1800m×ダート 10.5% / 未勝利×〜1400m×ダート 9.1% / 1勝×1401-1800m×ダート 7.9%
```

混戦度 = **AI上位3頭の確率合計**（低いほど混戦）。境界は**探索期だけ**で決めた
（top3_p 0.317 / 0.357）。

## 複勝（全OOS・探索/確認を分けて）

```
混戦度                探索 N   複勝率   回収   3本抜き  |  確認 N   複勝率   回収   3本抜き
混戦（上位3頭が薄い）      299  19.4%  68.3%  60.1%  |   275  19.3%  86.4%  70.2%
中                  298  18.8%  67.6%  57.1%  |   331  24.2%  76.4%  69.6%
堅い（上位3頭が厚い）      295  23.4%  63.2%  58.3%  |   397  20.9%  75.7%  65.2%
```

✅ **基準1（順序が両期間で保たれる）は通った**。混戦 > 中 > 堅い が両期間で同じ。
❌ 基準2（確認期>100%）86.4% / 基準3（3本抜き）70.2% / 基準4（日ブロックCI下限）**53**
（CI [53, 100]・38開催日）。**すべて未達。**

## 🔴 連系では混戦が「いちばん悪い」— 逆転する

```
混戦度        券種              点数  的中   的中率    回収   3本抜き
混戦         ワイド ×AI1,2      316   17  10.8%  64.0%   42.5%
混戦         三連複 軸流AI1-3     474    4   2.5%  39.6%    1.9%
中          ワイド ×AI1,2      486   38  15.6%  84.6%   71.5%
中          三連複 軸流AI1-3     729   19   7.8%  84.3%   58.4%
堅い         ワイド ×AI1,2      646   50  15.5%  65.0%   51.3%
堅い         三連複 軸流AI1-3     969   20   6.2%  63.7%   44.2%
```

🔑 **複勝で最良だった混戦帯が、連系では最悪になる。**
機序は単純で、混戦では**相手（AI1位）も当てにならない**。1頭で済む複勝は混戦に向くが、
2〜3頭そろえる連系は、混戦で的中率が落ちる幅（三連複 7.8% → 2.5%）が
配当の伸びを上回る。混戦の三連複は3本抜きで1.9%＝**ほぼ全部が数本の的中**。

⚠ 連系は `race_dividends` が 2026-06-06〜09-06 の949レースしか無く、
U2 の対象は724点・三連複の的中は計43件。**期間分割ができないので参考値**
（事前登録どおり、これ単独では採否を決めない）。

## 判定

**「混戦は当たりやすいが取り分にならない」で閉じる。**
しかも**連系にすると逆に悪くなる**ので、「この馬を含む連系は高配当になるはず」という
方向は、配当が大きいのは事実だが**的中率の落ち方がそれを上回る**。

🔑 順序が両期間で保たれた（基準1通過）のは、この一連の検証で初めて。
混戦度そのものは本物のシグナルだが、水準が足りない。
2026-09-08 Phase4「AI集中度が低いレースほどAIは市場に対して弱い」と同じものを
別経路で見ている。
