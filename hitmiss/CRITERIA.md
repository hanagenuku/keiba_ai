# H-M: 5番人気以下で「複勝が当たった馬／外れた馬」に特徴の差はあるか — 事前登録

⚠ **結果を見る前に書いた。** 2026-09-13。

## 🔴 この問いには罠がある（先に潰す）

134特徴量を「当たり群 vs 外れ群」で比べれば、**差は必ず大量に出る**。
`f_speed_fig_avg` や `f_pl_rating` に差が出るのは発見ではなく、
**それらが3着内を予測する特徴量だからそうなっている**だけ（定義に近い）。
2026-08-27（SHAP内訳から +0.1783 が出て、正体はベースラインの統制漏れだった）と同じ型。

したがって問いを2つに分ける:

| | 問い | 位置づけ |
|---|---|---|
| **A** | 生の差（当たり群 vs 外れ群） | **記述**。差が出て当然。発見としては扱わない |
| **B** | **モデルの予測確率で統制したあとの残差差** | **本題**。「AIが見落としている軸」があるか |

## 対象

- `q/predq.pkl` の OOS（train_end 2025-06-30 → **2026-01-01〜09-06 が完全OOS**）
- **5番人気以下**（`pop >= 5`）
- 的中の定義 = **複勝的中**（`y3 == 1`。8頭未満で複勝が2着払いの扱いは下記⚠）
- ⑨と同じく **探索期 2026-01-01〜04-30 / 確認期 2026-05-01〜09-06**

⚠ `y3` は「3着内」であって「複勝の払戻対象」ではない。7頭以下は2着までが払戻。
   本文では y3 で測り、**回収率のところだけ実配当（fukusho_payout）**で測る。

## 手法

### A 生の差
各特徴量について標準化平均差（Cohen's d）= (当たり群平均 − 外れ群平均) / プール標準偏差。

### B 統制後の残差差（本題）
モデルの予測確率 `p = sigmoid(raw)` の**10分位の中で**当たり/外れを比べる
（層別してプールした d）。市場人気は `p` に既に入っているので二重には統制しない。
⚠ 層別は連続量の統制として粗い。補助として `y3 ~ p` のロジスティック残差でも測り、
   2通りで符号が一致するものだけを候補にする。

### 多重比較
134特徴量を見るので **Benjamini-Hochberg FDR 0.05** を通す。
「有意なものが何個あったか」ではなく「**帰無で何個出るはずか**」を必ず併記する
（2026-08-15②「25マス見れば偶然100%超が出る」と同じ）。

## 🔴 先に置く対照群

| 対照 | 何を潰すか | 通過条件 |
|---|---|---|
| **ラベルをレース内でシャッフル** | レース内の構造だけで出る差 | 通過数が帰無の期待付近になる |
| **探索期→確認期** | 偶然の当たり | 探索期で通った軸が確認期でも同符号 |
| **予測確率そのもの** | 統制が効いているかの検算 | B では p 自身の d がほぼ0になる |

## 判定規則

**取り込み基準**（「AIが見落としている軸がある」と言ってよい条件）:
1. 探索期で FDR 0.05 を通る
2. **確認期でも同符号**、かつ確認期単独でも p < 0.05
3. 層別・ロジスティック残差の**2通りで同符号**
4. 通過数がラベルシャッフルの期待数を明確に上回る

**採用基準**（買い方に使ってよい条件・North Star #9）:
5. その軸で切ったとき、実配当の複勝回収率が確認期で > 100%
6. N ≥ 300 かつ 3本抜きでも > 100%

❌ 取り込み基準を満たさなければ「当たり外れを分ける残差の軸は見つからない」と記録する。
   それは失敗ではなく「**モデルは既に見えているものを見ている**」という知見。

## 追記（2026-09-13・ユーザーの意図を取り違えていたので測り直す）

前回は「5番人気以下の**全馬**」を当たり/外れで比べた。ユーザーの意図は違っていて、

> 写真7番の馬のような条件（5番人気以下で3着内に入った）で、当たったレースと
> 外れたレースに分ける。当たったレースに特徴はないか。未勝利戦とか、短距離とか。
> そこで差別化できればその条件のレースだけ買えばいい

つまり**買う単位は「AIが推している人気薄」1点**で、知りたいのは
**その1点が当たりやすい"レースの条件"**。

### 買う単位（2通り。どちらも1レース1点）
- **U1**: そのレースの5番人気以下のうち、AI順位が最上位の馬
- **U2**: U1 かつ **AI順位 < 市場人気**（＝写真の7番のような「推」に近い形）

### 条件の軸
クラス / 距離帯 / 芝ダート / 頭数 / 馬場状態 / 競馬場 / AIの自信（raw最大−中央値）

持ち越すかどうか**で行う。
