## 1. 直す欠陥（コードで確認済み）

`src/tools/calibrate_xgb.py::_predict_fukusho_probs` は base_margin を
`horse_history.popularity`（**確定人気**）から作る。一方:

| | base_margin の土台 |
|---|---|
| `train_xgb`（学習） | 確定人気 **＋ 実測ドリフト注入**（`simulate_serving_popularity=True`・seed 11/12）|
| `engine.calc_all`（本番推論） | **朝オッズ**の昇順から導いた人気 |
| `calibrate_xgb`（較正） | **確定人気（ドリフトなし）** ← ここだけ鋭い |

→ モデルは「ぼやけた土台」で学習し、較正器は「鋭い土台」で当てられ、本番は
「ぼやけた土台」で動く。`_predict_fukusho_probs` の docstring 自身が
「base_margin の作り方は engine.py の推論経路と同一にすること。ここがズレると
較正が本番と違う分布に対して当たってしまう」と書いており、**意図は明示されていて
実装が追いついていない**。

実測（2026-10-19・完全OOS 13,143頭の本番予想）: cal_prob の **ECE 0.0682**。
全体の水準は合っている（予測 0.226 / 実測 0.228）のに両端が外に開く**傾きの誤差**で、
較正時の記録 Test ECE 0.0097 の7倍。月別は 0.0476 → 0.0550 → 0.0423（8月以降）で
**経年劣化ではなく構造**。

## 3. 修正の方針

`_predict_fukusho_probs` の base_margin に、`train_xgb` と**同じ関数**で
同じドリフトを注入する（`load_popularity_drift` / `_apply_popularity_drift`）。
自前で書き直さない。seed は 11/12 と衝突しない **13** を使う（分布を合わせるのが
目的で、特定の引きを再現したいわけではない）。

⚠ **採らなかった案**: `race_predictions` の実朝オッズで較正器を当てる案のほうが
条件は忠実だが、①データ源を変える大きな変更 ②N が 13,948行に減る
③`cal_prob` が表示専用である以上、釣り合わない。**今回は最小の修正に留める。**

## 4. 測定の設計

- **評価行**: `race_predictions` のうち `date > 2026-06-30`（本番モデルにとって完全OOS）
  かつ `actual_place` 非NULL。**base_margin は `race_predictions.popularity`＝
  engine が朝オッズから導いた実際の値**を使う（シミュレートしたドリフトではなく本番の条件）。
- **学習行**: `horse_features.csv` の `date <= 2026-06-30`（評価行と重ならない）。
- **アーム**:
  - **OLD**: base_margin を確定人気から作って当てた較正器（現行実装の再現）
  - **NEW**: base_margin にドリフトを注入して当てた較正器（修正版）
- ビン数・PAV の手順は `calibrate_xgb._fit_isotonic` と同じ（n_bins=20）。
- 両アームとも**同一の評価行・同一の raw_prob** に対して transform を当てる。

## 5. 採用基準（4つすべて満たす場合のみコード修正を本番へ出す）

1. **OOS ECE が改善**（NEW < OLD）
2. 改善幅が **0.010 以上**（現状 0.0682 の約15%）
3. 5分位のうち **4帯以上**で |予測−実測| が悪化しない
4. **全体の水準を壊さない**: |平均予測 − 平均実測| が OLD より悪化しない
   （OLD は +0.003 でほぼ完璧。傾きを直して水準を壊したら意味がない）

## 6. 中止条件（ECE を読む前に通す）

1. **隔離**: 本番 `data/` の md5 が測定前後で不変・作業ツリーが clean
2. **ハーネスの検算（厳密）**: 評価行の raw_prob を再構成し、**現行の
   `xgb_calibrator.pkl`** を当てた値が `race_predictions.cal_prob` に保存されている値を
   再現する（中央値の差が 0.002 以内）。これが合わなければ raw_prob の再構成が
   間違っているので、ECE を読まずに破棄する
3. **OLD アームが現行 pkl と同系であること**: OLD の ECE が 2026-10-19 に実測した
   0.0682 と同程度（±0.01）。離れていたら fit 側の再現に失敗している
