## 0. この Step が問うこと（そして問わないこと）

**問う**: 能力 × 適性が、**別軸として結果（3着内）に効くか**。

**問わない**:
- 市場残差（Step 2・**記述のみ**）
- 回収率で儲かるか（Step 3）。🔴 本カードは**回収率で判定しない**。
  North Star #9（的中率が上がることと回収率が上がることは別物）により、
  3着内率が上がっても回収率が上がる保証は無い。ここで測るのは「情報があるか」だけ

## 3. 9セルの切り方（🔴 結果を見てから細分化しない）

レース内パーセンタイル `pct = (rank − 0.5) / n` で3分位に切る。

| 分位 | 範囲 |
|---|---|
| 上位 | `pct < 1/3` |
| 中位 | `1/3 <= pct < 2/3` |
| 下位 | `pct >= 2/3` |

能力3分位 × 適性3分位 = **9セル**。

⚠ 4分位・5分位に細分化しない。頭数・距離・芝ダ・クラス・会場で層別しない。

## 5. 採用/中止基準（🔴 結果を見る前に固定）

主要統計量は **log-odds**。率の差は基準率に依存し、能力上位では天井効果・下位では床効果が出るため。

| # | 基準 | 合格線 |
|---|---|---|
| **1** | **主効果** | 能力分位を統制した「T上位 − T下位」の 3着内率差が **A1・A2 とも正**、かつ**両期間とも >= 2.0pt** |
| **2** | **持ち越し** | A1 の9セル log-odds と A2 の9セル log-odds の Spearman ρ を**並べ替え分布で P 値化**。合格 **P < 0.05** |
| **3** | **単調性** | 各能力分位の中で 3着内率が T上位 >= T中位 >= T下位。**A1・A2 の両方で 3分位中 2つ以上** |
| **4** | **対照群A（並べ替え分布）** | T をレース内でシャッフル 200 回。合格 `\|mean(効果)\| < 2*std/sqrt(200)`。実測の効果は**並べ替え P で報告**する |
| **5** | **対照群B（注入の復元）** | 既知の効果を T の レース内 z 値に加算 → 合格 `注入後 − 注入前 = 注入量`（許容差 **1e-3**） |

**5つ全部を満たして初めて Step 2 へ進む。**

### 🔑 閾値が統計量自身の SE より大きいことの確認（North Star #11）

| 基準 | 閾値 | 統計量の SE | 判定可能か |
|---|---|---|---|
| 1 | 2.0pt | 各期間の T上位群は約 14,000頭。3着内率22%の SE = 0.35pt、差の SE ≈ **0.50pt** | ✅ **SE の4倍** |
| 2 | P < 0.05 | 並べ替え分布で出すので SE 問題が生じない | ✅ |
| 4 | `2*std/sqrt(200)` | 形そのものが SE 基準 | ✅ |
| 5 | 1e-3 | **代数恒等式の検算**なので統計量の SE とは無関係（North Star #11 の注記どおり） | ✅ |

### 🔴 基準1が落ちた場合に見る交互作用（**先に列挙する。事後に増やさない**）

`RESULTS_GATE0.md` §6 の要請（「適性の主効果が無い」だけで否定しない）に従う。

能力3分位それぞれの中での「T上位 − T下位」の 3着内率差を3つ出す（**d_top / d_mid / d_bot**）。

| # | 見るもの | 合格線 |
|---|---|---|
| **I-1** | A1 での d の**大小順序**（3! = 6 通り）が A2 で一致するか | 一致（偶然なら 1/6） |
| **I-2** | 少なくとも1つの能力分位で **差 >= 3.0pt** | 局所効果を主張するなら主効果（2.0pt）より強い証拠が要る |

**I-1 と I-2 の両方**を満たし、かつ**基準4・5 を通った**場合にのみ Step 2 へ進む。

⚠ これ以外の交互作用（頭数別・距離別・芝ダ別・クラス別・会場別）を**事後に足さない**。

## 6. 感度分析（事前登録）

`f_course_fit_score` を外した **4列版 T** で基準1〜3 を再計算し、結論が変わらないかを見る。

理由: Gate 0 でこの列だけ ρ̄=+0.7273（能力との縮退）/ τ̄=+0.9114（条件に反応しない）と
**両方で最悪**であり、`f_course_fit_score = 5·(stamina_demand·f_stamina_score + speed_demand·f_speed_score)` の
`f_stamina_score` / `f_speed_score` は**その馬の能力水準そのもの**（＝「適性」の顔をした能力の掛け算）。

🔴 **4列版で良い結果が出たからといって、そちらを採用しない。**
感度分析は「結論が1列に依存していないか」を見るためだけに使う。構成列は5列で固定。
