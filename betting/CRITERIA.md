## 0. この研究は何か（そして何ではないか）

**やること**: AI が**既に持っている情報**（能力・適性）を、
**馬券の形**（券種・軸・相手）に変換できるかを調べる。

**やらないこと**: 🔴 **市場の歪みを探さない。**
direction ②（市場が系統的に過大／過小評価している領域の探索）は
2026-09-18 に閉じた（`mispricing/CRITERIA.md` §5 の確定文）。
この研究は②の続きでも言い換えでもない。

| | ② | この研究 |
|---|---|---|
| 出口 | 市場残差 +6pt | 単勝・複勝の実回収率 |
| 探すもの | 市場が間違える領域 | **手持ちの情報の変換効率** |
| 市場残差の扱い | 主役 | 🔴 **記述のみ。選択には一切使わない** |

🔴 **Step 2（能力×適性 → 市場残差）は最後まで「記述のみ」。**
「このセルは市場残差が良いから Step 3 で買う」という使い方を**禁止する**。
それをやると②-B の交互作用探索と実質的に同じものになる。
Step 3 が選択に使ってよいのは **Step 1（能力×適性 → 結果）で事前登録した規則だけ**。

## 1. 🔴 なぜ Gate 0 が要るのか（2026-09-18 の発見）

現在の `f_course_fukusho` / `f_dist_fukusho` / `f_same_turn_rate` / `f_uphill_match` /
`f_same_course_rate` は、**過去走を今回条件で絞り込んだ 3着内率**である。
これは**条件付き能力**であって「今回条件への適合度」ではない
（全文と裏付けは `HORSE_ABILITY_DESIGN.md` §9）。

したがって「能力 × 適性」を掛け合わせる前に、
**そもそも能力と独立した適性軸を作れているのか**を先に測る必要がある。
それが Gate 0。**Gate 0 に落ちたら、この研究はその時点で終了する。**

⚠ Phase 2 の F8「コース・距離適性」が F1「近走成績・PL」と相関 0.00 であることを
**独立の根拠にしない**。8ブロックは**直交回転**で作られているので相関 0.00 は
回転の性質である。これを根拠にするのは 2026-09-17 に `f_last1_rank` で踏んだ
「直交化した成分の単独AUCで固有情報の有無を判定する」誤りと同型（North Star #8）。

### 2.2 適性軸 T

**採用する5列**（すべて `varies_horse: true` かつ `varies_course: true`。
＝馬によって変わり、かつ**今回の条件を差し替えると値が動く**）:

| 列 | 構造 | 符号 |
|---|---|---|
| `f_style_course_fit` | 脚質 × そのコースの有利脚質 | + |
| `f_dist_vs_optimal` | 今回距離 − その馬の最適距離 | **−│·│**（両方向に外れるほど悪い。絶対値の負） |
| `f_speed_x_shortening` | スピード型 × 距離短縮量 | + |
| `f_stamina_x_extension` | スタミナ型 × 距離延長量 | + |
| `f_course_fit_score` | コース要求（スタミナ/スピード）× 馬の型 | + |

**符号はすべてコードの構築式から決まる**（大きいほど適合）。データを見て決めていない。

```
T_score = mean_j [ z_race( sign_j · x_j ) ]     j = 上の5列・等重み
z_race   = レース内での標準化（平均0・分散1）。レース内 std = 0 の列はその列を除外
T_rank   = レース内の降順（1 = 最も適合）。タイブレークは馬番の昇順
```

## 4. Gate 0 の4つの検査

### 0-a 縮退検査（適性が能力の言い換えになっていないか）

```
測定量  ρ = レース内 Spearman( 能力順位 A_rank , 適性順位 T_rank )
        ρ̄ = レース平均
合格    ρ̄ < 0.80
```

🔴 **合否だけでなく、以下を必ずログに残す**（結果を見てから閾値を変えることは禁止）:

| 診断ログ | 意図 |
|---|---|
| ρ̄ と ρ の分布（5 / 25 / 50 / 75 / 95 パーセンタイル） | 0.79 と 0.81 の間に本質的な境界は無い。**分布として読む** |
| 平均絶対順位差 `mean │A_rank − T_rank│` | 順位相関とは別の言い方での乖離量 |
| `│A_rank − T_rank│ >= 3` の馬の割合 | 「大きく乖離する馬」がどれだけ居るか |
| **5列それぞれの単独 ρ** | どの列が縮退させているかを特定する。`f_course_fit_score` は構築式に能力（`f_stamina_score`/`f_speed_score`）が入るので高く出ることが予想される |
| 初出走馬を含むレース / 含まないレースの別の ρ̄ | θ=0 の同値が結果を作っていないか |

### 0-b 条件感応検査（今回条件に本当に反応しているか）

```
差し替え規則（固定）  各レースの (会場, 馬場, 距離) を、
                    race_id を昇順に並べた列で k=1 だけ循環シフトした先の
                    レースの条件で置き換える（＝実在する条件に必ず写る）
測定量  τ = レース内 Kendall( 元条件での T_rank , 差替後の T_rank )
        τ̄ = レース平均
合格    τ̄ < 0.70
```

診断ログ: τ の分布、**差し替えで適性1位が入れ替わったレースの割合**、5列それぞれの τ̄。

### 🔑 0-a と 0-b は別々の意味を持つ検査である

合否の組み合わせを**結果を見る前に**言葉にしておく:

| 0-a | 0-b | 読み方 |
|---|---|---|
| 合格 (ρ̄ < 0.80) | 合格 (τ̄ < 0.70) | **能力と別軸で、かつ今回条件に反応している** → Gate 0 通過。Step 1 へ |
| 落ちる (ρ̄ >= 0.80) | 合格 | **能力支配だが、条件由来の変動は持っている**。軸としては能力の言い換えなので Gate 0 は落とすが、「条件成分は存在する」という事実は別途記録する |
| 合格 | 落ちる (τ̄ >= 0.70) | 能力とは別軸だが**今回条件に反応していない**＝「適性」ではなく**別の馬属性**。Gate 0 落ち |
| 落ちる | 落ちる | 適性軸を作れていない。Gate 0 落ち |

### 0-c 対照群B — 注入の復元（**注入単位を実装前に固定する**）

🔑 **注入するもの・復元すべきものを、実装前にここで確定する**
（P3-01 で「注入後 ≈ 注入量」と書いて、測っていない仮定を置いた失敗の再発防止）。

**注入単位 = 適性スコアの「レース内 z 値」への加算（z 単位）。**
適性確率にも順位にも注入しない。

合成部品（すべて決定論的・seed=20260918 固定）:

```
v[horse_id]  標準正規の固定乱数。馬に固定。条件を差し替えても不変。能力を一切参照しない
g1,g2[cell]  一様 [-1, 1] の固定乱数。cell = (会場, 馬場, 距離帯4区分)。今回条件だけで決まる
v1,v2[horse] 標準正規の固定乱数（2本）。馬に固定。条件に依存しない。能力を一切参照しない
S            = z_race( g1[cell]·v1[horse] + g2[cell]·v2[horse] )
             → 「馬の型 × 今回条件の要求」という、本物の適性と同じ構造を持つ合成軸
A_z          = z_race( −A_rank )   ← 能力そのもの

> 🔧 **2026-09-18・実装中の修正（いかなる測定値も読む前）**: 当初 `S = z(g[cell]·v[horse])` と
> 1成分で書いたが、レース内では `g[cell]` は定数なので **順位が v の順序か、その完全な逆順に
> しかならない**（τ ∈ {+1, −1}）。これでは「条件感応の計測器が**段階的に**動くか」を
> 検査できず、c-2 の τ̄<0.30 が「平均すると 0 になる」という別の理由で通ってしまう。
> **2成分にした。** データを一切見ずに、構造だけを見て気づいた修正である。
> 🔴 乱数のキーは `hashlib.sha256` で作る。Python の `hash()` は文字列に対して
> プロセスごとに変わる（PYTHONHASHSEED）ため、対照群が実行のたびに別物になる。
```

| # | 注入 | 測定量 | 合格式（事前固定） |
|---|---|---|---|
| **c-1** | `T_inj = z(T_score) + 4·A_z`（**能力を注入**） | 0-a の ρ̄ | **ρ̄ > 0.95** ＝ 縮退があるとき計測器はそれを報告できる |
| **c-2** | `T_inj = S`（**本物の適性と同じ構造の合成軸に置換**） | 0-a の ρ̄ / 0-b の τ̄ | **ρ̄ < 0.10 かつ τ̄ < 0.30** ＝ 本物があれば Gate 0 は通す |
| **c-3** | 条件を**差し替えない**まま 0-b を実行 | 0-b の τ̄ | **τ̄ = 1.000（最大差 < 1e-9）** ＝ 代数恒等式。差し替えが黙って効いていない事故を捕まえる |
| **c-4** | `T_inj = z(T_score) + 0·S`（δ=0） | T_inj の値 | **z(T_score) と完全一致（最大差 < 1e-9）** ＝ 代数恒等式 |

⚠ **c-1 / c-2 は統計量の閾値**（0.95 / 0.10 / 0.30）。N=2,000レースでの SE ≈ 0.005 なので、
どれも SE の 20倍以上離れている。
⚠ **c-3 / c-4 は代数恒等式の検算**なので許容差 1e-9 でよい（両者を混同しない。North Star #11）。
⚠ 🔴 **c-1〜c-4 は本データの 0-a / 0-b を読む前に通す。** 通らなければ本データの数字を印字せず中止する。

### 0-d 対照群A — 並べ替え分布

```
操作    T_score をレース内でシャッフル（200回）
測定量  ρ_shuffle（0-a と同じ式）
合格    │mean(ρ_shuffle)│ < 2 · std(ρ_shuffle) / sqrt(200)
報告    本データの ρ̄ を並べ替え分布上の P 値として併記する
```

⚠ 🔴 `│ρ_shuffle│ < │ρ│/3` のような**1回の引きの大小比較は書かない**（North Star #11）。

### Gate 0 に落ちた場合（そのまま使う文）

> **現在の適性特徴量では、能力と独立した今回条件への適合度を作れていないため、
> 能力×適性の馬券変換研究には進まない。**

- この研究は**その時点で終了**する。Step 1 以降は書かない
- ⚠ ただし「**適性というテーマを永久に閉じる**」まではしない。
  別途「適性を本当に作れるか」という**特徴量設計の研究**を登録する余地は残す
- 🔴 ただしその研究を**このカードの中で続けない**。新しいカードとして登録し直す
  （結果を見てから目的を差し替えるのは、このプロジェクトが何度も踏んだ形）

### Gate 0 を通った場合

Step 1 へ進む。**ただし Step 3 を「最適買い目探索」にしない。** 順序を固定する:

| | |
|---|---|
| Step 1 | 能力 × 適性 → **結果**（3着内率）。能力×適性が本当に別軸として結果に効くか |
| Step 2 | 能力 × 適性 → **市場残差**。🔴 **記述のみ。選択には一切使わない**（§0） |
| Step 3 | Step 1 で事前登録した**固定規則**で **単勝・複勝のみ**を検証 |

**Step 3 が単勝・複勝に限られる理由**（データ側の制約・先に書く）:
組み合わせ券種の実配当 `race_dividends` は **993レース / 30開催日 / 2026-06-06 以降**しか無く、
**A期間には1行も存在しない**。ワイド・馬連・三連複は A/B の OOS 検証が構造的に組めない。
単勝・複勝は `history.db` の `tansho_payout` / `fukusho_payout` が 2023-01 から揃っている。

### 🔴 Step 1 の停止条件に課す制約（先に書く）

⚠ **「適性の主効果が無い」だけで否定しない。**
能力 × 適性の**組み合わせ**に、事前登録した範囲で意味のある差があるかを見る必要がある
（例: 能力1位の中では適性が効くが、能力5位の中では効かない）。

⚠ **ただし結果を見てから交互作用を探し始めるのは禁止。**
Step 1 を登録する時点で、見る交互作用（どの分位 × どの分位を、どの向きで期待するか）を
**列挙して固定する**。事後に増やさない。

⚠ 多重比較の予算を先に書く: 能力3分位 × 適性3分位 = 9セル × 軸/相手 2 × 券種 2 = **36比較**。
N=300 のセルなら偶然 100% 超が出る確率は 4.2%（2026-08-24 の帰無シミュレーション）なので、
**期待される偽セルは約1.5個**。「100% を超えたセルがあった」はそれ自体では何の証拠にもならない。
