## 4. なぜその条件でAIが弱いのか（仮説の整理・指示#19）

### 仮説1: 過去走が無い／薄いほどAIは何も言えない（新馬 −0.0851 が極端例）
新馬は AI 0.6977 に対し市場 0.7829。**AIの入力（近走成績22列・スピード能力27列）が
定義上ほぼ空**なのに、市場は厩舎評判・調教・血統の下馬評を織り込む。
Phase 2 で「効く3群」が近走成績・スピード能力・騎手だったこととぴったり整合する。
新馬では3群のうち2群が使えない。

### 仮説2: 混戦ほどAIが余計に落ちる（機序の本体）
`corr(市場AUC, AI−市場差) = +0.537`。AI上位3頭集中 Q4高(−0.0091) → Q1低(−0.0466)、
エントロピー Q1低(−0.0109) → Q4高(−0.0355) と**単調**。
⚠ この軸は内生的でもある（AIが自信を持つのは簡単なレースだから）。
ただし重要なのは**両方が落ちる中でAIの落ち方が大きい**こと。
市場は難レースでも 0.7566 を保つが、AIは 0.7211 まで落ちる。

### 仮説3: 🔴 AIと市場が食い違うレースほど、AIが弱い（希望と逆）
```
AI1位 = 市場1番人気     −0.0181 (R=1,023)
AI1位 = 市場2-3番人気    −0.0202 (R=545)
AI1位 = 市場4番人気以下  −0.0357 (R=163)

上位3頭が3頭一致  −0.0128 (R=583)
        2頭一致  −0.0204 (R=939)
        1頭一致  −0.0430 (R=196)
```
指示#11 の問い「乖離が大きいレースほどAIの相対性能が高いのか？」への答えは **No、逆**。
両方の軸で単調に悪化する。市場アンカーを外した Layer 1 でも同じ形が出た。
2026-08-03（AI強気ほど実勝率が単調に下がる）・2026-08-29（GAP）・2026-09-07
（AI軸が市場1番人気と違う14%が全部外れている）と**別経路で同じ結論**。

### 仮説4: 上位クラスは誰にも当てられないが、AIの落ち方が大きい
オープン −0.0427。2026-08-18「クラスが上がるほど市場AUCが落ちる（未勝利0.8367→OP0.7634）。
しかしOPだけAIの上乗せがマイナス」が、市場フリー体制でも再現した。

### 仮説5: 短距離・多頭数はゲート/展開の運の比率が高い
芝〜1200 −0.0342、16頭〜 −0.0276（〜9頭 −0.0162 との差 0.011）。
「能力を測る」というAIの土俵から外れるほど不利になる。

## 5. コース形態（Phase 2 の宿題への回答）

Phase 2 で「コース適性20列は単独AUC 0.7132 の情報を持つが Layer 1 では −0.0004」だった。
**Layer 2 の分割軸としてはどうか**を測った結果:

```
回り     left −0.0186 / right −0.0204            差 0.002
直線     medium −0.0168 / long −0.0213 / short −0.0215   差 0.005
坂       あり −0.0170 / なし −0.0219             差 0.005
コース形態 standard −0.0166 / spacious −0.0171 / tight −0.0180 / flat_tight −0.0286
```
🔴 **コース形態は分割軸としても弱い。** 最大でも 0.005〜0.012 しか動かず、
レース構造の軸（集中度で 0.0375 動く・一致数で 0.030 動く）に遠く及ばない。
唯一 `flat_tight`（−0.0286）が目立つが探索期は −0.0145 で持ち越しが弱い。

🔑 **Phase 2 の「Layer 2/3 の分割軸として使える可能性がある」という見立ては、
Layer 2 については支持されなかった。** 効く軸は「コースの形」ではなく
**「そのレースが難しいかどうか」**だった。

## 6. Phase 5 への含意（⚠ 指示#17に従い買い条件は作っていない）

- 🔴 **「AIが得意なレースを選んで買う」の前提が崩れている。** A が空なので、
  レース選別で拾えるのは「**AIが市場に近いレース**」であって「AIが市場に勝つレース」ではない
- ✅ **使える向きは逆側**。「AIが弱いレースを外す」なら軸は明確で再現もする
  （新馬・混戦・AIと市場が食い違うレース・オープン・芝短距離・多頭数）。
  CLAUDE.md の `racetype/` が「馬選びでは負けるが**見送り判断としてなら 84.8%**で
  唯一生存」と記録しているのと同じ方向
- 🔴 **ただし North Star #9。** 当てやすいレースは配当も安い。
  「混戦を外す」は「高配当レースを外す」とほぼ同義なので、**回収率で測るまで
  利益になるとは言えない**。ここが Phase 5 の最初の関門になる
- ⚠ AI集中度・エントロピーの軸は**内生的**（AIが自信を持つのは簡単なレースだから）。
  Phase 5 で使うなら、市場側の集中度で統制した上で AI 側に追加情報があるかを見ること。
  CLAUDE.md に「市場が割れている×AIが確信 で絞ってもどのセルでも軸の83〜88%が
  市場1番人気」という既測定があるので、そこと突き合わせる

## 7. 計測器について

- ⚠ 全体AUCは頭数効果を含む。ただし AI・市場の**差**を見ているので大部分は相殺される
- ⚠ 条件は R>=60 でフィルタ。65条件が残り、8条件（芝2500〜など）が両期間の
  どちらかで基準を割って除外された
