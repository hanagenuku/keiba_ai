# 事前登録カード: 相手の中穴を「前に行けそうな馬」から選ぶ（2026-11-13）

ユーザー指示「進めて」（`tenkai/EXPLORE_corner4.md` の「次の一手」）。
🔴 このカードを書いた時点で、**買い目の単位（馬連・ワイド・三連複）の数字は1つも見ていない**。

## 0. 何を確かめるか・何が既に見えているか

探索で「人気薄の中では、前に行けそうな馬のほうが3着内に来やすい」と出た（馬1頭ずつ・複勝）。
これを記事の買い目に移したとき、**相手に入る中穴の当たりやすさが実際に上がるか**を確かめる。

🔴 **未読の窓は無い。** 予想時点の `rl_rank` とオッズが残っているのは 2026-06-27〜11-08 だけで、
探索②はこの期間を馬の単位で読んでいる。だからこれは「新しい発見の検定」ではなく
**「馬の単位で見えた差が、いまの買い目の作り方を通しても残るか」の確認**として読む。

## 1. ルール

- **R0（現行）**: `tickets.split_partners`。中穴（単勝 7.0〜30.0倍）は `rl_rank` の良い順に取る。
- **R1**: 中穴の候補を「**`style` が 逃げ／先行 の馬を先、それ以外を後**（それぞれの中は `rl_rank` 順）」に並べ替えてから取る。
  固め（7.0倍未満）・頭数（strong 3+2／light 2+1）・埋め合わせの規則・買い目の形は変えない。
- `style` は本番と同じ関数（`_infer_running_style`・過去走の脚質の最頻値）で、そのレースより前の走りだけから作る。
  ⚠ 過去走が無い馬は本番どおり「馬番3以下なら先行・それ以外は差し」になる（本番で見える値に合わせる）。

## 2. 母集団

`race_predictions`（予想時点のオッズ・`rl_rank`）と `race_dividends`（全券種の払戻）がそろう 2026-06-27〜11-08 のレース。
`conf`（軸の3着内確率）で本番と同じに分ける: strong（66以上）／light（55〜65）／skip（55未満は買い目を出さないので対象外）。
**主な母集団は strong ＋ light。** ⚠ 「◎が危険な人気馬なら1段下げる」は当時の `solo_rank` が残っていないので再現しない（両ルールで同じ扱い）。

## 3. 測るもの（1点100円の均等買い）

- 中穴枠で選ばれた馬の3着内率・平均単勝オッズ
- 馬連（◎−相手全頭）／ワイド（◎−固め筆頭・中穴筆頭）／三連複（◎1頭軸流し）の的中率（レース単位）と回収率
- 買い目が変わったレースの数

## 4. 合否

| # | 基準 | 合格線 |
|---|---|---|
| 1 | 中穴枠の馬の3着内率 | R1 − R0 >= **+1.0pt**、かつ対照群A の上側5%点を超える |
| 2 | 3券種の的中率 | 単純平均で R1 > R0、かつどの券種も **−0.5pt より悪化しない** |
| 3 | 高配当の性質を保つ | 中穴枠の馬の平均単勝オッズが R0 の **0.9倍以上**（人気寄りに逃げていない） |
| 4 | 回収率のガード | 3券種合算の回収率 R1 − R0 >= **−5.0pt**（差のブートストラップ95%区間も報告） |

- **対照群A**: R1 の「前に行けそうな馬を先」の代わりに、**中穴の候補をでたらめな順**にして取る（200回）。
  基準1の統計量の分布を作り、実測がその上側5%点を超えること。帰無が0中心とは仮定しない（2026-11-11 の反省）。
- **対照群B**: 中穴枠の不的中 k 頭を的中に書き換えると3着内率がちょうど k/N 上がること、
  払戻に一律 +b 円を足すと回収率がちょうど b pt 上がることを検算する。
- 回収率は合否の主役にしない（`websig/ADOPTION_STANDARD.md` と同じ考え方）。三連複は的中が少なく誤差が大きい。

## 5. 中止条件（結果を読む前に印字）

1. 対象レースが strong＋light で 300 未満
2. strong の ◎ 複勝的中率が 60〜71% の外（成績ページの 65.5% から大きく外れる＝復元の失敗）
3. `style` が付かない馬が 1% を超える
4. R0 の相手が本番の規則（`tickets.split_partners` を直接呼ぶ）と別の実装になっている

## 6. 結果の読み方

- 1〜4 をすべて満たす → **採用**。`tickets.split_partners` の中穴の並べ方を R1 に変える（別PR・テストつき・実測を添えて報告）。
  記事の説明文も「中穴は前に行けそうな馬を優先」と事実だけ足す。**「回収率が上がる」とは書かない。**
- どれか落ちる → 不採用。並べ方・帯・期間を変えて測り直さない。
- 対照群が通らない → 計測器の不具合として採否に使わない。
