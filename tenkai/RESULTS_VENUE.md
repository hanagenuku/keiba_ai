# T'-C2: 競馬場 one-hot が効いた理由を分解した（2026-09-15・診断）

ユーザー指摘:
> 今すぐさらに特徴量を大量投入するより、「競馬場one-hotが効いた理由」を
> 一度確認してから次へ進むのがいい。どの競馬場がどれだけ寄与しているのか。
> できれば 競馬場×距離 まで見たい。「コースが重要」までは強く言えるが
> 「何が重要なのか」はまだ分かっていない。

**これは診断であって採用判断ではない。この検証でモデルは1行も変えていない。**

## ⚠ 使えなかった手法（先に潰したもの）

**one-hot から1会場分の列を落とす ablation は使えない。** 残りが全部0であることで
その会場だと分かるので、情報が消えない（ダミー変数の罠）。
代わりに ①会場ごとの改善量 ②改善を「定数ずらし」でどこまで再現できるか を測った。

## ② 🔑 改善の中身: 「発走地点ごとの定数ずらし」で 97% 再現できる

学習期の残差の平均をキーごとに取り、検定期の予測に**足すだけ**の単純な補正で、
会場 one-hot の改善をどこまで回収できるか:

```
粒度                              窓A       窓B     回収率A  回収率B
M0 会場なし                      0.8339   0.8431      0%      0%
+ 会場                          0.8291   0.8352      7%     18%
+ 会場×馬場                      0.8261   0.8320     11%     25%
+ 会場×馬場×距離帯                0.7970   0.8133     54%     66%
+ 会場×馬場×距離(実距離)           0.7673   0.7994     97%     97%
M1h 会場をモデルに入れる            0.7650   0.7980    100%    100%
```

🔑 **会場 one-hot がやっていたのは、実質「(会場, 馬場, 実距離) ごとの水準補正」だった。**
頭数やクラスとの交互作用ではなく、**発走地点ごとの固定オフセット**。

🔑 **「会場ごとに1つの数字」では足りない（7〜18%）。距離帯でも足りない（54〜66%）。
   実距離まで落として初めて 97%。** つまり効いているのは会場の性格ではなく
   **その距離のスタート地点**である。

## ③ そのクセは年をまたいで持ち越すか → 持ち越す

⚠ 最初 ρ=+0.966 と出したが、**2つの窓の学習期が重なっていた**（窓Bの学習 ⊃ 窓Aの学習）。
独立な再現ではないので取り消し。期間を分離して測り直した。

```
前期 3,335R（2025年） / 後期 2,144R（2026年）  ※重複なし
  前期のズレ vs 後期のズレ   ρ=+0.819  P=0.0005  n=25
  ズレの大きさ  前期 std 0.245s / 後期 std 0.242s
```
⚠ `lap_times` は 2025年以降しか無い（2023-24は0%）ので、これ以上前では分けられない。

**全部 |ρ| <= 0.26 / P >= 0.21。1つも説明できていない。**

⚠ c5 の初版では `uphill_sev` に `ρ=+nan, P=0.000 ←` と出ていたが、
   これは**分散ゼロ（全部同じ値）で相関が nan になり、並べ替え検定が

⚠ 機序的に最も関係しそうな `start_to_corner_m` は **n=5 でそもそも測れない**。
   「効かない」ではなく「**データが足りなくて測れていない**」。

**ズレは (会場, 馬場, 実距離) 単位で決まっているのに、その単位の物理データが 22% しか無い。**

### 優先順（機序から）

1. **スタート→最初のコーナーまでの距離**（全83組合せ）
2. **スタート地点の勾配（下り発走か上り発走か）** ← いま持っているのは
   「ゴール前の坂」と「コース全体の高低差」だけで、**スタート地点の高低は無い**
3. **発走の形**（直線の途中 / コーナーの途中 / ポケット・引込線から）

## 🔑 正直な見立て（物理データを集める前に知っておくべきこと）

**発走地点ごとの経験的な定数だけで 97% が説明できてしまう。**
つまり物理データを集めても「**当てる**」ためには効かない可能性が高い。
効くとすればその価値は別のところにある:

- **説明**: なぜ東京ダート1400が遅く中山ダート1200が速いのかが言える
- **外挿**: 観測の薄い組み合わせ（20R未満の組・新設距離）に効く
- **検証**: 「スタート→1角が長いほど前半が速い」という仮説を初めて検定できる

⚠ **逆に言えば、物理データを入れて RMSE が大きく下がることは期待しない方がいい。**
   会場 one-hot が既にその情報を経験的に持っているため。
   もし大きく下がったら、それは物理量が会場ダミーの代理になっているだけかもしれない
   （2026-09-15 の M2h/M3h がまさにそうで、one-hot の後では追加価値が消えた）。
