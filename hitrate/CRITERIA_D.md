# 事前登録カード D: 単勝回収率を**主指標**にして C-2 の差し替えを測り直す

作成 2026-11-10（測定前）。ユーザー依頼「1.2.3とも進める」の 2。

## 0. このカードが答える問い

`hitrate/RESULTS_C.md` §2-3 に出た **単勝回収率 101.46%（τ=0.60・N=134・2025年）**は
**別の期間でも残るのか。**

🔴 **このカードは「100%超を主張するため」ではない。N=134 の数字が消えるかを確かめるため**にある。
事前の見込みは「**消える**」。前例:

- 本番76点で ROI 182.8% → 約2,000レースで **71.3%**（2026-07-28）
- 成績ページの「100%超のマス」→ **3度否定**（2026-08-15・08-31）
- 4〜9.9倍の1着馬に共通の特徴 → 246セルで100%超は**帰無並み**（2026-08-24）
- 🔴 **回収率100%超はこのプロジェクトで一度も確認できていない。**

🔴 **測定前にコミットする。実行後は1文字も変えない。**

## 1. 探索期と確認期を分ける（同じデータを2回読まない）

| 期 | 期間 | レース数 | 役割 |
|---|---|---|---|
| **探索期** | 2025-01-01 〜 2025-12-31 | 3,442 | **ここで 101.46% が出た。判定に使わない** |
| **確認期（主）** | 2026-01-01 〜 2026-11-08 | 2,890 | **判定はここだけで行う** |
| 参考期 | 2024-01-01 〜 2024-12-31 | 2,961 | 学習期間が2023年だけで薄いので**報告のみ** |

確認期は walk-forward 3分割にする（学習期間は各窓の開始前日まで）。

| 窓 | 学習 | 評価 |
|---|---|---|
| V1 | ≤ 2025-12-31 | 2026-01-01 〜 2026-04-30 |

一度も読んでいない**。読むのはこれが初めてである。

## 2. 腕（C-2 と完全に同一。1つも変えない）

目的変数 `y = 1{着順(X) < 着順(P1)}`／特徴量は129特徴量の**差分のみ**／
本番ハイパーパラメータ／シード 42・7・2026／内側HO42日（起点は実在する最後の日）／
Isotonic 較正／τ ∈ {0.55, 0.60}。

🔴 **τ は 0.55 と 0.60 の2つだけ。** 探索期で基準②（>=100レース かつ >=3%）を満たしたのは
この2つだけだったので、それ以外は最初から見ない（事後に τ を増やさない）。

## 3. 主指標と対照

- **主指標**: 差し替え馬の**単勝回収率**（`logic2026/eval.py::roi(kind='tansho')`）
- **対照**: 同じレースで据え置いた場合（P1）の単勝回収率
- 併記（判定に使わない）: 勝率・複勝率・複勝回収率

## 4. 合格基準（すべて満たしたときだけ「残った」と書く）

ある τ ∈ {0.55, 0.60} が、**確認期（主）で**次を同時に満たすこと。

1. **差し替えレースが 100 以上**（下回ったら §6-2 で停止）
2. **ブートストラップ（レース単位・10,000回）95%信頼区間の下限が 100.0% を上回る**
3. 差し替え馬の単勝回収率 − P1 の単勝回収率 **>= +10.0pt**
4. 2・3 が **V1・V2・V3 の3窓すべてで同符号**（各窓で下限>100%までは要求しない）
5. 🔴 **信頼区間の幅（上限 − 下限）が 60.0pt 以下**。これを超えたら
   **点推定を読まずに「N 不足で判定不能」と書く**（North Star #11: 閾値が統計量の SE より
   大きいかを先に確かめる）

1つでも欠けたら **不採用**。閾値・期間・τ・指標を結果を見てから動かさない。

🔴 **合格しても「勝てる」「儲かる」と書かない。** 合格は「もう一度測る価値がある」という
意味でしかなく、その先は**実弾を1円も使わずに**さらに別の期間で確認する。
商品に載せるかは `biz/` の判断で、このカードでは決めない。

## 5. 対照群（North Star #11・`CRITERIA_C_RERUN.md` §3 と同じ形）

- **対照群A**: 差し替え対象レースの `Δ_i = 単勝払戻(差し替え馬) − 単勝払戻(P1)` を
  **符号反転**して200回。合格は `|mean(Δ_shuffle)| < 2·std/√200`。
  🔴 「ランダムに選んだ馬 − P1」を帰無にしない。
- **対照群B-1（閉じた式で復元）**: `roi(kind='tansho', bonus=5)` で
  `ΔROI = +5.00pt`（±0.01）。本物が無いときこの式が返す値（0.00pt）も同じ行に印字する。
- **対照群B-2（閉じた式で復元）**: スコアを `score + 1000·y` に差し替えて
  `AUC = 1.0000`（±0.0001）。

## 6. 停止条件（結果より**先に**印字する）

1. 確認期のレース数 < 2,500 → 停止
2. どの τ でも差し替えレースが 100 未満 → **「N 不足で判定不能」として停止**
3. 内側HO < 1,000行 → 停止
4. P1 を特定できないレースが 5% 超 → 停止
5. 対照群 B-1・B-2 のどれかが復元しない → **計測器の不良として停止**
6. 探索期（2025）を再実行して `c_result.json` と数字が一致しない → 停止（再現性）
7. **確認期の信頼区間の幅が 60.0pt を超えた** → 点推定を読まずに「判定不能」で停止

## 7. やらないこと

- 落ちたあとに期間・τ・券種（馬連・ワイド…）を変えて測り直さない
  （`danger/` を3着内と1着で二度読んだ失敗を繰り返さない）
- 「探索期では 101% だった」を根拠として使わない。探索期は**判定に使わない**
- 合格しても本番の `rl_rank` / ◎ / 印 / 買い目 / 確率を変えない
