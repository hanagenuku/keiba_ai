## 1. 前回の何が壊れていて、何が直ったか

前回（`RESULTS_C.md` §5-1）の対照群Bは「注入量」を

    注入量 = mean(z 単独の AUC) − mean(素のモデルの AUC) = 0.6482 − 0.6832 = **−0.0350**

として計算していた。**z 単独 AUC はモデルの AUC より低いので、この式は本物の信号が
あっても無くても負しか返さない。** 注入で AUC が +0.0483 上がったのは正しい挙動だった。

今回は**閉じた式で注入量が分かる統計量にしか合格線を置かなかった**。これで通った。

### どちらの τ を使うか（基準ではなく**表示の設計**の話）

カード §4 は「ある τ で5基準すべて」なので **0.55 と 0.60 のどちらでも合格**である。
2つが通ったので、どちらを使うかは閾値の「後出し変更」ではなく**文面の設計**になる。

| | τ=0.55 | τ=0.60 |
|---|---|---|
| ☆が出るレース（2025） | 302.7 / 3,442 = **8.79%** | 124.3 / 3,442 = **3.61%** |
| ☆が出るレース（2026・候補D） | **24.12%** | **18.72%** |
| 言える確率（評価実測） | 58.8% | **64.1%** |
| 複勝率差 | +13.74pt | **+25.35pt** |
| 窓ごとの最小 | +6.75pt（W3） | **+20.44pt**（W2） |

**推奨は τ=0.60。** ☆の文言が「上回る可能性が**比較的高い**」なので、
58.8%（ほぼ五分）より 64.1% のほうが文言と一致する。窓ごとの下振れも小さい。
τ=0.55 を選ぶなら「☆が出る頻度を増やす」ことが目的になるので、
その場合は文言を「やや上回りやすい」に弱める必要がある。
**最終的な選択はユーザーの判断**（`biz/S4_HITRATE_AXIS.md` §5 に追記した）。
