## 0. 結論

カード §11 に先に書いてあった文:

> ◎が4番人気以下になるレースで軸を市場1番人気に替える操作は、事前登録した幅では
> 的中率と回収率を同時に改善しなかった。**◎の決め方は変えない。**
> 🔴 これは「AI が強気な側で弱い」という既知の事実の否定ではない。否定したのは
> **その事実を軸の置き換えで馬券・記事の成果に変換できる**という部分である。

実測はそれより強い結論になった。**置き換える対象のレースが、そもそも存在しない。**

## 1. 🔴 1回目の実行は中止条件3 で自分を破棄した（データの穴）

1回目は登録どおり「`train_end` から42日前」で内側ホールドアウトを切り、
主判定窓 M が **661行**（登録線 1,000行以上）で**中止条件3 に当たって停止**した。

## 4. 🔑 なぜ対象レースが存在しないのか（計測器ではなく事実）

残差学習は `予測 = base_margin(市場) + AI補正` で、`base_margin` は**人気順位だけ**から
Zipf 近似で作る。実測（M 窓・seed 42）:

```
margin の SD 1.284 ／ base_margin の SD 0.873 ／ AI補正(ability) の SD 0.580
```

レース内の base_margin の差（1番人気と2番人気で約 0.9 logit）に対し、AI補正は
それを覆すほど大きくない。しかも AI補正は市場と**同じ向き**に出やすい。結果:

| M 窓・seed42（3,442レース） | 一致率 |
|---|---:|
| モデルの軸 == **ドリフト注入後の人気1位**（＝モデルが見ている人気） | **99.1%** |
| モデルの軸 == 確定人気1位 | 70.8% |
| モデルの軸 == AI単独（`ability_margin`）1位 | 31.2% |

**本番データでの独立確認**（`data/latest.json` の git 履歴・2026-10-03〜11-08 の15開催日。
`pop` は生成時点のオッズ由来＝`base_margin` が使うのと同じ人気）:

```
10/03 23R 100% / 10/04 23R 100% / 10/10 23R 100% / 10/11 23R  96% / 10/12 23R  96%
10/17 35R 100% / 10/18 34R 100% / 10/24 35R  97% / 10/25 35R 100% / 10/31 23R  96%
11/01 23R 100% / 11/07 35R 100% / 11/08 34R 100%  …
→ ◎ == 人気1位 96〜100%、**4番人気以下は全日 0本**
```

記録にある「残差学習では RL1 がほぼ市場上位人気に収束する」（2026-08-20）を、
**「上位人気」ではなく「1番人気そのもの」まで詰めた**のが今回の数字。
🔑 **市場とずれるのは ◎ ではなく `AI単`（`solo_rank`、一致率 31.2%）のほう。**

### 🔴 `logic2026/RESULTS.md` §3 の表の読み方を訂正する

あの表（◎の人気 1番 1,773 / 2〜3番 580 / 4番以下 303）は
`va['f_popularity']`＝**確定人気**で帯を作っている。モデルが見ているのは
ドリフト注入後の朝オッズ相当の人気なので、**あの303本は「AI が市場と食い違ったレース」ではない。**
同じ2026年の窓を本カードの定義（モデルが見ている人気）で切ると **1〜3本**しか無い。

正しい読み方: **「朝の1番人気が、確定までに4番人気以下まで売られたレース」**。
そこで的中率 23.4% / 回収率 57.9% になるのは、AI の弱点ではなく
**市場が朝から大きく評価を変えたレースは荒れる**という市場側の事実。
⚠ だから「AI が強気な側ほど悪い」という既存の6回の再現が否定されるわけではない
（それらは `ability_margin` や `solo_rank` など**市場と独立な順位**で測っている）。
否定されたのは**この表を「◎と市場のずれ」として読むこと**だけ。

## 5. 対照群

| | 結果 | |
|---|---|---|
| **B-1 注入の復元（算数の検算）** | 注入前 85.09% → 注入後 105.09%  差 **20.0pt**（許容 1e-3） | ✅ |
| **B-2 オラクル（替えるレースで軸を実際の1着馬に）** | Δ的中率 +0.00pt = 期待 +0.00pt（K=1 なので構造的に 0）| ✅（ただし**検出力が無い**） |
| **A 無作為に同数 K を1番人気に替える×200回** | 帰無の Δ的中率 平均 −0.000pt・std 0.002pt・5〜95%点 [+0.00, +0.00]。実測 −0.030pt・並べ替え P=1.0000 | ✅（ただし**K=1 なので何も判定できない**） |

🔴 **対照群A・B-2 は「通った」が、K=1 では意味が無い。**
形式上は合格（帰無が0中心・算数が復元する）だが、**替えるレースが1本しか無いので
本物の効果があっても検出できない**。North Star #11 の「本物があったらこの計測器は
検出できるのか」に対する答えは **「この母集団では検出できない」**。
だから本カードの結論は対照群ではなく **基準4（N=0）と §4 の一致率**に乗っている。
