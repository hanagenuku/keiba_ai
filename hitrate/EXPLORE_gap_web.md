## 結果

| 順位付けの精度（AUC） | |
|---|---|
| 市場なしの AI（指数なし） | 0.7560 |
| 市場なしの AI（指数あり） | 0.7787 |
| 指数だけ | 0.7849 |
| 市場 | 0.7957 |

- **AI と市場の差 0.040 のうち、指数が 57% を埋める。**
- AI と市場のずれの分散で見ると: 既存の特徴量 30.1% → DB の未使用変数を足して 33.5% → **指数を足して 54.8%**（+21.2pt）。説明できない残りは 45.3%。
- 残った 45% も、まだ結果を当てている（AI を固定したロジット係数 +0.62）。＝指数でも埋まらない情報が市場にはまだある。

## 読み方の注意

- 指数は市場とほぼ同じ向きを向いている（レース内の相関 **+0.89**）。「埋める」と言っても、市場がすでに知っていることを AI が後から知る形で、市場の先を行く情報ではない（North Star #9。儲かる根拠にはならない）。
- 指数だけの AUC（0.785）が、指数を入れた市場なしモデル（0.779）より高い。2024-08 までの学習では指数を使い切れていない。
- 本番モデルは 2026-11-13 に指数を採用済み（`websig/RESULTS_CONFIRM_kayochin.md`）。この測定は「市場を使わない AI」での話で、本番（市場が土台）での上乗せは +0.0026 AUC と小さい。両者は矛盾しない（本番は土台の市場がすでに同じ情報を持っている）。
