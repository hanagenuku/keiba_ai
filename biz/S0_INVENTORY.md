## 2. 商品価値の評価（STEP 2）

判定は**すでに測った OOS 実測**だけに基づく。測っていないものは「未検証」と書く。

### 2-1. 🟢 商品として出せる（市場に対する優位が実測されている）

| 項目 | 実測された優位 | 商品としての言い方 |
|---|---|---|
| **見送り判断**<br>`conf` = 軸の3着内確率 | **3,560レース**で「当てやすさ」の AUC **0.6041** vs 市場のみ **0.5708**。しかも**市場の自信度で4分割したどの層でも効く**（0.586/0.577/0.584/0.592）＝オッズに無い情報を持つ（2026-08-18②） | 「このレースは荒れやすい／読みやすい」。**低いから見送る**として使う |
| **危険な人気馬**<br>市場1番人気 × `ability_margin` 下位 | walk-forward 5窓。**市場1番人気のうち**、市場を見ないAIが6位以下に置いた馬は複勝率 **68.5% → 51.4%**（N=242頭・73開催日）（2026-08-29） | 「この1番人気はAIの見立てでは走らない」。⚠ **母集団は「市場1番人気」に限定して書く** |

🔑 この2つだけが「市場より正しい」と言える。**どちらも回収率の主張を必要としない。**

### 2-2. 🟡 情報としては出せる（優位は主張できない）

| 項目 | 実測 | 出し方の制約 |
|---|---|---|
| `ability_breakdown`（15カテゴリSHAP） | **信頼度の予測力はゼロ**（3窓26,340頭で −0.0038・2026-08-27） | 「なぜその順位か」の**説明**として出す。「内訳が良いから買える」とは書かない |
| `cmt`（自然文コメント） | 未測定 | そのまま出せる。**最も安く差別化できる資産** |
| `solo_rank`（AI単）と `pop`（市場）の差 | 2026-08-31：`corr(gap, 符号つき誤差) = −0.1213`＝**市場と食い違うほどその方向に間違っている** | 「市場との違いの可視化」として出す。**「AIが強気だから買い」は書けない**（3回否定） |
| `fit_rank`（適性） | Gate 0 は通過（ρ̄0.49・τ̄0.55）が、Step 1 で結果への効果の **67〜81%が市場評価の言い換え**（2026-09-22） | 「今回条件への当てはまり」として出す。儲かる根拠にしない |
| `rl_accuracy` / `divergence_analysis` | 実測値そのもの | **固定ルールで全件出す**。期間や帯を選び直さない |

### 2-3. 🔴 商品に出さない

| 項目 | 理由 |
|---|---|
| `value_horses` / `ev_direct` / `sim_ev` | **EVは3回否定**（2026-07-05・07-30・08-31）。本番8,546頭で EV>=1.0 は回収 **57.9%**、買わない側が **75.0%** で選別が裏返る。画面からは2026-08-09に削除済み。**商品に復活させない** |
| `bias`（馬場バイアス） | **4回否定**（2026-08-06 −0.0005 / 08-26 / 08-27 / 09-15） |
| `mark`（穴馬） | 2026-09-01：6人気以下のAI最上位を複勝で買うと72.9%。**市場人気最上位を選ぶと73.0%で同じ**＝AIは何もしていない |
| `chaos_level` | `stats.json` の `rl_accuracy.by_chaos` で **B が 3着内率 10.6%（N=66）** と A(67.6%)・C(57.4%) から極端に外れる。**定義か集計のどちらかが壊れている疑い**。原因が分かるまで出さない |
| 回収率を根拠にした一切の訴求 | 100%超は一度も確認できていない |

## 3. この棚卸しから出る結論

1. **「AI予想」そのものは商品にならない。** RL1 の3着内率 55.2%（911R）は立派だが、
   市場1番人気とほぼ同じで（複勝AUC 0.8252 vs 市場 0.8248）、しかも同等品が**無料**で
   大量に配布されている（→ `S0_MARKET.md`）。
2. **市場に勝っている量は2つだけ**で、どちらも「**買う**」ではなく「**買わない／疑う**」側。
   見送り判断（`conf`）と危険な人気馬（`ability_margin`）。
3. **「なぜ」を出す材料はすでに全部ある。** `ability_breakdown` の15カテゴリと `cmt` の自然文。
   新しく作る必要があるのは**公開スナップショットの保存だけ**。
4. **正直に出すと数字は地味になる。** 公開できる実績は複勝回収 79〜86% 帯で、
   「回収率150%」を掲げる競合より短期的な購入率は下がる。**これを承知で選ぶ**のが前提。
