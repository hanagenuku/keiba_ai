# 事前登録カード: ☆が出たレースで、◎と買い目の軸を☆の馬にする（HONMEI-STAR）

2026-11-17・博士「☆と◎は同じになってもいい。☆と◎は別々に測っていて、たまたま重なることもあるしそうでないこともある。1.をすすめて」
（1. ＝ ☆が出たレースだけ、軸を☆の馬にする）。2026-11-11 の「◎と☆は別扱い」をユーザーが改めた。

🔴 これは採否を決めるカードではない（決定はユーザーが済ませた）。**実装の前に、組み合わせ馬券で何が起きるかを測り、止める条件に当たらないかを確かめる**ためのカード。
🔴 測定は1回。結果を見てから期間・構成・止める条件を動かさない。

## 何を測るか

これまで☆の差し替えは単勝・複勝でしか測っていない（`hitrate/RESULTS_STAR.md` §4: 複勝の的中率 +16.5〜+21.2pt・複勝回収 −0.45〜+2.00pt）。
**勝負コース（馬連・ワイド・三連複・三連単）を☆軸にしたときの数字は一度も読んでいない**ので、それを測る。

## データ

- ☆: 本番と同じ作り方のモデルを、**各窓の手前までのデータだけで学習**したもの（`hitrate/eval_star.py` の 2026年の窓 V2・V3、シード42、τ=0.60）。
  本番の☆モデルは 2026-11-08 までで学習しているので過去に当てるとカンニングになる。だから使わない。
- 相手・オッズ・推奨の判定: 本番の `keiba.db` の `race_predictions`（`rl_rank`・単勝オッズ）。払戻: `race_dividends`。
- 期間: 2026-06-27〜11-08（組み合わせ馬券の払戻がある期間 ∩ ☆の窓）。
- 対象: **☆が出て、かつ☆の馬が今の◎（AI+市 1位）と違うレース**（＝差し替えが起きるレース）。全レースと推奨レース（`conf >= 66`。判定は今の◎のまま変えない）。

## 腕

- 現行: 軸＝AI+市 1位。
- 新: 軸＝☆の馬。相手は本番と同じ `split_partners`（軸を除いた `rl_rank` 順・固め3＋中穴2）。今の◎は相手の筆頭に入る。

堅実コース（単勝・複勝 各1点）と勝負コース（馬連5＋ワイド2＋三連複10＋三連単20）の両方。

## 測る量

コースごとの 的中率／回収率／最高配当1本抜き／元本割れ率、新−現行の差とレース単位ブートストラップ2,000回の95%区間・SE。

## 止める条件（どれか1つで実装しない・ユーザーに戻す）

1. 全レースで、**勝負コースの的中率**の差の95%区間の上端 < 0（はっきり下がる）。
2. 全レースで、**複勝の的中率**の差の95%区間の上端 < 0（これまでの測定と逆を向く）。
3. 差し替えが起きるレースが50本未満（測れない）。

回収率は報告だけ（SE が 10pt を超えたら「測れない」と書く）。

## 言わないこと

☆軸で「回収率が上がる」とは書かない。
