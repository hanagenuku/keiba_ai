# S5: 有料記事が売れるまでの計画と、続けるための決めごと（案・未決定）

> 作成 2026-11-17。ユーザーの問い:
> ①フォロワーがどの程度集まれば有料記事を出してよいか ②フォロワーを増やすには
> ③どこまで正直に実績を出すか（嘘は不可。出さなくてもよい情報は出さなくてよい）
> ④売れるまでの詳細な計画と、継続するための手段を今のうちに決めておきたい。
>
> 🔴 これは**案**。決めるのはユーザー（§8）。実行（アカウント開設・投稿・販売）はまだ何もしていない。
> 🔴 本番の予想・買い目・表示には触れない。AI 精度の話と混ぜない（`biz/README.md`）。
> 前提は `S2_ACQUISITION.md`（棚・手数料・規約ゲート）と `CRITERIA_SALES_01.md`（最初の販売実験）。
> 私は弁護士ではない。法律に関わる箇所は一般的な整理で、最終判断はユーザーか専門家。

---

## 1. 結論（先に）

1. **有料を出す条件はフォロワー数にしない。「無料記事が実際に読まれている量」と「公開した実績の日数」で決める。**
   目安は 直近4週の無料記事の閲覧が合計500以上 かつ 公開実績が8開催日以上（§2）。そのとき X のフォロワーは数百〜1,000人程度になっている見込み（推定）。
2. **集客の柱は「的中自慢」ではなく「競馬の定説をデータで検証した結果」と「全予想の全結果を消さずに出すこと」。** 回収率の棚では勝てない（`S2` §1）が、この2つは他の予想家が持っていない。
3. **実績は「公開を始めた日以降の全件」だけを名乗る。** 出さなくてよい情報は多いが、**良い部分だけを選んで出すのは「出さない」ではなく「誤認させる」側**に入る（§4）。
4. **続けるための要は時間の上限。** 週90分を上限にし、それを超える作業は自動化するか、やらない（§6）。

---

## 2. どの程度集まれば有料記事を出してよいか

### フォロワー数を条件にしない理由

- X の通常投稿が届くのはフォロワーの一部だけで、フォロワー数と届く数は比例しない（出典 A）。
- 外部リンクつきの投稿は表示が減る（出典 B・C）。note へ人を送れるかは、フォロワー数より投稿の作りで決まる。
- 測りたいのは「買う人がいるか」。それを決めるのは**無料記事を読んだ人の数**で、`CRITERIA_SALES_01.md` もそこを基準にしている（閲覧300未満なら「集客の失敗」で商品の評価は保留）。

### 条件（案）

| 条件 | 線 | 根拠 |
|---|---|---|
| A. 無料記事の閲覧 | **直近4週の合計 500 以上**（1開催日あたり約60） | 販売実験の合格線は4週で購入10件。購入率を2%と置くと 10 ÷ 0.02 = 500（2%は仮置き・未検証。`biz/README.md` ⑥） |
| B. 公開実績 | **8開催日以上**（約4週）を全件・結果つきで公開済み | 買う人が確かめられる実績が無いまま売らない。`prediction_archive/` はまだ0件 |
| C. 規約ゲート | note の規約確認（G1）・特商法表記の決定（G2）が済んでいる | `CRITERIA_SALES_01.md` §0 |

A・B・C が揃ったら販売実験（4週・500円/日・測定1回）を始める。

**フォロワー数の目安（推定・条件ではない）**: 1開催日60閲覧を X から送るには、リンクを開く人が投稿を見た人の1〜3%として 2,000〜6,000 表示/日が要る。開設直後のアカウントでこれが安定するのは、経験的に数百〜1,000フォロワーあたり。**この数字は測っていない推定**なので、条件は A の実測に置く。

### 早く出しすぎた場合・遅すぎた場合

- 早すぎ: 閲覧が足りず「集客の失敗」と判定され、4週の測定を1回使ってしまう（測定は1回の約束）。
- 遅すぎ: 無料で出し続ける期間が延び、時間だけ使う。→ §5 に「12週で条件Aに届かなければ集客の方法を変える」を置く。

## 3. フォロワーを増やすには

### 持ち物と制約

| 使えるもの | 使えないもの |
|---|---|
| 毎開催日の予想・記事が自動で出る | 回収率100%超の実績（大規模な検証で一度も確認できていない） |
| 公開後に書き換えられない記録（`prediction_archive/`） | 陣営コメント・調教・パドックの話（取得経路が無い） |
| 検証して否定した定説の蓄積（`CLAUDE.md` §4 に約80件） | JRA のレース・調教・パドック映像（2026-04 から YouTube 上の無断利用への対応が強化された。出典 D） |
| AI と市場の評価の違い・☆ | 博士の時間（最も希少。`S2` §3） |

### 柱を2本にする

**柱1（平日・週2本）: 「競馬の定説をデータで検証したら」**
すでに測り終えた結果を1本ずつ出す。新しい分析は要らない。例:
- 「不人気の逃げ馬はスローで残る」→ 実際は逆（前半が遅いと 17.2%、速いと 27.3%）
- 「期待値1以上を買えば勝てる」→ 3回測って全部負け
- 「1番人気なのにAIが評価しない馬は危険」→ 3着内に来ないとまでは言えなかった
- 「データが増えればAIは当たるようになる」→ 2年で頭打ち

当たり外れに左右されず、平日に出せて、後から読まれても古くならない。**外れた仮説を正直に出すこと自体が、他の予想家との違いになる。**
⚠ 「だからこう買えば勝てる」とは書かない（North Star #9）。結論は「この定説は当てにならない」まで。

**柱2（開催日）: 予想の事前公開と、全件の答え合わせ**
- 朝: 無料記事の公開を告知（本文は投稿の中に書き、リンクは返信欄に置く。出典 B・C）
- 夜: その日の全予想の結果を、外れも含めて同じ形で出す
- 月曜: 先週の全結果のまとめ（期間を選ばない）

### X の運用（最小限）

- プロフィールと固定投稿で「何のアカウントか」「全成績はここ」を1行ずつ。
- 小さいアカウントは投稿より会話が効く（出典 E）。開催日に競馬の話題へ返信を数件。
- 的中画像だけの投稿、フォロー返し目的のタグ、プレゼント企画はやらない（集まるのは買う人ではない）。
- note の棚（回収率順）には並べない（`CLAUDE.md` §3）。

### YouTube は後回し

映像が使えないので、図と声だけの解説になる。1本あたりの手間が X の10倍以上かかる。**最初の販売実験が終わるまで手を出さない**。やるなら柱1を週1本、図で見せる形。

## 4. どこまで正直に実績を出すか

### 線の引き方

「出さない」は自由。ただし**実績について何かを出すなら、都合の良い部分だけを出してはいけない**。
景品表示法は、実際より著しく優良だと誤認させる表示を禁じている（出典 F）。数字が本当でも、選び方で誤認させれば対象になりうる。有利な点だけ告げて不利な点を故意に告げない売り方は、消費者契約法でも問題になる。

| | 内容 |
|---|---|
| **出さなくてよい** | モデルの中身・特徴量・学習方法／開発の経緯・失敗の詳細／AUC などの研究指標／売上・購入者数／個人情報（特商法の表記は別。§8） |
| **出すなら全部出す** | 的中・回収の実績。期間は**公開開始日から今日まで**、対象は**公開した全レース**。券種別に 的中率と回収率を並べる |
| **やらない** | 当たった週・当たった券種・当たったレースだけを見せる／的中画像だけを流す／的中率だけ出して回収率を伏せる／公開前の成績を「実績」として名乗る／外れた記事を消す・書き換える |

### いま手元にある数字の扱い（重要）

成績ページには 2026-06-27 以降の推奨レース 272本の集計があり、**全券種の合計は回収率 114.6%** と出ている。
これを宣伝に使わない。理由は3つ:
1. **高配当1本で決まっている**。最高配当の1本を除くと 三連複 169.3% → 98.5%、上位3本を除くと 53.9%。単勝・複勝は 97.5%・85.4%。
2. 272本は小さい。同じ形の数字が約2,000レースで 71.3% に落ちた前例がある（North Star #7）。
3. **この期間の予想は事前に公開していない**。読む人が確かめられない成績は実績として名乗らない。

→ **実績は公開開始日からゼロで数え直す。** 過去分を見せる場合は「公開前の記録・参考」と明記し、上の1〜2も同じ場所に書く。

### 文言の型（案）

- プロフィール: 「全予想と全結果を公開。外れも消しません。回収率は100%を超えていません」
- 有料記事の冒頭: 「この記事は予想の根拠を読むためのものです。利益を保証するものではありません」
- ☆: 併記文は省略しない（`CLAUDE.md` §3）。成績は15開催日たまるまで名乗らない。

「回収率は100%を超えていません」と自分から書くかは博士の判断（§8）。書かなくても違反ではないが、**全成績ページへのリンクは必ず置く**。

## 5. 売れるまでの計画

| 段階 | 期間 | やること | 次へ進む条件 | 止める・変える条件 |
|---|---|---|---|---|
| **0. 準備** | 1〜2週 | note 規約を読む（G1）／特商法表記を決める（G2）／X・note のアカウント／プロフィール・固定投稿／全成績の公開ページ／投稿文の自動下書き | G1・G2 が済み、公開の配管が1日通る | G1 で不可なら販売場所を変える |
| **1. 無料期** | 4〜12週 | 開催日: 朝の告知・夜の全結果。平日: 検証ネタ週2本。**有料にする予定の記事も無料で全文出す**（「◯月から推奨レースは有料」と最初から書く） | §2 の A・B・C | 12週で直近4週の閲覧が150未満 → 柱と投稿の形を変える（商品は変えない） |
| **2. 販売実験** | 4週 | `CRITERIA_SALES_01.md` のとおり（500円/日・指標6つ・測定1回）。無料記事は続ける | 購入10件以上 かつ 2回以上買った人が3人以上 | 同カード §6・§7 |
| **3. 継続の形** | — | リピートが確認できたら月額（note メンバーシップ）を検討 | — | リピート0なら月額に進まない |

- 段階1で有料予定の記事を無料で出すのは、**売る商品そのものの実績**を作るため。質を落とした無料版は作らない（`CRITERIA_SALES_01.md` §2）。
- 段階3の手数料: メンバーシップ・有料記事は10%、定期購読マガジンは20%（＋決済5〜15%・振込270円。出典 G）。月額にするならメンバーシップ。
- note 全体ではメンバーシップの売上が前年比80%以上伸びている（出典 H）。ただし競馬予想での数字ではない。

### 毎週記録する数字（6つだけ）

X: フォロワー数・表示回数（週合計）／note: 無料記事の閲覧（開催日ごと）・スキ・フォロワー／有料開始後は `CRITERIA_SALES_01.md` の M1〜M6。
🔴 的中率・回収率をこの表に入れない（AI 研究の指標。混ぜない）。

## 6. 続けるための決めごと

1. **時間の上限: 週90分。** 開催日 15分×2日（朝の告知・夜の結果）＋平日 30分×2回（検証ネタ）。超える作業は自動化するか、やらない。
2. **自動化できる部分は私が作る（決定後）**: 朝・夜の投稿文の下書き／検証ネタの下書き（既存の結果文書から）／全成績の公開ページ／週次の数字の記録。博士の作業は「読んで直して貼る」だけにする。
   ⚠ 投稿の自動送信はしない（X の API は有料で、規約と誤投稿のリスクがある。まず手動）。
3. **外れた週の扱いを先に決める**: 結果は同じ形で出す。言い訳・削除・買い目の後出しをしない。連敗中も投稿の頻度を変えない。
4. **見る数字を分ける**: 続けるかどうかは §5 の6つの数字で決め、的中・回収で決めない。外れが続いても、閲覧が伸びていれば計画どおり。
5. **月1回だけ振り返る**: 6つの数字と「止める・変える条件」に当たっているかだけを見る。毎日は見ない。
6. **中止条件は `CRITERIA_SALES_01.md` §7 をそのまま使う**: 実績の数字を選び直したくなったら／「必ず」「勝てる」を書きたくなったら／公開後に書き換えたくなったら、止める。

## 7. この案が言っていないこと

- この計画で売れるとは言っていない。購入率2%・フォロワーの目安は仮置きで、測っていない。
- 「検証ネタ」に読者がつくかは未確認（`S2` §5 の「棚Bに客がいるか」と同じ未確認）。段階1がその測定になる。
- 法律上問題が無いと保証していない。景品表示法・特定商取引法・消費者契約法の整理は一般論。

## 8. 博士に決めてほしいこと

1. **名義**: 匿名（屋号）か実名か。特商法の表記は、継続して売るなら氏名・住所・電話番号の表示義務があり、実務では「請求があれば遅滞なく開示」として常時掲載を省く運用が案内されている（出典 I・`S2` §7）。
2. **note の規約を読む**（G1）。こちらからは読めない（403）。
3. **「回収率は100%を超えていません」と自分から書くか**（§4）。
4. **週90分の上限でよいか**。少なければ柱1を週1本に減らす。
5. **段階1で有料予定の記事を無料で全文出してよいか**（§5）。
