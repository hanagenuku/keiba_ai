## 1. いちばん重要な発見：note の競馬予想の棚は「回収率の数字」で並んでいる

第三者のランキング記事が挙げる note 競馬予想家 上位5名の実態:

| | 価格 | 販売頻度 | 掲載回収率 | Xフォロワー | 無料予想 |
|---|---|---|---|---|---|
| 1位 | 500円/1R | 基本毎日 | 172% | 8.7万 | あり |
| 2位 | 480〜777円/1R | 基本毎日 | 141% | 5.5万 | なし |
| 3位 | 400〜980円/1〜3R | 基本毎日 | 179% | 12万 | なし |
| 4位 | 100〜898円/1〜3R | 基本毎日 | 144% | 7.6万 | なし |
| 5位 | 498〜698円/1R | ほぼ毎日 | 132% | 11万 | なし |

一方こちらの実測（すべて `CLAUDE.md` の記録）:

```
複勝プール平均（控除率20%）                    80%
全レースの軸（複勝）                            84.2%
高自信の軸（複勝・N=3,560）                     93.4%   ← 最も信頼できる数字
単勝・高自信の軸（N=190レース・21開催日）        95.9%   ← North Star #7 の危険域
損益分岐                                       100%
```

🔴 **100%を超えた回収率は一度も確認できていない。** そして `biz/PHASE4_DESIGN.md` §22 で
「必ず勝てる」「回収率○○%保証」を書かないと自分で決めた（景品表示法・特定商取引法のリスク）。

⚠ 上表の 132〜179% は**アフィリエイト目的のランキングサイトの掲載値で検証されていない**。
だが**それが本当かどうかはこの考察にとって重要ではない**。重要なのは棚の形のほうで、
**買う人はその数字を見て選ぶ**という事実だけが効いてくる。

> 🔑 **結論: 同じ棚に並べたら必ず負ける。**
> 検証されていない「179%」に、検証済みの「100%未満」で勝つ方法は無い。
> 誇大広告をやめる判断（§22）は、同時に**棚Aから降りる判断**でもあった。
> それを引き受けたうえで集客を考える必要がある。

## 2. よって集客の問いは「どう宣伝するか」ではなく「どの棚に置くか」

| | 棚A：回収率で競う棚 | 棚B：「買わない／疑う」の棚 |
|---|---|---|
| 並ぶ場所 | note の競馬予想タグ・X の予想家 | 未確認（§5） |
| 比較軸 | 掲載回収率・的中実績 | 「今週どのレースを見送るか」「この1番人気は危ないか」 |
| こちらの持ち物 | **無い**（100%未満） | **実測で2つある**（下記） |
| 判定 | 🔴 入らない | 🟡 客がいるか未確認 |

棚Bで出せる、市場に勝っている実測は2つだけ（`biz/README.md` S0 と同じ）:

1. **見送り判断** — `conf`（軸の3着内確率）が「当てやすさ」を予測する AUC **0.6041**
   に対し、市場だけで作った自信度は **0.5708**（3,560レース）。
   市場の自信度で4分割したどの層の中でも効く＝オッズに無い情報を持っている
2. **危険な人気馬** — 市場1番人気のうち素のAIが6位以下の馬は複勝率
   **68.5% → 51.4%**（N=242・73開催日・walk-forward）

⚠ どちらも**「当てやすさ」であって「儲けやすさ」ではない**（North Star #9）。
商品として売れるとしたら「損を減らす道具」で、「勝てる予想」ではない。

## 3. X が唯一の現実的な入口だが、上位は 5.5万〜12万フォロワー

検索で確認できた業界の定番導線は
**「X で無料予想を出す → note / オンラインサロンへ誘導 → 有料予想を売る」**。

🔴 上表のとおり、**上位5人中4人が「無料予想なし」**。
つまり彼らは**フォロワーを先に作り終えてから有料に移している**。
フォロワー0から始める場合、最初にやるのは販売ではなく**無料の蓄積**になる。

⚠ ここが最大の制約。`CLAUDE.md`（2026-09-15）に
「**ユーザーは時間を割けないと明言している**」と記録がある。
週次の手作業が最も希少な資源なので、「毎週Xに無料予想を投げ続ける」は
**いちばんコストの高い選択肢**として扱う。

⚠ 用語の整理: `CLAUDE.md` の「**`x.com` は入れない**」は
**スクレイピング（取得）の禁止**であって、人が投稿することは別の話。
ここで検討しているのは後者なので規約違反ではない。

## 4. 数字（手数料は実測値）

note の手数料は 決済手数料5% → プラットフォーム利用料10% → 振込手数料270円/回。

```
1,000円を1本売る        手取り 約585円  （58.5%）
1,000円を10本売る       手取り 約8,280円
  500円を10本売る       手取り 約3,980円
```

🔑 **この金額はこの段階では意味を持たない。** S0 の設計どおり、
最初の実験（10人）で測るのは**購入率とリピート率**で、売上ではない。
1万円に届かない実験に「儲かるか」を問うのは North Star #7 と同じ誤り。

⚠ 逆に言えば、**価格を上げても解決しない**。市場の単価は 400〜980円/1レースで、
月額 550〜800円（netkeiba AI / SPAIA）が無料トライアル付きで存在する。
単発1,000円がそこに勝つ理由が無い（S0 で確認済み）。

## 5. 棚Bが棚として存在するかは未確認（次に調べること）

検索では「回収率を掲げる予想家」しか見つからなかった。
**「買わないレースを教える」「危険な人気馬を教える」を売っている人**を
1人も確認していない。これには2つの読み方があり、どちらかは分からない。

| 読み方 | 含意 |
|---|---|
| (a) 誰もやっていない＝空いている | 棚Bは差別化になる |
| (b) 誰もやっていない＝客がいない | 「買うな」に金を払う人はいない |

🔴 **(a) だと決めつけない。** 「競合がいないから勝てる」は、このプロジェクトが
何度も否定してきた「まだ試していないから効くはず」と同じ形をしている。
調べる価値はあるが、それは次のフェーズ（§8 P5）。

## 6. 規約ゲート①（note）— 読めていない。ただし観測はできた

🔴 **note の規約本文とコミュニティガイドラインは読めていない。**
`note.jp` / `terms.help-note.com` / `www.help-note.com` の3ドメインすべて **HTTP 403**
（2026-09-29 実測。S0 の時点と同じ）。UA を偽装して回避はしない。

検索で観測できたことは2つ:

- note 上に競馬予想家が **19名以上**ランキングされており、
  note は**公営競技系の有料note の決済プラットフォームとして機能している**
  → **カテゴリとして禁止されている形跡は無い**
- 実際にアカウント停止・売上没収の対象として挙げられているのは
  **「必ず儲かる」等の誤認を誘う表現**と**情報商材扱い**のほう

🔑 つまり実際のリスクは「競馬予想だから」ではなく「書き方」にある。
`biz/PHASE4_DESIGN.md` §22 の自己規制（誇大広告を書かない・外れた予想を消さない・
後出しで印を変えない）が、そのままこのリスク対策になっている。

🔴 **ただし「禁止されていない」ことを確認したわけではない。**
確実なのは**ユーザーが note にログインして規約とコミュニティガイドラインを読むこと**。
Claude が「他の人がやっているから良い」と判断しない。

## 7. 規約ゲート②（特定商取引法）— ほぼ答えが出た。判断はユーザー

- **反復継続して有料記事を売る場合、個人でも「販売業者」**にあたり、
  氏名・住所・電話番号の表示が法的義務になる
- 1回だけの販売なら義務が生じにくいとされる
- 実務では「**請求があれば遅滞なく開示する**」旨を明記して住所・電話番号の
  常時掲載を省略する運用が広く案内されている

🔴 毎週売るなら「反復継続」に該当する。これは**ユーザーの個人情報を出すかどうかの判断**
なので Claude が決めない。景品表示法（優良誤認）のほうは §22 の自己規制で対応済み。
