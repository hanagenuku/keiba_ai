# biz/ — 商品・販売の研究（AI研究とは分離する）

このディレクトリは **「競馬予想そのものを商品として売れるか」** を調べる場所。
`src/` の AI 研究（予測精度を上げる）とは**目的もKPIも分ける**。

⚠ **本番の予想ロジック・モデル・買い目・表示には一切触れない。**
`biz/` は `data/latest.json` / `data/stats.json` を**読むだけ**。書かない。

## 3つの研究を混ぜないルール

| 研究 | 問い | KPI | 置き場所 |
|---|---|---|---|
| AI研究 | 予測は良くなるか | AUC・回収率・OOSの持ち越し | `src/` `*/CRITERIA*.md` |
| 商品研究 | 読む人にとって価値があるか | 購入率・リピート率・何を価値と答えたか | `biz/` |
| 販売研究 | 無料→有料→継続が回るか | 閲覧数・遷移率・継続率・月間利益 | `biz/` |

🔑 **AUC が 0.001 上がっても商品価値が上がる根拠にはならない。**
逆に、AI と市場の食い違いを分かりやすく説明できれば、**精度が1ミリも変わらなくても**
商品価値は上がりうる。この2つを同じ文書で論じない。

## 絶対にやらないこと（ユーザー指示・2026-09-28）

1. 売れそうだからといって**後から都合の良い実績を作る**
2. **回収率の高かった期間だけ**を宣伝する
3. AIが市場を上回っていないのに「**AIだから勝てる**」と宣伝する
4. **予想公開後に内容を変更する**
5. 売れなかった理由を「AI精度が低い」と決めつける（価格・商品内容・集客・信頼性を分離する）
6. **販売システムを先に大規模開発する**（まず手作業で売れるか確認する）

🔴 **「必ず勝てる」「AIだから儲かる」「高回収率」を商品価値の中心に置かない。**
回収率100%超は一度も確認できていない。これは自主ルールであると同時に
**景品表示法・特定商取引法上のリスク回避**でもある（根拠 → `S0_MARKET.md` §3）。

## 7つの問いへの回答（結論のみ。根拠は各文書）

| # | 問い | 回答 |
|---|---|---|
| ① | 商品として現実的か | 🟡 **条件付き**。「AI予想」としては**現実的でない**（無料で同等品が31サイト以上ある）。「**買わないレースの判断とその理由**」としてなら成立の可能性がある |
| ② | 最大のボトルネック | 🔴 **集客**。次に「無料AIとの差」。**AI精度ではない**（精度を上げても無料勢と同じ棚に並ぶだけ） |
| ③ | 何を商品化できるか | ①見送り判断（`conf`・市場に勝つ唯一の実測量）②危険な人気馬（`ability_margin`）③評価内訳（`ability_breakdown`）④レースコメント（`cmt`・既に自然文で出ている）⑤市場との順位差 |
| ④ | 差別化 | 「**なぜ**」と「**買わない**」。無料AIは買い目を出すが理由を出さない。競合調査記事自身が「透明性がない」と指摘している |
| ⑤ | 最初のMVP | **1日1本の有料記事 500円**。無料側に「見送りレース一覧＋1レース全文」を置く。新規開発は**公開スナップショットの保存1点だけ** |
| ⑥ | 最初の10人 | X→無料記事の導線を毎開催日。購入率2%なら**約500閲覧が必要**＝現実には**4〜8週** |
| ⑦ | 成立しないと判断する時点 | `CRITERIA_SALES_01.md` §6 に事前登録済み。**閲覧300以上あって購入2件以下**なら商品・価格の失敗。**閲覧300未満**なら集客の失敗で商品の評価は保留（AI精度のせいにしない） |
