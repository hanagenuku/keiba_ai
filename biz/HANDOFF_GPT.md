## 1. 🔴 守ってほしい制約（これを外した提案は使えません）

### 表現の禁止
- 「必ず勝てる」「AIだから儲かる」「高回収率」を**商品価値の中心に置かない**
- 理由は誠実さだけではありません。**景品表示法（優良誤認）・特定商取引法のリスク**です
  （虚偽の的中実績・「的中率100%」等は実際に規制対象）
- 回収率は **100%未満の実数のまま**出す（複勝79〜86%・控除率20%と併記）

### やらないこと
1. 売れそうだからといって**後から都合の良い実績を作る**
2. **回収率の高かった期間だけ**を宣伝する
3. AIが市場を上回っていないのに「AIだから勝てる」と宣伝する
4. **予想公開後に内容を変更する**
5. 売れなかった理由を「AI精度が低い」と決めつける（価格・商品内容・集客・信頼性を分離する）
6. **販売システムを先に大規模開発する**（まず手作業で売れるか確認する）
7. **代行購入・配当の分配**（刑法185〜187条の賭博・富くじに触れうる。情報提供のみなら適法）

### 提案してほしくないこと（**すべて大規模OOSで測って否定済み**）
以下を「馬券で勝つ方法」として再提案しないでください。数字は実測です。

| 案 | 実測された結果 |
|---|---|
| EV（AI確率×オッズ）で買う | 本番8,546頭で **EV≧1.0 は回収57.9%**、**買わない側(EV<1.0)が75.0%** で選別が完全に裏返る。3回否定 |
| 不人気馬をAIで拾う | 2,318R・31,978頭。6人気以下のAI最上位 72.9% に対し**市場人気最上位が73.0%**で同じ＝AIは何もしていない |
| 馬場バイアス | **4回否定**（AUC −0.0005 等） |

## 2. 🔴 いちばん重要な前提：市場（オッズ）の天井

パリミュチュエル方式のオッズは、**全投票者の見解を金額で重み付けして締切まで連続集約したもの**です。
つまり「集約された個人予想の完成形」が既にオッズです。

| | 複勝AUC |
|---|---|
| **市場人気だけ**（＝集約された群衆の見解） | **0.8248** |
| 市場あり AI（134特徴量） | **0.8252** |

差 **+0.0004**（8,543頭）。別年・新規学習モデルでも **+0.0009**（46,027頭）。
さらに log-loss ベースの継続KPIでは **AIが市場に負けています**：

```
898レース・11,546頭   AI logloss 0.2374  vs  市場 0.2244  → delta +0.013 ＝ 市場優位
```

🔑 **「AI予想の精度」を売り文句にできません。** これは実測です。

## 3. ✅ それでも市場に勝っている量が2つだけある（どちらも「買わない／疑う」側）

| 資産 | 実測された優位 |
|---|---|
| **① 見送り判断**（レースの当てやすさ） | 「このレースは当てやすいか」の判定AUC **0.6041** vs 市場のみ **0.5708**（**3,560レース**）。しかも**市場の自信度で4分割したどの層でも効く**（0.586 / 0.577 / 0.584 / 0.592）＝オッズに無い情報を持っている |
| **② 危険な人気馬** | **市場1番人気のうち**、市場を一切見ないAIが6位以下に置いた馬は複勝率が **68.5% → 51.4%** に落ちる（walk-forward 5窓・N=242頭・73開催日） |

⚠ ②は**母集団を「市場1番人気」に限定**して書かないと嘘になります（全馬で見ると逆の絵が出ます）。

⚠ ①も**当てやすさであって儲けやすさではない**：自信度の最上位帯でも複勝回収は **91.2%**（最下位帯79.0%）。
だから「高いから買え」ではなく「**低いから見送る**」向きに使います。

### そして「なぜ」の材料はすでに全部出力されている
- **評価の内訳**：AIの市場非依存スコアを15カテゴリにSHAP分解した値（騎手 / スピード能力 / コース適性 / 実力レーティング / 近走成績 …）
- **自然文のレースコメント**：既に日本語で生成済み（例：「馬場は時計遅め。スロー想定(49%)で逃げ・先行に有利な流れ。◎の脚質はこの展開に噛み合う。やや拮抗したメンバー構成。」）

🔑 **新規開発はほぼ不要。すでに出ているものを並べ替えるだけ。**

## 5. 法務（調べた範囲・出典は消費者庁と複数の法律情報源）

- **有料の競馬予想情報の販売そのものは適法**。ただし「予想情報の提供のみ」で、購入者自身がJRA等で馬券を買う形が最も安全
- **運営が資金を預かって代行購入する・配当を分配する**と刑法185〜187条に触れうる → **絶対にやらない**
- **過去の的中実績や利用者の声を偽る**表示は**景品表示法の優良誤認**にあたりうる
- 「的中率100%」「必ず勝てる」は**特定商取引法**上も問題になりうる
- **個人であっても要件を満たせば特商法上の「販売業者」**。インターネット通販では広告画面から**事業者の氏名・住所・電話番号**へ容易に到達できる必要がある
  → 🔑 **いきなり自前サイトで直販すると個人情報の開示が必要になりうる。だから最初はプラットフォーム経由に限定する**

⚠ **未確認**：note（等）の利用規約本文は HTTP 403 で読めませんでした（Zendeskがブラウザ以外を拒否）。
「競馬予想の有料販売が規約上OKか」は**私（人間側）が確認する必要があります**。
ただし note で競馬予想が有料販売されている事実自体は二次情報（2020年の予想盗用問題の報道）で確認済み。

### 最後の一文のルール（ここが商品の核）
「この条件ならこう判断する」と言う。「絶対買い！」とは言わない。
**AI信頼度から機械的に決め、手で書き換えない。**

| AI信頼度 | 最後の一文 |
|---|---|
| 70以上 | 「この条件なら◎から入って良い。AIの見立てでは読みやすいレース。」 |
| 60〜69 | 「買うなら◎。ただし強く勝負するほどの確信度ではない。」 |
| 60未満 | 「AIの見立てではこのレースは読みにくい。見送りを推奨する。」 |

参考：実データ（23レース）では信頼度は34〜74に分布し、**AI自身の推奨レースは信頼度66以上と1件も食い違いませんでした**。

### 実績の見せ方（固定ルール・後から選び直さない）
| 出す数字 | 実測 |
|---|---|
| AI1位の3着内率 | **55.2%**（911レース） |
| AI1位の勝率 | **31.0%** |
| AI2位・3位の3着内率 | 43.5% / 38.9% |
| AIと市場の比較 | **AIは市場に負けている（logloss delta +0.013）** ← これも隠さず出す |
| 買い目成績 | 複勝回収 **79〜86%**（控除率20%と併記） |

🔴 **「市場に負けている」ことを隠さない。** 隠して後で見つかると商品全体の信用が消えます。
出し方は「**AIが市場より正しいのは『どのレースが読みにくいか』と『人気馬のうちどれが危ないか』**」。

### 「予想を後から変更しない」を最大の信用材料にする
公開時点の予想（時刻・AI順位・推奨馬・買い目・評価理由）を**追記専用で永続保存**し、結果を見て書き換えない。
これが唯一の新規開発項目です（既存の出力ファイルは当日更新で上書きされるため）。

## 8. 🎯 GPTに聞きたいこと（ここから回答してください）

**§1 の禁止事項と §2 の市場の天井を前提にしたうえで**、次に答えてください。

1. **この商品定義（「買わないレースとその理由」1日500円）は、競合が無料で飽和している市場で成立しますか。**
   成立しないと思うなら、**同じ資産（§3の2つ＋評価内訳＋自然文コメント）で別の形**を提案してください。
2. **最大のボトルネックは集客だと考えています。** 個人が X＋note だけで4〜8週で有料購入10件に到達する、
   具体的で現実的な導線を設計してください（フォロワー0からの立ち上げ前提）。
3. **表示フォーマット（§6の実例）を、購入判断が起きる形に改善してください。**
   どの情報が余計で、何が足りないか。「最後の一文」の文言も含めて。
4. **「市場に負けている」という事実を正直に出しながら、それでも買いたくなる説明の言い方**を書いてください。
   （禁止表現を使わずに。ここが一番難しいと思っています）
5. **価格**：500円／980円／1,500円のどれから始めるべきか、理由付きで。月額を後回しにする判断は妥当か。
6. **見落としている商品形態はありますか。**
   例：買い目を売らない情報プロダクト、法人向け、データ提供、教育コンテンツ、コミュニティ など。
   ⚠ ただし **§1 の否定済みリストに戻る提案は不可**。
7. **「この事業は成立しない」と判断すべき基準**として、§7 の失敗条件は妥当ですか。抜けている観点は？

### 回答の形式のお願い
- **§1 の否定済みリストにある案を再提案しないでください**（すべて大規模OOSで測って否定済みです）
