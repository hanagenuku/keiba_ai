# P3-01 — 前走の「着順」と「内容」の乖離量は、市場残差を A→B で再現するか

> ⚠ **結果を見る前に書いた。** 数字を見てから X の定義・期間・基準を変えない。
> 事前登録の位置づけ: `mispricing/CRITERIA.md` §2 の **②-B**（開いていた唯一の枠）。
> ②-A（主効果131軸）は 2026-09-10 に **正の残差の上限 +3.23pt** で閉じている。

---

## 0. 一行の仮説

> **前走着順が示唆する評価と、前走内容が示唆する評価の乖離量が大きいほど、
> 予測時点の市場残差が正の方向に動く。**

方向: **② 市場の誤評価**

### 機序（符号と向きまで先に書く）

市場は前走の**着順**を額面どおり受け取り、**走破内容**による割増・割引が不足している。
したがって

- 着順より内容が良かった馬（X > 0）→ 市場は過小評価 → 残差は**正**
- 内容より着順が良かった馬（X < 0）→ 市場は過大評価 → 残差は**負**

**期待する符号: β > 0**（A期間・B期間とも）。

### 2026-08-18 の回顧と何が違うか

| | 2026-08-18（閉じた） | P3-01（今回） |
|---|---|---|
| 対象 | 「前走10着以下 × 上がり上位20%」という**セル** | **連続量 X 1本** |
| 測ったもの | そのセルの市場残差と複勝回収 | **X → 市場残差の傾き β** |
| 期間 | 学習2023-24 → 評価2025〜（片方向） | **A で β を推定 → B で固定仕様のまま評価** |
| 危険 | 閾値（10着・20%）を後から動かせる | 閾値が存在しない |

同じ材料（前走着順・上がり順位）を使うこと自体は問題にしない。
**「特定条件のROI」から「乖離量→市場残差の連続的な関係が A→B で持ち越すか」に問いを変える。**

---

## 1. X の定義（**ここで固定する。以後A/Bを通して一切変えない**）

各馬の**直前の1走**（date が当該レースより厳密に前で、最も新しいもの）から:

```
n_prev      前走の出走頭数（history.db の race_id ごとの行数で数える）
place_prev  前走の着順
agari_prev  前走の上がり3F順位

rank_pct    = 1 − (place_prev − 1) / (n_prev − 1)     … 1着=1.0 / 最下位=0.0
content_pct = 1 − (agari_prev − 1) / (n_prev − 1)     … 上がり最速=1.0 / 最遅=0.0

X_raw = content_pct − rank_pct                        ∈ [−1, +1]
X     = X_raw − （そのレース内の X_raw の平均）        ← 主仕様（レース内中心化）
```

### なぜ中心化するか

市場残差はレース内で和が **≈0 に構造的に固定**される（2026-09-15 で実測・
`zansa/CRITERIA.md`）。したがって X のレース定数成分は原理的に傾きへ寄与できない。
中心化しておけば β が「**レース内で X_raw が 1 高い馬**」という一義的な意味を持つ。

⚠ 生の `X_raw` での β も**ログには出す**が、**判定には使わない**。
どちらが良かったかを後から選ばないために、ここで主仕様を中心化版に固定する。

### 3条件（`NEXT_PHASE_PLAN.md` の ② 着手条件）の確認

| 条件 | 判定 |
|---|---|
| 1. 予測時点で計算できる連続量か | ✅ 前走の確定結果のみ。閾値・セルを持たない |
| 2. レース内で変化するか | ✅ 馬ごとに違う（中心化後の std をログに出す） |
| 3. carryover を一次基準に置くか | ✅ §3 が Primary |

### 禁止情報（**実行可能な assert にする**）

`assert_no_future_access(row)` が以下を確認し、1件でも破れば**結果を印字せず中止**:

1. X の計算に使う前走の `date` < 当該レースの `date`（等号も不可）
2. X の計算に**当該レースの**列（place / agari_rank / popularity / win_odds / 配当）が
   一切入っていないこと（使用列をホワイトリストで固定し、それ以外を参照したら落とす）
3. X に**当日の市場情報**（popularity / win_odds / odds_snapshots）が入っていないこと
4. 期待値テーブルが **A期間のみ**から作られていること（B の行が1件も入っていない）

## 2. 市場残差の定義（`zansa/z2.py`・F-1・②-A と同一。新しく作らない）

```
期待3着内率  A期間の「人気 × 頭数帯(~9 / 10-13 / 14~)」の実測表（各セル n>=100）
市場残差     res = (実測3着内(0/1) − 期待3着内率) × 100      単位 pt
```

- **期待値テーブルは A 期間だけで作る**（B の情報を混ぜない）
- B の評価にも **A で作った同じテーブル**を使う
- 検算として A / B それぞれで「実測3着内率 − 期待3着内率の平均」を印字する
  （±1pt 以内でなければ計測器を疑い、本測定に進まない）

---

## 3. Primary — A→B の carryover（連続X 1本なので rank correlation は使わない）

### 期間

| | 期間 | 役割 |
|---|---|---|
| **A** | 2023-01-07 〜 2024-12-31 | β を推定する |
| **B** | 2025-01-01 〜 2026-09-13 | **定義・向き・モデル仕様を一切変えずに**評価する |

重複なし。B を見て A の設計に戻ることはしない。

### モデル仕様（固定）

```
res_pt ~ β · X          （X はレース内中心化済みなので切片は ≈0）
推定     最小二乗
95%CI    レースを1ブロックとするブロックブートストラップ 2,000回
```

⚠ **素の OLS の標準誤差は使わない。** レース内の残差は「3着内は必ず3頭」の制約で
強く負に相関しており、独立を仮定した SE は**必ず狭すぎる**
（2026-09-15 実測: レース内残差の和の std 16.4pt / 独立なら 155pt）。
ブロックブートストラップにするのはこのため。

### 対象行（先に固定）

- 前走が存在し、`place_prev` / `agari_prev` / `n_prev` がすべて有効
- `n_prev` ∈ [5, 18] / 当該レースの頭数 ∈ [5, 18]
- `popularity` ∈ [1, 18]（99 は「不明」のセンチネル。除外）
- 芝・ダートのみ（障害は除外）
- **前走からの間隔で絞らない**（閾値探索の禁止）。分布はログに出すだけ

### 判定（4つすべてを見る）

| # | 基準 | 落ちたとき |
|---|---|---|
| 1 | **βA と βB が同符号**、かつ期待した向き（正） | 符号が違う → 「効果が無い」と読む。弱い効果とは書かない |
| 2 | **B の効果量**: X の 5%点→95%点で残差が動く量 `βB × (q95 − q05)` | §4 参照 |
| 3 | βB の 95%CI（ブロックブートストラップ）が 0 を含まない | 含む → 「B では確認できない」 |
| 4 | βA の 95%CI も 0 を含まない | 含む → A の時点で信号が無い。B も測るがそこで閉じる |

## 4. 実用水準（**探す前に**決めた ROI 換算）

`mispricing/CRITERIA.md` §1 の換算レートをそのまま引き継ぐ（新しく作らない）。

```
残差 +1pt ≈ 複勝回収 +4.8pt      （全馬 −0.37pt/69.9% と PL上位 +1.67pt/79.6% の2点較正）
100% に届くのに必要な残差        ≈ +6pt
```

| ライン | 効果量 `βB × (q95 − q05)` | 意味 |
|---|---|---|
| **採用** | **>= 6.0pt** | 控除率を超えうる。関門4（実配当での複勝回収）に進む |
| **信号** | **>= 2.0pt** かつ 基準3を満たす | 効果は実在するが単体では使えない。記録して閉じる |
| **不採用** | < 2.0pt | 「あっても使えない」と書いて P3-01 を閉じる |

⚠ 2.0pt の根拠: 2026-08-18 の回顧の上限が **+1.18pt**、`zansa/CRITERIA.md` の基準2が
実効 1.8pt 相当。**2pt は「既知の上限をようやく超える」という意味しか持たない。**

⚠ **事前の見通しを正直に書いておく**: ②-A で 131軸 × 10分位を測って正の残差の上限は
**+3.23pt**（`f_pl_rating` 最上位10%）だった。X の材料である `f_last1_rank` は単独で
上側 +0.83pt、`f_agari_ability` は +2.20pt。**この2つの乖離が +6pt に届く事前確率は低い。**
それでも測るのは、②-B が「主効果では見えない交互作用」を1〜2本だけ試す枠であり、
P3-01 がその1本目だから。**届かなかったときに「惜しかった」と書かない。**

## 5. Secondary — 「情報がある」と「市場に優位がある」を分ける

| | 測るもの | 意味 |
|---|---|---|
| **S1** | X → 実際の3着内（X 単独の AUC、人気で統制しない） | X に**予測情報**があるか |
| **S2** | X → 市場残差（＝ Primary） | 市場が X を**十分に評価していないか** |

- S1 と S2 が**両方**安定して初めて、馬券上の市場ミスとして検討する価値がある
- **S2 だけ強く S1 が無い場合は慎重に扱う**（残差の作り方の副産物である可能性を先に疑う）
- S1 も A/B 両期間で出す

⚠ **ラダー（X単独 / Market / Market+X / Market+AI+X）は P3-01 では走らせない。**
`NEXT_PHASE_PLAN.md` に書いたとおり、AI全体で +0.0009・シード std 0.0007 の世界で
`Market+AI+X` に有意差を求めると、X 単独に「134特徴量ぜんぶの2倍以上」を要求することになる。
②の主指標は残差であり、AUC ではない。S1 の単独 AUC だけを見る。

## 6. 対照群

### 対照群A（偽の相関が出ないか）

X を**レース内でシャッフル**して β を測り直す。

- 通過: |β_shuffle| が実測 |β| の **1/3 未満**、かつ 95%CI が 0 を含む
- 落ちたら: 計測器が壊れている。本測定の数字は読まない

### 対照群B（既知の効果を検出できるか）

**本データの β を見る前に通す。** 落ちたら本測定に進まない。

```
注入   res* = res + δ · X          δ は事前固定
δ      +3.0 pt と −3.0 pt の両方        （X 1.0 あたり）
期間   A・B の両方
合格   推定された β* が (β + δ) を ±20% 以内で復元する
```

⚠ **この設計の限界を先に書いておく**（GPT の指摘）: 「X で注入した効果を同じ X で
検出できた」だけでは、測定器の**独立性**は証明できない。確認できるのは
「このパイプラインが、既知の大きさ・向きの効果を正しい大きさで拾えるか」まで。

そこで**1回だけ**、別経路の変数でも確認する:

```
Z      馬番の偶奇を ±0.5 にした量（レース内で変動し、X ともほぼ無相関、結果とも無関係）
注入   res** = res + 3.0 · Z
合格   Z を説明変数にした回帰が β_Z ≈ +3.0 を復元し、
       かつ **同じデータで X を回帰しても β が動かない**（干渉しないこと）
```

これ以上は工数をかけない。

## 7. 成功・中止・予算（空欄にしない）

### 成功基準

基準1〜4 をすべて満たし、効果量が **>= 6.0pt**。
このときのみ関門4（実配当で複勝回収 N>=300・前後半・3本抜き・CI下限）に進む。

### 中止基準（どれか1つで止める）

1. 対照群B が復元に失敗 → **本データの β を読まずに中止**
2. 対照群A で β_shuffle が実測の 1/3 を超える → 中止
3. 市場残差の検算（§2）が ±1pt を外れる → 中止
4. `assert_no_future_access` が1件でも落ちる → **結果を印字せず中止**
5. 効果量が 2.0pt 未満 → 「あっても使えない」と書いて **P3-01 を閉じる**
6. βA と βB の符号が違う → 「効果が無い」と書いて閉じる

### 測定の予算

- **本測定は 1 回。**
- X の定義・期間分割・推定仕様を変えて測り直さない。
- 「中心化しない版の方が良かった」「前走間隔で絞れば出た」「上がり順位ではなく着差なら」
  —— これらは**すべて後知恵の探索**なので、P3-01 の結論には使わない。
  次の仮説として **P3-02 を新しく登録**してから測る（1本ずつ）。
- 対照群A・B は本測定の前に通すので予算に含めない。

# 🔴 実行後の追記（2026-09-17）— 対照群の合格式を2つ訂正した

**Primary（§3・§4）の判定基準は一切変えていない。** 訂正したのは §6 の対照群の
合格式だけで、どちらも**書いた時点で検出力を持っていなかった**:

| # | 当初 | 問題 | 訂正後 |
|---|---|---|---|
| 1 | 別経路の注入で `β_Z ≈ +3.0` | 「Z の素の効果は 0」という**測っていない仮定**。実際は A −1.03 / B −0.67pt あり、正常でも必ず落ちる | `注入後 − 注入前 = δ`（X 側の対照群Bと同じ形）|

🔑 **対照群の合格基準を書いたら、その閾値が統計量自身の SE より大きいかを先に確かめる。**

⚠ この訂正で結論が有利になっていない: 対照群Aが落ちた場合の帰結は「測れない」であって
