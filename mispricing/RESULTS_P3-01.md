## 4. 🔴 対照群の合格式を2つとも自分で書き損ねていた（本件最大の教訓）

**判定基準（§3・§4 の Primary）は一切変えていない。** 直したのは対照群の合格式だけだが、
どちらも**結果を見る前に書いたのに、検出力を持たない式**だった。

| # | 当初書いた式 | なぜ壊れていたか | 直した形 |
|---|---|---|---|
| 1 | 別経路の注入で **β_Z ≈ +3.0** | 「Z の素の効果は 0」という**測っていない仮定**を置いていた。実際は β_Z(注入前) が A −1.03 / B −0.67pt あり、**正常でも必ず落ちる** | **注入後 − 注入前 = δ** で判定（X 側の対照群Bは最初からこの形だった）|
| 2 | シャッフルで **\|β_shuffle\| < \|β\|/3** | 閾値 0.37〜0.43 が**推定量自身の SE（0.63〜0.70）より小さい**。完全に正常な計測器でも半分以上落ちる | **並べ替え分布 200回**で帰無が0中心かを見る（2026-09-16 `tenkai/g3.py` の既存標準に合わせた）|

🔑 **一般則にする: 対照群の合格基準を書いたら、その閾値が統計量自身の SE より大きいかを
先に確かめる。** SE より小さい閾値は「厳しい基準」ではなく「何も判定できない基準」。

⚠ **この訂正で結論が有利になっていないことの確認**: 対照群A が落ちた場合の帰結は
「計測器が壊れている＝測れない」であって「採用」ではない。訂正によって不採用が
採用に変わる経路は存在しない。実際 Primary は §1 のとおり効果量で落ちている。

⚠ **βの値は対照群Bの印字（期待 = β + δ）の時点で既に見えていた。**
その後に変更したのは上の2式だけで、Primary の4基準には触れていない。

## 5. Secondary S1 — 「情報がある」と「市場に優位がある」の分離

| | 測ったもの | A | B |
|---|---|---|---|
| **S1** | X 単独の AUC（今回3着内・人気で統制しない） | **0.4297** | **0.4269** |
| **S2** | X → 市場残差の傾き β（Primary） | +1.277 | +1.107 |

🔴 **S1 は 0.5 を下回る。** つまり X が高い（着順より内容が良かった）馬ほど、
今回の3着内率は**低い**。

機序ははっきりしている:

```
corr(X_raw, 前走着順パーセンタイル) = −0.355
前走着順 単独の AUC(今回3着内)     = 0.6901
上がり順位 単独の AUC(今回3着内)   = 0.6373
```

X は定義上「前走で負けた馬ほど高く」なる（負けた馬しか「着順より内容が良い」に
なりえない）。したがって S1 は **X の予測力ではなく「前走着順が悪い」を測っている**。

GPT の分類に当てはめると:

- X → 結果 は**負**
- X → 市場残差 は弱く正（CI は 0 を含む）

→ **S1・S2 のどちらも合格しない。** 「市場残差だけ強い」パターンですらない。

## 6. 副産物（追わない。記録だけ）

**馬番の偶奇に市場残差の差がある**（A −1.03pt / B −0.67pt、SE ≈ 0.31）。
