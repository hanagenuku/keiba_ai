## 2. AIと市場の乖離を連続量として測る

```
q     = 市場示唆確率（オッズから、レース内で正規化）
gap   = log(AIの確率 / q)      ← 連続な乖離量
```

### 統計的には、AIの乖離には情報がある

```
              市場のみ   +gap     増分    gapの係数
  3着内      0.7706   0.7756  +0.0050    +0.2887
  1着        0.8086   0.8099  +0.0013    +0.1818
```

✅ **係数は正で、AUCも上がる。「AIの乖離は純粋な雑音」ではない。**
これは事前の予想（2026-08-31③の `corr(gap, 符号つき誤差) = -0.1213` から
負を予想していた）と**逆**で、こちらの見立てが外れた。

⚠ ただし **+0.0050 AUC ≒ 回収率 +0.9pt**。必要な +12〜24pt には遠い。

### 🔴 経済的には逆。AIが強気なほど回収率が下がる

```
        gap帯      N     勝率    3着内   単勝回収  複勝回収  オッズ中央
AI弱気 (下位10%)   838   5.0%   13.6%    95.8%   75.1%    25.9
       やや弱気  1675   5.3%   15.9%    60.5%   78.3%    28.3
           一致  3349  11.1%   30.9%    76.4%   76.4%    10.0
       やや強気  1675   7.2%   25.0%    77.8%   76.3%    15.5
AI強気 (上位10%)   838   2.3%   11.0%    31.5%   66.6%    52.2
```

**AI強気の上位10%は単勝回収31.5%・勝率2.3%。** 2026-07-30 / 08-03 / 08-31 に続く
**4回目の同じ結論**（別経路・別データで再現）。

機序も同じ：AIの確率は softmax T=3.5 で平坦にしてあるので、
人気薄ほど `log(p_AI/q)` が大きくなる。**「AI強気」は実質「人気薄」を指す**
（オッズ中央値 52.2 vs 一致10.0）。

### 人気帯で統制すると符号が揃わない

```
     人気帯   gap低い側 単勝  gap高い側 単勝      差
    1番人気        92.7%       89.1%    -3.6pt
  2-3番人気        79.9%       64.6%   -15.3pt
  4-6番人気        64.1%       77.3%   +13.2pt
  7-9番人気        67.2%       71.3%    +4.1pt
 10番人気〜        74.4%       59.5%   -14.9pt
```

5帯中プラスは2帯だけで、単調でもない。
⚠ **4-6番人気の +13.2pt は 2026-08-03 に一度検証したセル**
（「4-6番人気 × 差+2以上 → 131.7%」）。当時 N=162 で事前登録5基準のうち
②N≥300・③前後半・④CI下限が未達で見送っている。**同じセルの再出現であり、新発見ではない。**

## 3. GPTの問いへの答え

> AIの乖離が実際の結果にほとんど寄与していないなら、AI側の改善探索はかなり縮小できる。
> 逆に、普段は市場が正しいが特定の条件でだけAI側に寄るなら、そこがエッジ候補になる。

**答え：寄与は「ある。ただし小さく、しかも符号が逆向きに働く」。**

| | |
|---|---|
| 統計的な寄与 | ✅ **ある**（3着内で +0.0050 AUC、係数 +0.29） |
| 経済的な寄与 | 🔴 **無い。むしろ負**（AI強気の上位10%で単勝回収31.5%） |
| 特定条件でAI側に寄る場所 | 4-6番人気で +13.2pt だが、**2026-08-03に検証済みで見送ったセル**の再出現 |

🔑 **「AIの乖離には情報があるが、その情報は配当に食われる」** が正確な言い方。
North Star #9（的中率と回収率は別物）の、これまでで最も明確な実例。

**→ Aルート（予測精度を上げる）の探索は縮小してよい。ただし「情報ゼロ」ではないので
「二度と触らない」ではなく「優先度を下げる」が正しい扱い。**

## 5. これで探索空間はどうなったか

```
A 予測精度を上げる
   → 測定0で AI軸=市場1番人気96%。今回、乖離の統計的寄与は +0.0050 AUC だが
     経済的には負。**優先度を下げる**（ゼロではない）
B 市場が値付けしていない情報
   B-1 オッズ時系列（75分前〜締切）  → 🔴 打ち切り済み
   B-2 オッズ盤の形                → 🔴 今回打ち切り
   B-3 パドック                    → 未確定（初日 N=193 で偏相関 +0.008±0.142）
   B-4 前日〜当日朝のオッズ         → 未検証（明確な仮説がある場合のみ）
C 控除率の回避（WIN5キャリーオーバー） → 構造確認のみ
```

**JRA公式データから作れる「市場の構造的な歪み」は、これで一通り測り終えた。**
F-3（246セル）・F-4（41セル）・F-1（枠）・今回（23セル・盤の形）を合わせて、
**約310セルを総当たりして、持ち越す歪みは1つも見つからなかった。**
