## 1. 本当に未検証な軸＝「オッズ盤の形」

ユーザーが挙げた軸のうち、**一度も測っていない**のはこれだけ：

- 1番人気のオッズ / 市場示唆確率
- 2番人気以下とのオッズ差
- オッズ分布の歪み
- 頭数に対する人気の集中度
- 人気が割れている／集中している
- 断然人気がいる／いない

🔑 **しかもこれは筋の良い候補である。** 測定0で、同数のレースを
「1番人気の市場示唆勝率が高い順」で選んだところ **単勝97.8% / 複勝86.4%** となり、
AIのゲート（89.8% / 81.0%）にも無作為（87.9% / 86.0%）にも勝った。
**盤の形はこのプロジェクトで最も高い回収率を出した唯一の選択軸。**

## 4. 判定（結果を見る前に固定）

1. **全セルを報告する。** 良いセルだけ拾わない
2. **帰無シミュレーション**：実配当をレース間でシャッフルして
   「100%超のセルが偶然いくつ出るか」の期待値を出し、観測数と比べる
3. **持ち越し検定（最重要）**：探索期（2026-06-27〜08-08・385R）でセルを順位付けし、
   検証期（08-09〜09-06・295R）でその順位が保たれるか。**相関がゼロなら打ち切り**
   （F-4 で Δ の持ち越しが r=-0.001 だった前例がある）
4. 生き残ったセルにのみ **CI下限 > 100% / 3本抜き / 前後半 / N>=300** を適用

**打ち切り基準：持ち越し相関が有意でなければ、この筋を閉じる。**

## 5. あわせて実施：AIと市場の乖離を連続量として測る

ユーザー提案。個別のセル検証ではなく、**価格誤差問題**として測る。

```
q     = 市場示唆確率（オッズから、レース内で正規化）
p_AI  = AIの確率（cal_prob）
gap   = log(p_AI / q)        ← 連続な乖離量
y     = 実際の結果
```

問い：**q を統制した上で、gap は y を説明するか。その符号は？**

| gap の係数 | 意味 |
|---|---|
| **正** | AIが市場と食い違ったとき、AIの側が正しい → Aルートに価値が残る |
| **ゼロ** | AIの乖離は雑音 → **Aルートの探索を大幅に縮小してよい** |
| **負** | AIが食い違うほど間違っている → 乖離は避けるべき信号 |

⚠ 既測定との関係：2026-08-31③ で `corr(gap, 符号つき誤差) = -0.1213`（負）が出ている。
今回はそれを**回収率まで通して**、条件別に符号が変わる場所があるかを見る。
