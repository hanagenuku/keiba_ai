# レース種別ごとに「着眼点」は変わるか：事前登録

**書いた時点: 結果を見ていない。**

## 問い

予想家は**レースごとに見る条件を変えている**（チャレンジCでは距離短縮・好位・脚質、
別のレースでは別の条件）。本番モデルは**それをしていない**ことが実測で確認された：

```
61本の木のうち、レース単位の特徴量を根（深さ0）で使っている木  = 0本
レース単位の特徴量が分岐に占める割合 = 4.3%（gainでは2.8%）
```

**問い：レース種別によって「効く馬の属性」は本当に変わるのか。変わるなら翌期間に持ち越すか。**

## 既実施との関係

2026-08-28 **MF-3** が近いことを測っている（10特徴量群 × 10条件 = 90組で
「条件別に特徴量を抜く」→ 選抜期で良かった30組のうち検証期でも良かったのは
**3組=10%**、偶然50%より悪い、相関 r=-0.004）。

⚠ ただし MF-3 の限界：
- 条件が**10個と粗い**（芝1600-1800 等）
- **「抜く」**という操作で、「着眼点の重みが変わる」を直接測っていない
- 坂・直線長・回り・コーナー・開催週といった**コース形状の軸を含んでいない**

**今回はユーザーが挙げた軸で、より細かく、直接測る。**

## 測り方

各レース種別セル `c` × 各属性 `f` について、**市場人気を統制した偏相関** ρ(c,f) を出す。

```
ρ(c,f) = corr( f , 3着内 | 人気 )   をセル c の中で計算
```

### 検定A：セル間のばらつきは偶然より大きいか
セルのラベルをシャッフルして ρ のばらつきの帰無分布を作り、観測と比べる。

### 検定B：持ち越すか（本命）
探索期（2023-01〜2025-06）で ρ(c,f) を出し、検証期（2025-07〜2026-08）で再計算。
**両者の相関がゼロなら、レース種別ごとの着眼点は存在しない（＝MF-3の再確認）。**

### 検定C：持ち越すなら、回収率で効くか
検定Bを通ったセル×属性の組にだけ、単勝・複勝の実回収率を出す。

## 合格基準（結果を見る前に固定）

1. **検定A**：ρ のばらつきが帰無の95%点を超える
2. **検定B**：探索期 ρ と 検証期 ρ の相関が **r >= +0.20** かつ 並べ替え検定 P < 0.05
3. **検定C**：持ち越した組で回収率100%超（CI下限・3本抜き・前後半も確認）

**検定Bが通らなければ、そこで打ち切る。**（1・3は見ない）

## 計測器の関門

1. `開催何週目か` の計算が正しいか：既知の開催（例：東京の春開催）で1〜8週になるか
2. 属性はすべて**そのレースより前**の走りのみから作られているか（リーク検査）
3. 市場統制が効いているか：人気だけを入れた偏相関がゼロ近辺になる対照を置く
4. セルの最小N：1セル200頭未満は使わない
5. 探索期と検証期のレースが重複していないこと
