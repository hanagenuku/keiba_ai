# レース種別ごとの「着眼点」は変わるか：結果

対象: **2023-01-14〜2026-09-06 の 136,902頭 / 10,769レース**（history.db 全期間）
基準は `racetype/CRITERIA.md` に、結果を見る前に確定済み。

---

## 結論

| 検定 | 結果 |
|---|---|
| **A. セル間で効き方が変わるか** | ✅ **通過**。11属性中6つが帰無を超える |
| **B. それは翌期間に持ち越すか（本命）** | ✅ **通過**。r=+0.465（全体水準を除いた後）・対照群の最大 +0.132 |
| **C. 回収率に変換されるか** | 🔴 **未達**。セル固有の着眼点で選ぶと**むしろ悪化** |

🔑 **ユーザーの直感は前半（AとB）で正しく、後半（C）で成り立たなかった。**
「レースによって見るべき条件は違う」は**実在し、しかも事前に予測できる**。
しかしそれで馬を選ぶと回収率は下がる。

### ⚠ MF-3（2026-08-28）との関係

MF-3 は「条件別に特徴量を抜くと良くなるか」を測り、持ち越し10%・r=-0.004 だった。
**矛盾しない。** MF-3が測ったのは*差の差*（抜いた前後の差）という雑音の大きい派生量で、
今回測ったのは ρ そのもの。**MF-3の結論は「切り替えは効かない」ではなく
「切り替えの*効果*は測れないほど小さい」と読むべきだった。**

## 3. 🔴 検定C：しかし回収率には変換されない

探索期の ρ から「セルごとの着眼点」の係数を作り、検証期3,625レースで馬を選んだ。

```
買い方                          N     単勝ROI   CI下限   複勝ROI  CI下限   3本抜
① 市場1番人気（対照）           3625   75.8%   70.2%   82.0%  75.5%  81.8%
② セルを見ない（全体ρだけ）      3625   75.4%   65.4%   78.5%  71.0%  77.2%
③ セルごとの着眼点（本命）        3625   70.6%   60.7%   75.4%  67.5%  74.2%
④ 市場1番人気 × ③上位半分のみ    1813   77.5%   73.6%   84.8%  79.5%  84.3%
```

🔴 **③が①②より悪い。** セル固有の着眼点を使って馬を選ぶほど回収率が下がる
（① 82.0% → ② 78.5% → ③ 75.4%）。

これは本プロジェクトで繰り返し出ている形と同じ：

```
2026-08-24 E-2  実力で絞るほど回収率が単調に低下（78.4→76.9→74.9→62.1%）
2026-08-24 E-3  AIで選ぶより素直に人気順で選ぶほうが良い（60.5% vs 71.4%）
2026-09-07 測定0 AIゲートは市場だけのゲートに複勝で-6.1pt
```

✅ 唯一 ① を上回るのは **④（③を見送り判断にのみ使う）で 84.8%**（+2.8pt）。
ただし **CI下限79.5%** で、損益分岐まで **あと15.2pt**。

## 4. これが意味すること

**「レースによって見るべき条件が違う」は本物で、事前に予測もできる。**
統計的な裏付けは、このセッションで測った中で最も強い（対照群の3.5倍）。

**しかし、それで馬を選ぶと市場に負ける。**
効き方の違いの大きさが ρ で ±0.02 程度しかなく、
市場が既に織り込んでいる分を超えられない。

🔑 **予想家が「このレースは距離短縮を見る」と言うのは正しい。
だが、それを知っているのは彼だけではない。** 同じことを1万人が知っていて、
それがオッズに入っている。

⚠ **唯一残る使い道は④（見送り判断）** で、これは測定0で「AIのゲートは無作為以下」
と出た件の代替になりうる。**82.0% → 84.8%（+2.8pt）** だが、
CI下限は100%に届かない。単独で追う価値があるかは、次の議論に委ねる。
