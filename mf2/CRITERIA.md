# 事前登録: 市場フリーモデル再構築（Phase 1-2）
作成 2026-09-08 / **数字を一つも見る前に確定させる**

## 何を測るか
「市場情報を特徴量に一切使わないモデル(F)」が、どこまで馬の好走確率を独立に評価できるか。
比較対象を先に固定する。

## アーム定義（列の出入りだけが違う。ハイパラ・窓・シードは全て共通）
| | base_margin | 除外する列 | 位置づけ |
|---|---|---|---|
| **R** 本番同型 | 人気順位Zipf + 実測ドリフト注入(seed 11/12) | f_popularity | いま動いている本番。上限の参照点 |
| **M** 市場のみ | 同上 | 全特徴量（木を建てない） | 市場アンカー単体の下限。base_margin だけで測る |
| **F** 市場フリー | **なし** | f_popularity, f_pop_last, f_pop_avg, f_beat_market_rate | 今回の主役 |
| **F+** 参考 | なし | f_popularity のみ | 「過去の市場評価」を残すと何が変わるかの内訳 |

⚠ F の除外4列は「市場情報を加工した特徴量」に該当する（f_pop_last/f_pop_avg は過去走の人気、
f_beat_market_rate は着順<人気だった率）。方針書の禁止リストに沿って **F では必ず全部落とす**。
F+ は F と R の差を「base_margin の有無」と「過去の市場評価3列」に分解するためだけに置く。

## 計測器の妥当性検査（結果を見る前に置く関門。1つでも落ちたら測定をやり直す）
1. **再現**: R の W1 AUC が本番記録 0.7804 ± 0.003 に入ること（入らなければ経路が違う）
2. **窓の独立**: 各アームの val 最小日 > train_end であることをコードで assert
3. **列の検算**: F の特徴量リストに `pop` / `market` を含む列が 0 件であることを assert
4. **プラセボ**: F の学習ラベルをレース内シャッフルした版が AUC 0.50±0.02 に落ちること
5. **シード幅**: 同一アーム3シードの std を必ず併記する。std の2倍未満の差は「差なし」と書く

## 判定（Phase 1）
仮説1「市場フリーでも 0.77 前後から**大幅に**改善できる」の合否:
- **合格**: F の3窓平均 AUC が **0.79 以上**、かつ 3窓すべてで F > 0.78
- **部分的**: F が 0.77〜0.79 に収まる（＝現状維持。改善はしていない）
- **不合格**: F が 0.77 未満

⚠ この時点では「F < R」は不合格の理由にしない。R は base_margin で市場を土台にしている以上、
周辺確率のAUCで上回るのは既知（2026-08-08③・MF-1b）。**F の目的は独立性であって AUC の勝利ではない。**

## 判定（Phase 2 アブレーション）
特徴量を10グループに分け、F から1グループずつ抜いて 3窓×3シードで測る。
- 「効いている」= 抜くと **3窓すべてで AUC が下がり**、平均低下がシード std の2倍以上
- 過去に市場アンカー型で「効果なし」とされた群（近走成績・PL・コース適性・距離適性・脚質・
  枠順・ペース・馬場適性・レースレベル・相手関係）を**もう一度全部測る**。
  過去の結論を市場フリー側に持ち込まない（方針書の指示）。

## 追加で必ず出すもの（AUCだけで判定しないため）
- LogLoss / Brier / ECE（較正）
- F と 市場示唆確率の **順位相関**（独立性の直接測定。低いほど独立）
- F と R の順位相関

## やらないこと
- 回収率をこの段階で判定材料にしない（Phase 4以降）。
- 数字を見た後に指標を選ばない（2026-08-28 R1 の失敗を繰り返さない）。
- 1窓だけ良い結果を採用しない（2026-08-08③ の失敗）。
