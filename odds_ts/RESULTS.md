# オッズ時系列の結果：経済的に意味のある大きさの経路情報は無い（打ち切り）

対象: **2026-09-05 / 09-06 の 55レース・737頭**（発走75分前〜0.6分前・約2分間隔・1レース31〜36観測点）
基準は `odds_ts/CRITERIA.md` に、結果を見る前に確定済み。

---

## 結論

**事前登録した合格線（ヌル補正後 AUC +0.0225）に、どちらの目的変数でも到達しなかった。**
モデルを使わない層別テストでも一貫した傾向は出なかった。**この筋は打ち切る。**

---

## 1. 本測定：最終オッズを統制した上での経路情報の増分

経路特徴量は事前登録した3本（`rel_move_z` / `last_move_z` / `wiggle`）。
判定は0ではなく**レース内シャッフル60回の経験的ヌル**に対して行った。

```
=== 3着内 ===
  M1 最終オッズのみ         AUC 0.8150
  M3 + 経路3特徴量          AUC 0.8117
  実測増分                  -0.0033
  経験的ヌル                -0.0038 ± 0.0025
  ヌル補正後                +0.0005   (+0.21σ, 片側p=0.400)   ❌ 合格線 +0.0225 に未達

=== 1着 ===
  M1 最終オッズのみ         AUC 0.7754
  M3 + 経路3特徴量          AUC 0.7765
  実測増分                  +0.0011
  経験的ヌル                -0.0089 ± 0.0081
  ヌル補正後                +0.0100   (+1.24σ, 片側p=0.100)   ❌ 合格線 +0.0225 に未達
```

🔑 **ノイズ床が実際に負だった**（-0.0038 / -0.0089）ことは事前の較正どおり。
0と比べていれば「3着内で -0.0033、経路情報は無い」と結論するところだったが、
正しい比較先はヌルなので実際は **+0.0005**。**偽陰性の罠は回避できた。**

### 検出力に照らした読み方

| 目的変数 | ヌルのσ | +0.0225 は何σか | 判定 |
|---|---|---|---|
| 3着内 | 0.0025 | **9.0σ** | ✅ **決定的に否定**。この大きさの効果があれば必ず見えた |
| 1着 | 0.0081 | **2.8σ** | ✅ **9割方否定**（観測は +1.24σ） |

⚠ 1着の **+0.0100 はゼロではない**。ただし合格線の半分以下で、有意でもない（p=0.100）。
仮にこれが本物でも回収率換算で **+1.8pt** にしかならず、必要な +12〜24pt に遠く及ばない。

## 2. 層別テスト（モデルを使わない確認）

最終オッズ帯を固定し、レース内での**相対的な動き**（市場全体の動きを除去）で3分割。

```
  オッズ帯      経路タイプ        N    3着内率   複勝回収
  1-4倍     買われた(相対↓)     24    58.3%    80.8%
  1-4倍           横ばい      24    70.8%    97.1%     ← 単調でない
  1-4倍     売られた(相対↑)     24    66.7%    90.8%

  4-10倍    買われた(相対↓)     45    40.0%    92.2%
  4-10倍          横ばい      47    46.8%    80.2%     ← 単調でない
  4-10倍    売られた(相対↑)     45    37.8%    77.8%

  10-30倍   買われた(相対↓)     69    26.1%    98.7%    ← 3着内率は単調
  10-30倍         横ばい      72    22.2%   107.4%    ← 回収率は単調でない
  10-30倍   売られた(相対↑)     69    18.8%    91.2%

  30倍-     買われた(相対↓)    104     3.8%    23.7%
  30倍-           横ばい     108     4.6%   148.2%     ← 単調でない
  30倍-     売られた(相対↑)    104     2.9%    51.7%
```

**4帯のうち3着内率が単調なのは 10-30倍 の1帯だけ。回収率は4帯とも単調でない。**

```
              N   3着内   回収   3本抜   09-05   09-06   最大配当の寄与
```

しかも見たセルは 4×3 + 6 = **18セル**で、多重比較の期待どおりの現れ方。

## 3. 判定

事前登録の非対称ルール：

> ヌルに対して有意な増分が出ない → **経済的に意味のある大きさの経路情報は無い。打ち切ってよい**

に該当する。**オッズ時系列は打ち切る。**

### 何を否定して、何を否定していないか

| | |
|---|---|
| ✅ 否定した | 発走75分前〜締切の経路に、**控除率20%を超えるだけの**追加情報があること |
| ❌ 否定していない | 経路に**統計的に検出可能な微小な**情報があること（1着で +0.0100・p=0.100） |
| ❌ 否定していない | **75分前より前**の経路（前日〜当日朝）に情報があること |

⚠ **2開催日しかない。** ただし合格線の大きさ（+0.0225）なら3着内で9σ・1着で2.8σの
分解能があるので、**経済的に意味のある効果は、あればこのNで見えていた。**

### 収集は続ける（コストがゼロなので）

`collect-odds.yml` は土日に自動実行され、1レース1リクエストで無保守。
週55レースずつ溜まる。**打ち切るのは「優先テーマとしての探索」であって、収集ではない。**
将来この判定を覆すだけの別の仮説が出たときに、データがある状態にしておく。
