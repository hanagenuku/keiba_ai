## 0. なぜ「2026年1月から」が特別なのか

本番モデルの `train_end` は **2026-06-30**。したがって **2026-01〜06 は
学習期間の中**で、そのままでは評価に使えない。2026-08-29 に
「検定窓が学習期間と重なるだけで複勝回収率が 106.2% → 77.5%（**28.7pt**）
動く」と実測している。

学習を **2025-12-31 で止めれば**、2026-01-01〜2026-10-18 の約2,700レースが
丸ごと完全 out-of-sample になる。

🔑 **これはこのプロジェクト史上いちばん大きい clean window になる。**
今ある実績記録（`shadow_bets`）は 1,023レースで、しかも
2026-08-21 / 09-15 の**モデル2世代の入れ替えを跨いでいる**。
同一モデルで 2,700レースを通しで測ったことは一度も無い。

⚠ ただし **2026年に新しい予想ロジックを見つけに行く**のではない。
見つけに行くと、同じデータで探して同じデータで検証する選択汚染になる
（2026-08-24 F-4 で踏みかけた）。**比べるアームは下に全部書き切る。**

## 1. 問い

> 既存の実装スイッチの範囲で、本番より複勝回収率が高い予想生成の構成はあるか。

🔴 **新しい特徴量は作らない。** 特徴量追加・データ蓄積・モデル精緻化は
2026-08-17〜18 に測り切って飽和と確定している（129特徴量 vs 市場アンカーのみ
= +0.0009）。ここで比べるのは**既にコードにある構成の選び方**だけ。

## 2. アーム（これ以外は測らない）

| | 構成 | なぜこれを測るか |
|---|---|---|

| **F** | 市場フリー。`f_popularity` 系の市場由来列を除外し base_margin を使わない独立モデル | 2026-08-28 MF-1b が「**置き換えではなくフォールバックなら成立しうる（未検証）**」と明記して**閉じていない**唯一の筋 |

## 3. 母集団と期間

```
学習    history.db の 〜2025-12-31
```

- `is_fukusho` が無い行は除外

## 4. 主要評価指標

🔴 **判定は回収率で行う。AUC では行わない**（North Star #9）。
的中率が上がっても配当が縮むので、当てやすさの改善は成果ではない。

| 記号 | 定義 |
|---|---|
| **R_fuku** | 軸(予測1位)の複勝1点を全レース買った時の回収率。払戻は `history.db.fukusho_payout` |
| R_cut3 | 上位3本の配当を除いた R_fuku |
| R_tan | 軸の単勝1点の回収率 |
| 月別 | 2026-01〜10 の月ごとの R_fuku |

⚠ **的中なのに配当が取れていない行は0円として混ぜない**（2026-08-18③ で
実力を過小評価した）。分母から外し、除いた件数を結果に書く。

副指標（参考。判定には使わない）: AUC / Brier / LogLoss。

## 5. 市場比較ゲート（必須・CLAUDE.md の標準）

アームの優劣とは別に、**毎回この3つを並べる**:

| | |
|---|---|
| 市場単独 | 人気順位だけで軸を決めた時の R_fuku / AUC |
| AI単独 | そのアームが市場を見ずに出した順位（F はこれ自体） |
| AI×市場 | 両方（P はこれ自体） |

さらに**乖離の方向別**（AIが強気 / 一致 / AIが弱気）に R_fuku を出す。
🔴 **AIが強気な側で改善が出たら、まず計測器を疑う**
（2026-08-31: `corr(gap, 符号つき誤差) = -0.1213`。市場と食い違うほど
その方向に間違っている、が3回測って出ている）。

## 6. 採用基準（結果を見る前に確定）

**F を本番に置き換える**（全部満たして初めて）:
1. 全期間の R_fuku が P を **+2.0pt 以上**上回る
2. R_cut3 でも P を上回る（高配当1〜2本で作られていない）
3. 月別10ヶ月のうち **6ヶ月以上**で P を上回る
4. 市場比較ゲートで、F が市場単独を R_fuku で上回る

**F をフォールバックとして採用**（置き換えが不成立の場合のみ）:
5. **市場アンカーが壊れたレース**（`f_popularity` 欠損）に限ると
   F が P を +2.0pt 以上上回り、かつその部分集合が **N>=300**

どれも満たさなければ **現状維持**（Pのまま。何も変えない）。

🔴 **基準を満たしても、回収率が100%を超えたとは書かない。**
100%超は未確認のまま（最良の実測は 2026-08-18③ の複勝 93.4%・N=3,560）。

## 7. 対照群

- **対照群A（並べ替え分布）**: レース内で予測順位をシャッフル 200回。
  合格は帰無が0中心＝`|mean(ΔR_shuffle)| < 2*std/sqrt(200)`。
  実測の差は並べ替え P 値で報告する。
  🔴 1回の引きとの大小比較は書かない。
- **対照群B（注入の復元）**: 既知の効果を注入し
  **`注入後 − 注入前 = 注入量`** を 1e-3 の精度で復元できること。
  🔴 「注入後 ≈ 注入量」と書かない（2026-09-17 P3-01 で踏んだ罠）。

## 8. 中止条件（1つでも該当したら、結果を読まずにハーネスを破棄して出直す）

1. 学習データに `date > 2025-12-31` の行が1行でも混ざる
2. 両アームの学習行数・行順・`is_fukusho` が完全一致しない
3. P の検定窓 AUC が **0.75〜0.82 の外**
   （過去の実測帯から外れたらハーネスを疑う。2026-08-05 の 0.787、
     2026-08-21 の 0.780、2026-09-15 の 0.783 が実測）
4. 本番の `data/*.pkl` の md5 が測定前後で変わる
   （2026-09-15 にワークスペースがリポジトリを貫通して本番モデルを
     書き換えた事故があるため）

🔴 **中止条件は回収率より手前で印字する。**
2026-10-19② で、中止条件3を最後に印字する作りにしたせいで
ECE を先に見てしまった。同じ作りにしない。

- 買い目・券種・資金配分の変更（2026-08-18③ で算数的に決着済み）
