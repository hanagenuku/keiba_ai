## 4. フォールバック仮説（市場アンカーが壊れたレースで F > P か）

`f_popularity` が3割以上欠けるレース **274本**:

| | N | 複勝率 | 回収 |
|---|---:|---:|---:|
| P（本番構成） | 263 | 26.62% | **53.46%** |
| F（市場フリー） | 249 | 51.00% | **76.43%** |

差は **+22.97pt** で、方向も大きさも事前の予測どおり。
🔴 **しかし N=263 で、カードが登録した N>=300 に届かない → 不採用。**

🔴 **そして、これを「本番のフォールバックに市場フリーモデルを持つべき」と読んではいけない。**
理由は3つで、どれも実測・実装に基づく:

1. **壊れているのは本番の推論経路ではなく、history.db のほう。**
   欠損の正体は 2026-04（充足 92.3%）と **2026-05（53.9%）** で、
   2026-08-06 に「JRA の結果一覧が遡れず**復旧不可**」と記録済みの月。
   ＝ これは**学習・評価データの欠損**であって、本番が推論時に見るオッズの話ではない。
2. **本番はオッズが取れない時すでにフラットアンカーに落ちる**（2026-08-29 FB）。
   推論時の人気はライブオッズから導くので、レース単位で**全有り / 全無し**になり、
   ここで見ている「レース内で一部だけ壊れている」状態は**本番では起こらない**。
3. **その「市場フリーモデルをフォールバックに持つ」案は 2026-08-29 に測って否定済み。**
   B（市場フリー）が C（フラットアンカー）を上回ったのは **2/5窓**で、
   結論は「**新モデルは持たない**」。今回も同じ結論を変える材料は出ていない。

✅ 読んでよいのは「**市場アンカーが壊れると本番構成は 53.46% まで落ちる**」まで。
2026-08-06 の「健全行 AUC 0.8207 / 死亡行 0.7091」、2026-08-29 の「偽アンカーで AUC 0.66台」を
**回収率で**裏づけた形。**対策は予想ロジックではなくデータ取得側**。

## 5. 対照群

### 対照群B（注入の復元）✅ 誤差0で通過

```
注入前 81.04%  注入後 101.04%  差 20.0000pt  = 注入量 20.0pt

```
払戻の経路・分母の作り方・3本抜きの計算が正しいことを**2通りで**確認した。

### 対照群A（並べ替え200回）🔴 **登録した形で通らなかった（計測器の欠陥）**

```
帰無の平均 −11.395pt  std 4.441  合格線 |mean| < 0.628  → ❌
実測 P − 無作為 = +11.395pt  並べ替え P値 = 0.0150
```

🔴 **これは仕様ミス。** 実装した統計量は `ROI(無作為な軸) − ROI(P の軸)` で、
**P に実力がある限り負の値になる**のが当然。「帰無が0中心」という合格線は
この統計量には当てられない（β係数の帰無に対する線をそのまま流用した）。
2026-09-27 SPAIA・2026-10-16 danger と**同型の壊し方**で、これで3度目。

⚠ **結果を見てから測定器を足し直すことはしない**（North Star #8）。
代わりに、**この欠陥が結論を動かさない**ことを明示する:
- 主結論は「**F を採用しない**」＝挑戦側の**否定**。並べ替え対照群の役目は
  「偽の陽性が出ていないか」の検査であって、**今回の risk はそちらではない**
- 判定は §2 の4基準と §3 の市場ゲートに乗っており、**どれも無作為ベースラインに依存しない**
- 読める事実が1つある: **P は無作為な軸選びより +11.40pt 上**（並べ替え P=0.0150）。
  ＝ 予想には実力がある。**ただし +11.40pt 足しても 80.74% で、100% には届かない**

🔑 次に並べ替え対照群を書くときは、**「何の帰無分布か」を統計量ごとに決める**。
比較が `F − P` なら並べ替えるのは**アームの割り当て**で、予測値そのものではない。

## 8. この測定で測っていないこと（射程）

🔴 **「2026年の結果から最適な予想生成ロジックを見つけた」とは書かない。**
比べたのは**カードに書き切った2アームだけ**で、以下は**1つも測っていない**:

- softmax 温度 T / `conf` の較正（`conf` の尺度が動くと商品の対象範囲が変わる。**別カードが必要**）
- 本番モデルの再学習そのもの（**2026-10-19 に測って不採用**。ΔAUC −0.0007・全9回 `best_iteration` 10〜11）
- 較正器の作り直し（**2026-10-19② の副産物**として未測定のまま残っている）
- 特徴量の追加・削除（2026-08-17 に「129特徴量 vs 市場アンカーのみ = +0.0009」で閉じた）
- 買い目・券種・資金配分（2026-08-18③ で算数的に決着）
- 閾値（`CONF_STRONG` / `CONF_LIGHT` / `DANGER_*` / `MIN_AXIS_FUKU_PROB`）

⚠ よって正しい射程は「**既存の実装スイッチの範囲では、本番構成がいちばん良い**」まで。
カード §9 に先に書いておいた文のとおり:

> 2026年の完全OOS 2,700レースで測っても、既存の実装スイッチの範囲に
> 本番を上回る予想生成の構成は無かった。現行構成を維持する。
