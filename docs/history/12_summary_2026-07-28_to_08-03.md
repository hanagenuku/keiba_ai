ユーザーの方針「**AIのRL順位と市場人気の差にだけ着目する。差がなければ買いレースではない**」
に沿って、本番の実記録（`race_predictions` の**朝の人気** 5,036頭・397レース・12開催日）を

**4-6番人気 × 差(朝の人気 − RL順位)+2以上 → 単勝回収率 131.7%（N=162・22的中）**

### 🔴 最重要：市場を外したAIには妙味がない（「差」の追求はここで一区切り）

「市場人気を特徴量に入れている限り差は生まれにくい。市場を見ないAIの差なら何か見えるのでは」
というユーザーの提案を検証した。**前提は正しかったが、結論は逆だった。**

残差モデルは `raw_margin = base_margin(市場) + ability_margin(市場ゼロのAI)` と分解でき、
`ability_margin` は base_margin に**一切依存しない**（検算済み・最大ずれ 2.8e-06）。
これで順位を付け直せば「市場を一度も見ないAI」が得られる。

**① アンカーは確かに差を潰していた（ユーザーの指摘は正しい）**
| | 市場人気との平均ずれ | 一致率 |
|---|---|---|
| 市場ゼロAI | **2.11位** | 20.5% |
| 市場ありAI（本番） | **0.88位** | 47.8% |

→ アンカーが差を **58%圧縮**している。

**② しかし外すと、差の傾きが逆になる**
| 差（人気 − 市場ゼロAIの順位） | N | 勝率 | 回収率 |
|---|---|---|---|
| -4以下（AIが弱気） | 893 | 8.5% | 76.1% |
| -1〜+1 | 4,470 | 7.9% | 70.8% |
| +2〜+3（AIが強気） | 1,516 | 3.7% | 52.6% |
| **+6以上** | 332 | 1.2% | **41.4%** |

過去の市場評価（`f_pop_last`/`f_pop_avg`/`f_beat_market_rate`）の寄与も差し引いた
**完全に市場ゼロ**の順位だと、+6以上は **21.8%** とさらに悪化する。
**市場を外すほど悪くなる。**

**③ 主因で絞っても救えない**（本番82頭でのスピード能力302.8%はN=18のノイズだった）
| 主因（市場ゼロAIが強気な2,524頭） | N | 回収率 |
|---|---|---|
| 騎手 | 407 | 78.9% |
| **スピード能力** | 620 | **53.2%** |
| 過去人気推移 | 362 | 55.5% |
| 近走成績 | 408 | 25.6% |

100%を超える主因は**一つもない**（市場ありAI側でもN≥40の8主因中1つだけ、それもN=41・1的中）。

**④ 的中力そのものが市場に劣る**
| | AUC |
|---|---|
| 市場ゼロAI | 0.7778 |
| 市場ありAI | 0.8252 |
| 市場人気だけ | 0.8248 |

市場ありAIは市場とほぼ同じ（+0.0004）、市場ゼロAIは市場より**明確に下**。

⚠ **この検証データはモデルが学習に使ったもの**で、AIに有利に出るはずの条件。
それでも負の傾きだった。

**→ 結論: アンカーはエッジを隠していない。アンカーこそがAIを市場並みに保っている。**
131.7%（N=162・基準②③④未達）は、AIの洞察ではなく**朝のオッズが未成熟なことによる
ブレ**を拾ったノイズである可能性が高い。
