## ⚠ 出典の扱い（ユーザー指示・厳守）

> 約○mと書かれていない距離について、推定値を勝手にfeatureとして採用しないこと。
> 「公式記載値」「公式図からの算出値」「未確定」を分けたデータ表にする。

`data/course_starts.json` の `*_src`:

- `official` … 資料が「JRA公式が…と説明している」と明記している数値
- `stated` … 資料に「約○m」とあるが公式明記の確認は取れていない数値
- `doc` … 資料の記述（数値でないカテゴリ。スタート地点・コーナー番号・勾配・スパイラル）
- `na` … 概念が存在しない（新潟芝1000の直線コース等）

`race_shape.start_to_first_corner_m()` は **`official` / `stated` 以外を返さない**。
**書かれていない項目は None のまま。埋めない。**

⚠ 中京芝1600の200mは「1角まで」ではなく「本線に合流するまで」なので
`start_to_mainline_merge_m` に分けてある。同じ列に混ぜないこと。

## ⚠ 期待値（集める前に）

前半600mのクセの97%は「発走地点ごとの**経験的な**定数」で再現できる
（`tenkai/RESULTS_VENUE.md`）。物理データの価値は「当てる」ことではなく
**説明・未見コースへの外挿・仮説の検定**にある。
数値62組が埋まって初めて、一般化能力の検定に検出力が出る。
