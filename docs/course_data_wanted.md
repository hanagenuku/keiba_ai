## まだ欲しいもの（優先順）

### 🟡 優先1: merge_ambiguous 3組の「初角まで」の距離

東京芝1800（206R）・東京芝2000（148R）・札幌芝1500（83R）。

資料の数値（約150m / 約100m / 約170m）は合流までのもの。
