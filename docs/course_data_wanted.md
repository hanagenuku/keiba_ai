## ⚠ 出典の扱い（ユーザー指示・厳守）

> 約○mと書かれていない距離について、推定値を勝手にfeatureとして採用しないこと。
> 「公式記載値」「公式図からの算出値」「未確定」を分けたデータ表にするのが安全。

`data/course_physical.json` の `src` に必ず入れる:

- `official` … JRA公式が距離別に明記している値
- `stated` … 資料に「約○m」として記載（公式明記の確認は取れていない）
- `web` … web検索由来（**特徴量には使わない**）

**数値が無いものは空欄のままにする。埋めない。**

## ⚠ 期待値を先に書いておく

発走地点ごとの**経験的な定数**だけで 97% 説明できるので、
物理データを入れて RMSE が大きく下がることは期待しない方がいい。
価値は「説明できること」「観測の薄い組み合わせへの外挿」「仮説の検定」にある。
もし大きく下がったら、物理量が会場ダミーの代理になっているだけかを疑うこと
（2026-09-15 の M2h/M3h が実際にそうで、one-hot の後では追加価値が消えた）。
