## 🔴 優先3: スタート地点の勾配（いま76組中11組）

資料に記述があるのは中山芝1200/2000・阪神芝1200/2000・福島芝1800/2000・
小倉芝1800/2000・函館芝2000・東京芝1400/1600 だけ。
ゴール前の坂とコース全体の高低差は持っているが、**発走地点の高低**は
この11組以外に無い。前半600mを決めるのはここのはずなので優先度が高い。

## ⚠ 出典の扱い（ユーザー指示・厳守）

> 約○mと書かれていない距離について、推定値を勝手にfeatureとして採用しないこと。

`data/course_starts.json` の `*_src` に必ず入れる:

- `official` … 資料が「JRA公式が…と説明している」と明記している数値
- `stated` … 資料に「約○m」とあるが公式明記の確認は取れていない数値
- `doc` … 資料の記述（数値でないカテゴリ）
- `na` … 概念が存在しない（新潟芝1000の直線コース等）

**書かれていない項目は None のまま。埋めない。**

## ⚠ 期待値（集める前に）

前半600mのクセの97%は「発走地点ごとの**経験的な**定数」で再現できる。
物理データの価値は「当てる」ことではなく **説明・未見コースへの外挿・仮説の検定** にある。
ダート25組と数値29組が埋まって初めて、一般化能力の検定に検出力が出る。
