# コース基礎台帳（実データ由来・参照用）

`data/course_ledger.json` の読み方と主要な数字。
生成: `python -m src.tools.build_course_ledger .`（history.db から再生成できる）

出典: history.db **12,017レース / 164,915頭 / 2023-01-07〜2026-09-13**
粒度: venue×surface **20セル** ＋ venue×surface×距離帯 **64セル**＝計84セル

## 読み方（重要）

- **`resid_pt` を見ること。`top3` は見ないこと。**
  `top3` は生の3着内率で、**馬の強さと交絡する**（ハナを切れる馬はそもそも強い）。
  `resid_pt` は人気×頭数から期待される3着内率を引いた残差で、
  「**同じ人気の馬が、このコース・この脚質／この枠だと市場の想定より走るか**」を表す。
- ⚠ **脚質の残差は事後の脚質**（実際にどう走ったか）で測っている。
  事前に「誰が逃げるか」は当てられないので、**この数字をそのまま買い目に使わない**。
  2026-08-27: 位置取りを完璧に知れば AUC +0.0479 だが、その **94.6%は4角＝着順の
  言い換え**で、過去走から予測した位置取りでは **+0.0001**。
- **事前に分かるのは「コース側の差」と「枠」**。その2つがこの台帳の使いどころ。

## 1. 脚質 — 全コースで逃げが大幅プラス。差はコース間にある

人気を揃えると **全20コースで逃げ +9〜+20pt / 追込 −3.7〜−7.5pt**。
つまり「このコースは前が有利」ではなく「**前に行けた馬は市場想定より走る**」が地の性質。

```
                  逃        先        差        追
福島_ダート    +20.28   +15.66    +0.16    -6.67   ← 最も前が止まらない
小倉_ダート    +19.29   +13.61    -0.65    -5.78
阪神_芝       +15.32    +2.05    +0.63    -3.88
函館_ダート    +14.05   +15.22    -1.49    -7.50
東京_芝       +11.75    +4.31    +1.10    -4.53
中京_ダート     +9.25   +11.16    -1.01    -3.96
札幌_ダート     +4.32   +14.40    +0.70    -6.25   ← 逃げ切りは効かない
   コース間std   3.36pt   4.51pt   0.90pt   1.02pt
```

🔑 事前に使えるのは**コース間std のほう**（逃 3.36pt / 先 4.51pt）。
福島ダ +20.28 と札幌ダ +4.32 の差 16pt は、レース前に分かっている情報。

## 2. 枠順 — これは完全に事前に分かる

`内/中/外` は馬番÷頭数の3分割。

```
venue×surface（内−外）   最大 小倉_ダート +3.39pt（内有利）
                       最小 札幌_ダート -5.21pt（外有利）
                       コース間std 内1.19 / 中0.68 / 外0.97pt
```

**距離帯まで割ると差が大きくなる**（N>=400のみ）:

```
小倉_ダート_~1400        内 +4.52  中 +0.12  外 -3.59   内−外 +8.11pt
函館_芝_1401-1800       内 +4.16  中 -0.31  外 -2.27   内−外 +6.43pt
札幌_ダート_~1400        内 -2.80  中 -1.80  外 +3.05   内−外 -5.85pt
福島_芝_1401-1800       内 +2.85  中 +0.38  外 -2.52   内−外 +5.37pt
中山_芝_2201~           内 +2.74  中 +0.99  外 -2.27   内−外 +5.01pt
中山_芝_~1400           内 +2.05  中 +1.88  外 -2.81   内−外 +4.86pt
東京_芝_~1400           内 -1.77  中 -0.61  外 +2.16   内−外 -3.93pt
```

🔑 **符号がコースによって逆**（小倉ダ短距離は内、札幌ダ短距離は外）。
venue×surface だけ見ると打ち消し合って見えなくなる。距離帯まで割る必要がある。

✅ 枠は 2026-08-17 の129軸総当たりで **2年連続・同符号でFDRを通った唯一の軸**
（`f_post`・r≈+0.008〜0.010）。独立の裏付けがある唯一のコース次元。

## 3. 荒れやすさと決め手

```
コース          1番人気3着内   上がり3F中央値   平均頭数
東京_芝           72.4%        34.5        15   ← 最も堅い・最も速い上がり
函館_ダート         68.9%        37.9        12
東京_ダート         67.2%        37.6        16
中山_芝           65.2%        35.4        16
福島_ダート         60.1%        38.4        15   ← 最も荒れる
小倉_芝           59.8%        35.9        16
```
1番人気の信頼度は **59.8%〜72.4%** で12.6ptの幅。芝の上がりは 34.5〜36.0、
ダートは 37.6〜38.8 で、**芝ダの差のほうがコース間の差より大きい**。

## 🔴 この台帳を作って見つかった defect

`data/course_profiles.json` の `style_advantage` は**手書きのまま一度も
データで検証されていない**。生成器 `generate_style_advantage.py` は実行時に
`_generated_from_db: True` を書き込むが、本番の JSON にそのキーが無い。

```
              手書き（合計1.0の配分）        実データ（3着内率）
東京_芝    0.20 0.30 0.35 0.15    37.3% 32.7% 28.7% 12.7%   ← 逃と差が逆
新潟_芝    0.18 0.27 0.38 0.17    39.0% 31.5% 23.9% 11.8%   ← 逆
東京_ダート  0.22 0.35 0.30 0.13    37.0% 34.3% 25.2% 10.8%   ← 逆
```

- 順位の大枠は当たっている（Spearman 中央値 +0.800・20/20コースで正・
  まとめた相関 +0.879）。**ただし直線が長いコースほど強く「差し有利」と
  書いてある部分が、実データでは逆**。
- **スケールが別物**。手書きは合計1.0の配分、生成器が書くのは生の3着内率。
  しかも生成器は `merged = {**existing, **adv}` なので、
  サンプル不足の脚質だけ手書きの値が残り **1つの辞書に2つのスケールが混在する**。
- この値は `f_style_course_fit` → `f_style_total_fit` と相対列を通じて
  本番134特徴量のうち**最大6列**を支えている。

⚠ **まだ直していない。** 直すと6列が動くので、本番同型A/Bを通してから。
手順は `docs/course_ledger_next.md` に事前登録する。
