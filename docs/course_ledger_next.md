# C': style_advantage を実データ由来に差し替える A/B（結果を見る前に登録）

登録 2026-09-14。`docs/course_ledger.md` で見つかった defect の修正を、
**本番に入れる前に**測るための事前登録。

## 何を変えるか

`course_profiles.json` の `style_advantage`（手書き・合計1.0の配分）を、
`course_ledger.json` の **`resid_pt`（人気を統制した残差）** に差し替える。

🔑 生成器 `generate_style_advantage.py` が書く**生の3着内率は使わない**。
   交絡が残るうえ、手書きの配分とスケールが混ざる既存バグがある。

🔑 粒度は **venue×surface×距離帯**にする。venue×surface だけだと
   枠の符号が距離帯で逆転して打ち消し合う（小倉ダ短距離 +8.11pt vs
   札幌ダ短距離 −5.85pt）。脚質側も同じ可能性がある。

## 腕

- A: 現状（手書き）= 本番134特徴量
- B: 台帳由来に差し替え（列数は同じ134。値だけが変わる）
- 対照1: 台帳の値を**コース間でシャッフル**（コース固有性が効いているかを見る）
- 対照2: 全コース共通の値（＝コース差をゼロにする）

## 判定（結果を見る前に確定）

本番同型（residual・ドリフト注入ON）・3窓 × 3シード。

1. 悪化した窓がゼロ
2. 3窓平均 +0.002 以上（シードstdの2倍以上）
3. Brier・LogLoss も同じ方向
4. **対照1（シャッフル）を上回る** ← pace_bonus で効いた関門。必須
5. 複勝回収率が下がっていない（North Star #9。上がることは求めない）

- 1〜4 を満たす → 差し替える
- 4 が未達 → **差し替えない**（コース固有性ではなく値の分散が効いているだけ）
- 1〜3 のどれかが未達 → 「手書きを消して中立値にする」案だけ別途検討
  （作り話をしない、という観点では手書きの誤った値より中立値のほうが良い）

⚠ AUC が上がっても回収率が上がるとは書かない（North Star #9）。
⚠ 「向きが正しくなった」ことは採用根拠にしない。数字で通ること。
