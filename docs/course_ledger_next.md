# C': コース基礎の2つの defect を直す A/B（結果を見る前に登録）

登録 2026-09-14。`docs/course_ledger.md` で見つかった defect の修正を、
**本番に入れる前に**測るための事前登録。

## C-1: style_advantage を実データ由来に差し替える

### 何を変えるか

`course_profiles.json` の `style_advantage`（手書き・合計1.0の配分）を、
`course_ledger.json` の **`resid_pt`（人気を統制した残差）** に差し替える。

🔑 生成器 `generate_style_advantage.py` が書く**生の3着内率は使わない**。
   交絡が残るうえ、手書きの配分とスケールが混ざる既存バグがある。

🔑 粒度は **venue×surface×距離帯**にする。venue×surface だけだと
   枠の符号が距離帯で逆転して打ち消し合う（小倉ダ短距離 +8.11pt vs
   札幌ダ短距離 −5.85pt）。脚質側も同じ可能性がある。

## 腕

- A: 現状（手書き）= 本番134特徴量
- B: 台帳由来に差し替え（列数は同じ134。値だけが変わる）
- 対照1: 台帳の値を**コース間でシャッフル**（コース固有性が効いているかを見る）
- 対照2: 全コース共通の値（＝コース差をゼロにする）

## 判定（結果を見る前に確定）

本番同型（residual・ドリフト注入ON）・3窓 × 3シード。

1. 悪化した窓がゼロ
2. 3窓平均 +0.002 以上（シードstdの2倍以上）
3. Brier・LogLoss も同じ方向
4. **対照1（シャッフル）を上回る** ← pace_bonus で効いた関門。必須
5. 複勝回収率が下がっていない（North Star #9。上がることは求めない）

- 1〜4 を満たす → 差し替える
- 4 が未達 → **差し替えない**（コース固有性ではなく値の分散が効いているだけ）
- 1〜3 のどれかが未達 → 「手書きを消して中立値にする」案だけ別途検討
  （作り話をしない、という観点では手書きの誤った値より中立値のほうが良い）

⚠ AUC が上がっても回収率が上がるとは書かない（North Star #9）。
⚠ 「向きが正しくなった」ことは採用根拠にしない。数字で通ること。

# C-2: 枠順バイアスに surface を入れる（🔴 こちらのほうが筋が良い）

## 見つかった defect

本番の `_post_zone_bias` のキーは **`(venue, dist_zone)`** で、**surface を持っていない**
（`engine.py:238` / `engine.py:1475` の `_post_zone_bias.get((rc, zone))`）。

`course_ledger.json` で同じ競馬場・同じ距離帯の芝とダートを突き合わせると:

```
競馬場×距離帯         芝 内−外    ダ 内−外      差
小倉_~1400        -1.83     +8.11    -9.94
中山_~1400        +4.86     -2.24    +7.10
福島_1401-1800    +5.37     -1.33    +6.70
中山_2201~        +5.01     -0.77    +5.78
中京_~1400        +2.63     -2.95    +5.58
中京_1401-1800    +3.37     -1.74    +5.11

  符号が芝ダで逆のセル 12 / 25
  |芝−ダ| 中央値 2.43pt / 最大 9.94pt
```

🔑 **半分のセルで正反対の信号を平均して打ち消している。**
これは値が間違っているのではなく**集計の粒度が足りない**ので、
C-1（値の差し替え）より defect としてはっきりしている。

## なぜ優先度が高いか

`f_post`（枠順）は 2026-08-17 の **129軸総当たりで2年連続・同符号で FDR を通った唯一の軸**
（r≈+0.008〜0.010）。コース次元の中で独立の裏付けがあるのはこれだけ。
その1本が、打ち消しの入った表を引いている。

⚠ ただし 2026-08-06 に「**当日**の馬場バイアスを6特徴量で足す」は **−0.0005** で否定済み。
   今回はそれとは別で、**静的な枠バイアスの集計キー**の話。混同しないこと。

## 腕

- A: 現状 `(venue, dist_zone)`
- B: `(venue, surface, dist_zone)`
- 対照1: `(venue, surface, dist_zone)` の値を**セル間でシャッフル**
- 対照2: 枠バイアスを全セル共通の定数にする（＝コース差をゼロに）

## 判定（C-1 と同じ。結果を見る前に確定）

本番同型（residual・ドリフト注入ON）・3窓 × 3シード。

1. 悪化した窓がゼロ
2. 3窓平均 +0.002 以上（シードstdの2倍以上）
3. Brier・LogLoss も同じ方向
4. **対照1（シャッフル）を上回る** ← 必須
5. 複勝回収率が下がっていない（North Star #9。上がることは求めない）

⚠ セルを細かくすると1セルあたりの N が落ちる。`_build_and_save_stats` の
   最低サンプル数を決めてから測ること（決めずに測ると細分化＝過学習になる）。
⚠ AUC が上がっても回収率が上がるとは書かない。
