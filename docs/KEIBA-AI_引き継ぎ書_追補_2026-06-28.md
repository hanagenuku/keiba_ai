2026-08-09③「対になっている処理は片方だけ直される」）と同じ構造です。
そのため二重管理をやめ、**CLAUDE.md を唯一の情報源**にしました。

## ここにしか無いもの：新しいセッションの始め方

CLAUDE.md はプロジェクトの内容を書く場所なので、
「セッションの立ち上げ方」だけこのファイルに残します。

### セッション開始チェックリスト

- [ ] `CLAUDE.md` を読んだ（特に North Star と「過去に試して撤回した判断」）
- [ ] 作業ブランチを作成した（**main へ直接pushしない**）
- [ ] 提案する前に、同じ提案が過去に否定されていないか撤回表で確認した
- [ ] 数字を引用する前に、実データ・実ログで裏を取った

### コピペ用：最初の指示文テンプレート

新しいセッション（特にこのリポジトリに直接触れない相談用セッション）を
始める際は、以下をそのまま最初のメッセージとして貼ると前提がずれにくい。

```
このセッションでは hanagenuku/keiba_ai (JRA競馬AI予想システム) を扱います。
作業前に必ず CLAUDE.md の「🌟 North Star」セクションと
「過去に試して撤回した判断」一覧、および DESIGN.md の
「6. やってはいけないこと」を確認してください。

特に以下は厳守：
- 市場オッズを特徴量に追加しない
- コード変更は作業ブランチ→PR→CI確認→mainマージ（main直pushしない）
- データなしの特徴量追加をしない。追加するなら学習/推論パリティを確認する
- スクレイピングの新規リクエスト元には必ず件数上限(budget)を設ける
- 小さいNの好成績を信じない。採用前に大規模out-of-sample検証を通す

過去に同じ提案が試されて撤回されていないか、
CLAUDE.mdの「過去に試して撤回した判断」を先に確認してから提案してください。

今回の依頼: 【ここに具体的な依頼内容を書く】
```
