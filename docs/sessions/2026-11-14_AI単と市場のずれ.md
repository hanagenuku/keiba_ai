# 2026-11-14 AI単と市場のずれは何で説明できるか

ユーザーの問い: AI単体の評価と市場の評価が大きく違うときがある。市場が正しいとしたとき、AI単体は何か情報が抜けているはず。それは何か。

- 記述統計として測った（`hitrate/EXPLORE_solo_market_gap.md`）。モデル・買い目・表示は変えていない。
- 2025-01-05〜2026-11-08・6,227レース・83,518頭（2024-08-31 までで学習したモデル2本: 本番同型の残差 R／市場なし F）。
- 結果: ①大きくずれた馬の実測は市場側に約85〜90%寄る ②アプリの AI単（R）のずれは 51.3% が既存特徴量で説明できる＝騎手・前走好走・厩舎は「無い」のではなく補正項の設計上「使っていない」 ③市場なしモデル（F）のずれは 66.4% が DB のどの変数でも説明できず、その部分が結果を当てている（AUC 0.7556→0.7569→市場 0.7949）④未使用変数の上乗せは +2.5〜3.5% で、最大は過去の人気。
- 途中で外した集計: 「休み明け」の場面（`f_days_since_last` が日数そのものではなく、条件が8万頭中5.9万頭に当たった）。
- 未測定: web 情報（追い切り評価・予想家の印・能力指数）が「説明できない66%」をどれだけ埋めるか。
