### 自動収集が止まっていた機序

1. 2026-09-25 に kayochin を不採用にした → 収集スクリプトは「不採用の情報源は集めない」仕様だった
2. 2026-09-28 の回は何も集めずに**成果物なしで成功**した
3. 以後の回は「直近の成功run」を復元元に選ぶ → 成果物が無い → 「復元できない」で失敗。これが毎週続いた
4. 蓄積していた非公開DB（811記事・134,874頭）は artifact の中にしか無く、**今は1つも残っていない**（API で 0 件を確認）

### 反映がゼロである理由

これまで測った3つの情報源（kayochin 指数・yosounohone 追い切り★・netkeiba 実オッズ）は、
採用基準を「複勝回収率100%超」に置いたため、すべて不採用になっている。
- yosounohone の★: ★付きの馬の3着内率 33.6% vs 同じレースの印なし 19.7%（信号は本物）。
  ただし市場人気に足しても AUC は 0.8060 → 0.8059 で**上乗せなし**、複勝回収率 85.0%
- 回収率100%超は、このプロジェクトでまだ一度も確認されていない。**この基準のままでは、どの情報源も採用されない見込み**

## 未解決のまま残したこと（ユーザーの判断が要る）

1. **反映の基準。** 「複勝回収率100%超」のままだと永久に反映されない。的中率（3着内率）や
   OOS の順位付け（AUC）で判定する基準に替えるかどうか。替える場合も、基準を先に登録してから測る
2. **予想家の印の出典。** 主要な予想媒体（スポーツ紙・netkeiba・umanity・競馬ブック）は
   robots か規約で取得できない。取れるのは個人ブログ・AI予想サイトが中心になる
3. kayochin の過去分（2023〜・834記事）は取り直し中。マージ後に手動で起動した1回目は 300記事・50,128頭・失敗0で成功（run 42706588935）。残りは2回目の手動起動と週次の実行で埋まる
4. 未着手の情報源14件に自動の収集器はまだ無い（朝の Routine が手で読む範囲に入れただけ）
