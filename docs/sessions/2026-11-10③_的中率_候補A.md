## 結論（全文は `hitrate/RESULTS_A.md`）

**不採用。しかも「効かなかった」ではなく「置き換える対象のレースが存在しない」。**

| 窓 | 評価レース | ◎が4番人気以下 |

R1 的中 59.69% / 回収 84.93%（Δ ほぼ 0）。R2（常に1番人気）59.41% / 85.02%。
採用基準は 1・2・3・4 が未達、5・6 は通過 → **不採用**。

### 🔑 なぜ存在しないのか（計測器ではなく事実）

残差学習は `予測 = base_margin(人気順位) + AI補正`。実測で
`base_margin の SD 0.873` に対し `AI補正の SD 0.580` で、レース内の1番人気と2番人気の
base_margin 差（約0.9 logit）を覆せない。結果:

| M 窓・seed42（3,442レース） | 一致率 |
|---|---:|
| モデルの軸 == **モデルが見ている人気の1位** | **99.1%** |
| モデルの軸 == 確定人気1位 | 70.8% |
| モデルの軸 == AI単独（`ability_margin`）1位 | 31.2% |

**本番データで独立に確認した**（`data/latest.json` の git 履歴・2026-10-03〜11-08 の15開催日）:
◎ == 人気1位が **96〜100%**、**4番人気以下は全日0本**。
→ 記録にあった「残差学習では RL1 がほぼ市場上位人気に収束する」（2026-08-20）を
**「1番人気そのもの」まで詰めた**。市場とずれるのは ◎ ではなく `AI単` のほう。

### 🔴 `logic2026/RESULTS.md` §3 の読み方を訂正した

あの表（◎の人気 1番 1,773 / 2〜3番 580 / **4番以下 303**）は `va['f_popularity']`＝
**確定人気**で帯を作っている。モデルが見ているのは朝オッズ相当の人気なので、
**303本は「AI が市場と食い違ったレース」ではない**。同じ2026年の窓をモデルが見ている人気で
切ると 1〜3本しか無い。正しい読み方は
**「朝の1番人気が確定までに4番人気以下まで売られたレース」**で、そこが荒れるのは市場側の事実。

⚠ 「AI が強気な側ほど悪い」という既存の6回の再現は否定されない（それらは `ability_margin` や
`solo_rank` など**市場と独立な順位**で測っている）。否定したのは**あの表の読み方**だけ。
