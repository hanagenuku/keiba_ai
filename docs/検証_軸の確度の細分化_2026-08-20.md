# 事前登録：軸の確度による細分化＋掛け金の段階化（2026-08-20）

## 問い
既に採用済みの「軸の確度 top3_prob >= 0.55 で下位半分を見送る」より内側で、
確度をさらに細分化すると回収率は単調に上がるか。上がるなら掛け金を段階化する
価値があるか。

## 掛け金を変える2つの正当化を分けて判定する
- (a) 配分の傾斜（損を減らす）: 高確度ほど厚く。100%未満でも加重平均は改善しうる
- (b) 増額（勝つ）: そのビンの回収率が100%を超えていなければ正当化されない

## 採用基準（結果を見る前に確定。すべて満たさなければ「実装しない」）
1. 確度ビン間で回収率が**単調**（最上位ビン > 最下位ビン、かつ逆転が1箇所以内）
2. 各ビン **N >= 100レース**
3. 期間を前半・後半に割っても**順序が保たれる**
4. 最上位ビンが**上位3本の高配当を抜いても**最下位ビンを上回る
5. (b)を主張するには最上位ビンの回収率が**100%超**、かつ4を満たすこと

## 測定方法
- 対象: 本番が実際に出した予想（race_predictions, 2026-06-27〜08-16）
  ※すべて各時点のモデルにとって out-of-sample
- 確度: RL1 の `fuku_prob`（= top3_prob。ev_filter が実際に見ている値）
- 買い目: 軸1頭ベース構成を race_predictions の値から再構成
  （単勝=軸1点 / 複勝=軸1点 / ワイド=軸×中穴 最大3点 /
    三連複=軸-中穴2-(RL2..9+中穴)）
- 配当: `race_dividends` の実配当（組番一致で判定）
- 中穴 = 単勝 7〜30倍 のうち cal_prob 上位

## 事前に分かっている限界（結果次第で言い訳にしない）
- 本番データは約8週・N は多くて500レース強。ビンを割ればすぐ小さくなる
- ワイドの的中は15%前後なので、1ビン150レースでも的中は20本程度
- したがって**この検証だけで実装は決めない**。基準を満たした場合でも、
  2,000レース規模の再現（2025年末まで学習→2026年で評価）を通すこと
