## 3. レース選択も市場に負ける（唯一残っていた優位が消えた）

同じ本数（241レース）を、AIのゲートで選ぶか、市場だけで選ぶかを比べた。
市場側の選び方は「1番人気の市場示唆勝率が高い順」＝**モデルを一切使わない**。

```

市場だけ(1番人気の確率順)     AI軸       241   95.8%  [88.0, 104.3]
市場だけ(1番人気の確率順)     市場1番人気  241   97.8%  [91.7, 104.6]

AIのゲート                  AI軸       239   81.0%  [77.1, 84.7]
市場だけ                    AI軸       239   87.2%  [81.5, 92.6]
無作為に同数                AI軸       239   86.0%  [78.3, 95.4]

対応のある差（日ブロックbootstrap）
  単勝: AIゲート − 市場ゲート = -6.0pt  95%CI [-19.0, +4.6]
  複勝: AIゲート − 市場ゲート = -6.1pt  95%CI [-12.7, -0.2]   ← CIが0を含まない

🔴 **複勝では市場のゲートが有意に上。AIのゲートは無作為とも区別できない。**
選んだレースの中身も、1番人気オッズ中央値 2.70倍（AI）vs 2.60倍（市場）でほぼ同じ。

⚠ これは 2026-08-18② の「自信度AUC 0.6041 > 市場のみ 0.5708 (N=3,560)」と矛盾しない。
あれは**当てやすさ**の測定で、これは**回収率**の測定。North Star #9 のとおり別物だった。

```

**2026-07-09（f_popularity を特徴量に入れて AUC 0.68→0.82）の直後の開催日から、
順位相関が 0.25〜0.56 → 0.89 に跳んでいる。** 07-14の残差学習移行後もそのまま。

⚠ **これはバグではなく設計の帰結。** 残差学習は `logit(p) = base_margin(市場) + ability_margin(AI)`
で市場を土台にする。`ability_margin` のレース内の幅が `base_margin` の幅より小さければ、
順位は市場人気で決まる。

⚠ **ただし CLAUDE.md の「維持率99.5%＝予測力の99.5%は独自情報」は、この事実と両立する。**
あれは f_popularity を抜いたときの **AUCの維持率**であって、**出力の順位が市場と違うか**は
別問題だった。**AUCが保たれることと、市場と違う馬を選ぶことは別。**

## 5. 選択汚染を直接測った

同じルールを、決定に使った期間と使っていない期間で比べる：

```

```

⚠ 標本のプール回収率（全馬に単勝を買った場合）が 61.4% と 77.3% で大きく違う。
標本の運を打ち消すと ρ は **IN 1.251 → OOS 1.161**。

つまり **ρ で 0.09 ぶん（回収率で約7pt）の選択汚染があった。**

## 7. 限界（正直に）

- **N=295レース / 9開催日**しかない。CIは広い
- 有意なのは **複勝の「AIゲート − 市場ゲート = −6.1pt」1つだけ**
- ただし**すべての比較で符号が同じ**（AIが市場に劣る方向）で、偶然の並びとしては揃いすぎている
- 「AIに価値が無い」ではなく「**AIを外して市場1番人気を買っても同じ結果になる**」が正確

## 8. GPTとの合意に照らした分岐

議論で事前に決めた分岐条件：

> A：現在地が100%未満で、かなり大きく下回る → 損失最小化戦略への転換を真剣に検討
> B：100%近辺 → オッズ時系列・パドックの調査に価値がある
> C：すでに100%超 → CI下限などで確認

**結果は A と B の境界**：単勝 89.8%（あと10.2pt）、複勝 81.0%（あと19.0pt）。

そして**必要量の見積もりが変わった**：

```
これまでの前提: ρ=1.17 → 必要な改善は相対 +7%（AUC +0.0225 相当）
今回の実測:     ρ=1.12（単勝）/ 1.01（複勝）
                → 必要な改善は相対 +12%〜+24%（AUC +0.038〜0.075 相当）
                = 3ヶ月で採用に至った全成果（+0.0093）の 4〜8倍
```

⚠ **「必要な優位の80%は取れている」は撤回。実際は 50〜65%。**
