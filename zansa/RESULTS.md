# Z: 市場残差に「発走地点」の系統的なずれはあるか（2026-09-15）

基準は `zansa/CRITERIA.md` に**結果を見る前に**書いた。

## 問い

ペース診断で、前半600mのクセが **(会場, 馬場, 実距離) ごとの固定オフセットで
97% 説明できる**と分かった。同じことが**市場の値付け**でも起きているか。

- 起きていれば → 市場の系統的な盲点。コース情報を本体に戻す根拠
- 起きていなければ → 市場は発走地点を織り込んでいる。コースDBの価値は
  「説明と外挿」に確定する

---

## 🔴 1回目（z1.py）の設計は構造的にゼロしか返せなかった

「セルごとの市場残差の平均」で測り、ρ=+0.136 (P=0.27) / std=0.220pt / 同符号5/10 と
全滅したが、**この数字は採用も棄却もできない**。

1レースで3着内は必ず3頭。期待値が較正されていれば**レース内の残差の和は ≈0 に固定**される:

```
レース内の残差の和   平均 -0.23pt  std 16.4pt  （|和|<5pt が 87.5%）
1頭あたりの残差 std  36.6pt  → 18頭が独立なら和の std は 155pt のはず
n=1000頭のセルの標準誤差（独立仮定） 1.16pt
実際に観測されたセル間の std        0.22pt   ← 独立仮定の 1/5
```

会場・馬場・距離は**レース内で一定**なので、その単位でまとめると
**市場が何をしていようが平均残差は0に潰れる**。

### 🔑 対照群はこれを捕まえられなかった

`基準4`（セルのラベルをシャッフル）は ρ≈0 で「✅ 計測器は正常」と出たが、
**偽セルも同じ理由で0になる**ので何も検査していなかった。

> **対照群を置いたら、次に「本物があったらこの計測器は検出できるのか」を問うこと。**
> 対照群は「偽の相関が出ないか」を見る道具であって、
> 「本物でも必ず0になる設計か」は見てくれない。

以降、この確認を **対照群B（効果の注入）** として基準に加えた。

---

## 2回目（z2.py）: レース内で変わる属性で測り直す

市場は1レースで3枠を配るだけなので、会場が「3着内の総数」を動かすことはできない。
動かせるのは**誰に配るか**。今日のペースの発見から最も自然な属性は**先行度**。

```
先行度   その馬の**それ以前の**走りの1角通過位置の平均（shift().expanding()）
        1.0 = 先頭寄り / 0.0 = 最後方寄り。レース前に手に入る
傾き    セル内で市場残差を先行度に回帰した傾き（pt / 先行度1.0）
        ＝「前に行く馬ほど市場評価より走るか」
前期 2023-2024（66,640頭） / 後期 2025-2026（64,806頭）※重複なし
セルは前期・後期とも n>=300頭 → 70セル
```

### 結果

```
基準1 持ち越し   ρ=+0.158  P=0.2019  n=70        ❌
基準2 大きさ     後期 std = 7.11pt (>=3.0pt)      ✅
基準3 上位10     同符号 6/10 (7以上が必要)         ❌
基準4 対照群A    偽の先行度で ρ 平均 -0.000        ✅
基準5 対照群B    注入した効果を検出 +4.83→+14.14pt  ✅
基準6 セル数     70                              ✅
```

**計測器は動く。それでも持ち越さない。**

### 🔑 基準2が通ったのは、傾きの分散が全部ノイズだから

```
観測されたセル間の傾きの std           7.07pt
先行度をレース内でシャッフルした偽データ   6.76pt （10回: 5.96〜7.81）
                          観測 / ノイズ = 1.05 倍
```

**見かけの分散は、ほぼ完全にノイズで説明できる。** 基準2は「大きければ本物」を
仮定していたが、それは誤りだった（大きさだけでは本物かどうか決まらない）。

前期で選んだ上位セルの符号反転もそのとおりの形:
```
会場 馬場 距離          前期      後期     後期n
札幌 ダート 1000    -18.75    -5.51      369
阪神 芝 1200       +12.72   -14.53      389   ← 符号反転
京都 芝 1400       +10.96   -10.61      580   ← 符号反転
函館 ダート 1700    +12.40    -7.40      826   ← 符号反転
札幌 芝 2000       +15.66   +14.86      531   ← これだけ持ち越している
```

---

## 判定

**発走地点ごとに市場が系統的にずれている、という証拠は無い。**

ペースとの対比が決定的:

| | 発走地点ごとのオフセット | 持ち越し |
|---|---|---|
| **前半600m（市場アンカー無し）** | std 0.24秒（残差 std 0.83秒の29%） | **ρ=+0.819 (P=0.0005)** |
| **市場残差 × 先行度（市場あり）** | std 7.1pt だが**ノイズの1.05倍** | ρ=+0.158 (P=0.20) |

🔑 **コースは前半600mを強く決める。しかし市場はそれを完全に値付けしている。**

## 副産物: 「前に行く馬ほど市場評価より走る」は全体でも不安定

```
2023  n=31,402  傾き -0.98pt
2024  n=35,238  傾き +1.66pt
2025  n=38,766  傾き +1.26pt
2026  n=26,040  傾き +2.66pt
```
2023年だけ負で、以降は正だが振れる。⚠ 仮に +2pt が本物でも
2026-08-18 の「回顧」の上限 +1.18pt（複勝回収74%止まり）と同じ桁。
2026-08-24 の「先行 × 実力上位 × 4-9.9倍」も回収76.9%で否定済み。

## 含意（ユーザー提示の進め方に対して）

> ⑤ 市場残差×コースで本当に市場の系統的な盲点が見つかった場合だけ、
>    そのコース情報を本体に戻す

**見つからなかったので、戻さない。**

→ コースDBの価値は **①ペースモデル ②説明 ③観測の薄い組み合わせへの外挿** に確定。
   本体モデル（3着内）の精度向上は目的から外す。
   これは今日の別の測定とも整合する:
   - 本体に会場 one-hot を足すと **−0.0003**（残差学習で市場が既に知っているため）
   - 本体に P(先頭) を足すと **−0.0006**
