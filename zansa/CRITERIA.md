# Z: 市場残差に「会場×馬場×実距離」の固定オフセットはあるか

⚠ **結果を見る前に書いた。** 数字を見てから基準を足さない。

## 問い

2026-09-15 のペース診断で、前半600mのクセが
**(会場, 馬場, 実距離) ごとの固定オフセットで 97% 説明できる**と分かった。
同じことが**市場の値付け**でも起きているか。

- 起きていれば → 市場の系統的な盲点。コース情報を本体に戻す根拠になる
- 起きていなければ → 市場は発走地点を完全に織り込んでいる。
  コースDBの価値は「説明と外挿」に確定する

🔑 これは今日の測定「本体に会場one-hotを足すと −0.0003」と**別の問い**。
   あちらは「XGBが会場を使えるか」、こちらは「市場が会場×距離で系統的にずれるか」。
   残差を直接見る方が、木が拾えなかっただけ、という可能性を潰せる。

## 測り方

```
期待3着内率   前期(2023-2024)の「人気 × 頭数帯」の実測表から引く
市場残差      実測3着内(0/1) − 期待3着内率          （単位: pt）
セル          (会場, 馬場, 実距離)
オフセット     セル内の市場残差の平均
```

- **前期 2023-2024 / 後期 2025-2026。重複なし。**
  （lap_times と違い popularity は全期間あるので、ここは4年使える）
- 期待値テーブルは**前期だけ**で作る（後期の情報を混ぜない）

## 事前に決めた判定

1. **持ち越し**: 前期のオフセットと後期のオフセットの順位相関 ρ が
   並べ替え検定（2,000回）で **P < 0.01**。
2. **大きさ**: 後期のオフセットの **std >= 1.0pt**。
   これ未満なら「あっても使えない」と書いて終わる。
   ⚠ 2026-08-18 の「回顧」の上限が +1.18pt で複勝回収74%止まりだった。
      1pt はその程度の意味しかない、という目安。
3. **選択汚染を避けた確認**: **前期だけ**で |オフセット| 上位10セルを選び、
   後期でその平均残差が同符号か。10セル中7以上で同符号なら通過。
4. **対照群**: セルのラベルを人気帯の中でシャッフルした偽のセルでは
   ρ ≈ 0 になること。ならなければ計測器が壊れている。
5. **セルの大きさ**: 前期・後期とも **n >= 300頭**。
   ⚠ 3着内率 22% なら n=300 で平均の標準誤差は約 2.4pt。
      n が小さいセルは偶然のオフセットを量産する。
6. **回収率は見ない**（North Star #9）。残差は pt で書く。

## ⚠ 自分への注意

- 🔴 **大きなオフセットが出たら、まず「そのセルに特定の馬・厩舎・時期が
  偏っていないか」を疑う**。会場×距離は開催時期と強く結びついている
  （札幌・函館は夏のみ等）ので、季節や開催回次の効果を会場の効果と
  取り違えうる。
- 🔴 基準2を満たしても、それは「市場が系統的にずれている」までであって
  「買える」ではない。買えるかは別の大規模検証が要る（North Star #7）。

# 🔴 上の設計は壊れていた（実行後に判明・記録として残す）

結果は 基準1 ρ=+0.136 (P=0.27) / 基準2 std=0.220pt / 基準3 同符号5/10 で全滅だったが、
**この設計は構造的にゼロしか返せない**と分かった。採用も棄却もできない。

## なぜ

1レースで3着内は必ず3頭。期待値テーブルが較正されていれば
**レース内の残差の和は ≈ 0 に固定される**。実測:

```
レース内の残差の和   平均 -0.23pt  std 16.4pt  （|和|<5pt が 87.5%）
1頭あたりの残差 std  36.6pt   → 18頭が独立なら和の std は 155pt になるはず
n=1000頭のセルの標準誤差（独立仮定） 1.16pt
実際に観測されたセル間の std        0.22pt   ← 独立仮定の 1/5
```

会場・馬場・距離は**レース内で一定**なので、その単位でまとめると
**市場が何をしていようが平均残差は0に潰れる**。

🔴 **対照群（基準4）はこれを捕まえられなかった。** 偽セルも同じ理由で0になるから。
   対照群は「偽の相関が出ないか」を見る道具であって、
   「本物でも必ず0になる設計か」は見てくれない。
   🔑 **対照群を置いたら、次に「本物があったらこの計測器は検出できるのか」を問うこと。**

## 正しい問いに直す

市場は1レースで3枠を配るだけなので、会場が「3着内の総数」を動かすことはできない。
動かせるのは **誰に配るか**。つまり測るべきは

> **発走地点ごとに、市場の「配り方」が特定の馬のタイプに対して系統的にずれるか**

これは**レース内で変わる属性**が要る。今日のペースの発見（発走地点が前半600mを決める）
から最も自然なのは **先行度**。

```
先行度      その馬のそれ以前の走りの「最初のコーナー通過位置」の平均（0=先頭〜1=最後方）
           shift().expanding() で当該レースを除外。レース前に手に入る
傾き        セル内で 市場残差 を 先行度 に回帰したときの傾き（pt / 先行度1.0）
           ＝「前に行く馬ほど市場評価より走るか」
```

# 事前に決めた判定（やり直し版）

1. **持ち越し**: 前期(2023-24)の傾き と 後期(2025-26)の傾き の順位相関 ρ が
   並べ替え検定（2,000回）で **P < 0.01**
2. **大きさ**: 傾きの後期 std >= **3.0pt**（先行度が0→1で3pt動く）
   ⚠ 先行度の実際の幅は概ね 0.2〜0.8 なので、3pt の傾きは実効 1.8pt 程度。
      2026-08-18 の「回顧」の上限 +1.18pt と同程度。これ未満なら使えない
3. **選択汚染回避**: 前期だけで |傾き| 上位10セルを選び、後期で同符号が7以上
4. **対照群A**: 先行度を**レース内でシャッフル**すると傾きが0付近になること
5. **🔑 対照群B（今回の反省から新設）**: **人工的に本物の効果を注入して、
   この計測器がそれを検出できるか**を確認する。
   特定セルの前寄りの馬の3着内を人工的に +5pt 増やし、傾きがそのセルで
   実際に動くことを見る。動かなければ計測器が壊れている
6. セルは前期・後期とも **n >= 300頭**
7. **回収率は見ない**
