## ✅ 事前登録していたゲート（D-1・スケールの一貫性）は通過した

2026-09-02 に「繋ぐ前にこれを確認すること」と書いた検査＝
**「未勝利の6点」と「重賞の6点」が同じ意味を持っているか**。

```
クラス別の平均点   未勝利 4.73 → 1勝 5.64 → 2勝 6.44 → 3勝 7.11 → OP 7.80
レース内std（中央値） 0.60      全頭同点のレース 0 / 47
```
**完全に単調。** 宣言どおりの絶対スケールで入力されている。

🔑 **含意: 生の点数をそのまま馬の評価に使ってはいけない。**
点数がレースレベルを含んでいるので「6点」は未勝利では上位・OPでは下位。
使うなら**レース内の偏差**（ps − レース平均）。

## 🔴 偏差の半分は市場の言い換え

```
corr(偏差, -log(人気))      = +0.513   （R² = 0.280）
corr(偏差, AIのcal_prob)    = +0.504
corr(偏差, 3着内)          = +0.246
（参考）corr(-log人気, 3着内) = +0.455
```
偏差帯ごとの平均人気 11.7 → 10.0 → 7.8 → 5.1 → 3.7。
複勝率は単調に上がるが（0% → 34.2%）、人気が上がっているためで新情報ではない。

## 🔑 いちばん重要な発見は「入力の使われ方」のほう

```
人気帯      N    減点率   加点率   平均偏差
1-3人気   133    1.5%   66.2%   +0.46
4-5        89   11.2%   50.6%   +0.22
6-9       173   35.3%   30.1%   −0.10
10+       198   47.0%   13.1%   −0.32

1番人気 44頭: 減点 1頭 / 並 9頭 / 加点 34頭
        実際の複勝率 72.7% ＝ 27% は飛んでいる
```
🔴 **人気馬はほぼ減点されない。** 1番人気44頭のうち減点は1頭だけ。
これが corr +0.513 の正体で、同時に**情報量を半分捨てている**。

市場が最も自信を持っているのは上位人気で、そこで食い違ったときが最も情報量が大きい。
飛ぶ27%の1番人気を事前に減点できるなら、それは市場が持っていない情報になる。
逆に人気馬を加点しても、市場が既に言っていることの追認にしかならない。
