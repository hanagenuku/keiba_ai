# data/private — 公開リポジトリに出さないデータ

このディレクトリは `.gitignore` で除外されている。**中身は git に入らない。**

## なぜ分けるか

`hanagenuku/keiba_ai` は**公開リポジトリ**で、`weekend.yml` /
`sunday-results.yml` は毎週 `git add data/` で data/ 配下を丸ごと
自動commit・pushする。そのため既存の `data/history.db` に書いたものは
自動的に公開される。

netkeiba の利用規約（2026-08-16に本文を実際に読んで記録）は、取得行為自体を
名指しで禁じてはいないが、**入手したデータの用途を私的利用に限定**している:

> サービスを通じて入手したいかなるデータ、情報…も、著作権法で認められた
> **私的利用の範囲を超える複製、販売、出版のために利用することはできません**。
> なお、著作物に該当しないデータ等であっても、サービスを通じて入手したものは
> 著作物とみなします。

「自分の予想モデルに使う」は私的利用の範囲内だが、
**公開リポジトリに置くのは規約が名指しした『複製・出版』にあたる。**
そのため netkeiba 由来のデータはここに置き、git には入れない。

## 置くもの

| ファイル | 中身 |
|---|---|
| `netkeiba.db` | netkeiba 由来の生データ（追い切り等） |

## 使う側の作法

**「あれば使う・無ければ NaN」**で degrade すること。このディレクトリは
GitHub Actions のランナーには存在しないので、**本番の週次ワークフローでは
常に不在**として動く。学習は Drive 側（Colab）で行う。

⚠ 派生した特徴量であっても、netkeiba の値をそのまま復元できる形のものは
公開リポジトリに置かないこと。
