## 5. 対照群（2つの形以外で書かない）

**対照群A ＝ 並べ替え分布**
```
レース内シャッフル 200 回。
合格: |mean(統計量_shuffle)| < 2 * std / sqrt(200)   ← 帰無が0中心
実測値は並べ替え P で報告する。
⚠ 「|β_shuffle| < |β|/3」のような1回の引きの大小比較は書かない
```

**対照群B ＝ 注入の復元**
```
既知の効果 δ を注入して復元できるか。
合格: 注入後 − 注入前 = δ（許容差 1e-3。代数恒等式の検算なので厳しくてよい）
⚠ 「注入後 ≈ δ」と書くと「その変数の素の効果は0」という測っていない仮定が入る
```

🔴 **対照群の合格基準を書いたら、その閾値が統計量自身の SE より大きいかを先に確かめる。**
SE より小さい閾値は「厳しい基準」ではなく「何も判定できない基準」。
