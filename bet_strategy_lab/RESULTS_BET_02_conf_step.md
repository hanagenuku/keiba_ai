# 🔴 判定: **測定不能**。中止条件3と4が発火し、回収率を1つも読んでいない

カード §7 のとおり、中止条件は**回収率より手前**で印字・判定する作りにしてあり、
ログのとおり ROI の表は1行も出ていない。事前の見込み（「段差なし・なめらかな坂」）は
**検証も反証もされていない**。

## 1. 発火した中止条件

```
🔴 W1: ビン 50-54 の N=0 < 300（中止条件4）    🔴 W1: ビン 55-59 の N=0
🔴 W2: ビン 50-54 の N=0 < 300                🔴 W2: ビン 55-59 の N=0
🔴 W3: ビン 50-54 の N=35 < 300               🔴 W3: ビン 55-59 の N=23
🔴 対照群B が +10.00pt を復元しない（中止条件3）
```

対照群B が W1・W2 で復元できなかったのは、**比較するビンが空だったから**
（Δ55 が None）。W3 では ✅ 47.27 → 57.27 ＝ **増分ちょうど +10.00pt** を復元しており、
払戻の配線そのものは正しい。

## 2. 🔴 原因① 私の計測器が本番の `conf` と**別物**を計算していた（仕様ミス）

| | 本番 | 今回の計測器 |
|---|---|---|
| 作り方 | `total`（合成スコア）→ **softmax(temperature=3.5)** → `win_prob` → **Harville** で top3 → `conf = top3×100` | 複勝モデルの**生の確率** `1/(1+exp(-margin))` × 100 |
| 出どころ | `engine.calc_all` → `app_json.race_confidence` | `logic2026/eval.py` の `prob` |

残差モデルの確率は `scale_pos_weight` のぶん**水準が系統的に高い**
（CLAUDE.md §3「残差モデルの確率の水準は切片の行き過ぎでずれている」）。
そのため軸の値がほぼ 70 以上に張り付き、**50〜59 のビンが空になった**。

🔴 **同じ名前の量を2か所で別々に作った**という、このプロジェクトが何度も踏んでいる形
（2026-09-22 / 10-19 / 10-21 / 11-09 / 11-10 に続く）。
カード §3 に「`conf = 軸の複勝確率 × 100`（`app_json.race_confidence` と同じ式）」と
書いておきながら、実装で別の確率を使った。**カードの文言は正しく、コードが違った。**

✅ 計測器の他の部分は健全だった: 軸AUC は3窓とも **0.8049〜0.8064**（中止条件2の
0.75〜0.82 の内側）、評価レースは 1,253〜1,746本（中止条件1の800本以上）。

## 3. 🔴 原因② 直しても**今のデータでは測れない**

本番と同じ `conf` を持っているのは `race_predictions` だけで、**2026-06-27〜11-23 の
1,432レースしか無い**（それ以前のレースには本番の conf が存在しない）。

その1,432レースでの `conf` の分布:

| ビン | <=39 | 40-44 | 45-49 | **50-54** | **55-59** | 60-64 | 65-69 | >=70 |
|---|---:|---:|---:|---:|---:|---:|---:|---:|
| レース数 | 96 | 33 | 42 | **219** | **411** | 284 | 167 | 180 |

- 隣接差 Δ(55) を読むのに要る `50-54` が **219本 < 300**（中止条件4に再び触れる）
- そもそも**窓が1つしか無い**ので、カード §5 の「3窓すべてで符号が揃う」が判定できない

→ **カードの合格線を満たすデータが存在しない。**
🔴 線を下げて読むことはしない（結果を見てから閾値を動かさない）。

## 4. 過去レースの `conf` を作れないのか

作るなら `engine.calc_all` をウォークフォワードで全レースに回すことになる
（合成スコア → softmax → Harville を本番と同じ経路で再現する）。可能ではあるが:

- 窓ごとにモデルを差し替えて 12,613レースぶん回す大きな工事
- `horse_dist_dict` など**キャッシュ経由のリーク経路が増える**（North Star #8）
- それでも、**測れるのは「段差があるか」だけ**で、どの帯も回収率100%未満という
  事実（2026-11-25 の記述統計・45マスでゼロ）は動かない

**費用に見合わないので、今はやらない。**

## 5. この測定から言えること・言えないこと

| | |
