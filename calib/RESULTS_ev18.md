# 勝率予測 18%以上 × EV(=勝率×オッズ) > 1.00 の回収率

ユーザーの問い（2026-09-11）。事前登録した検証ではなく、**指定された1セルの実測**。
読み取り専用・本番コード変更なし。

母集団は `calib/RESULTS_ability.md` の⑦⑧⑨と同じ
**単勝・実オッズ W1（2026-07-04〜09-06）8,703頭 / 667レース / 20開催日**。
買う判定は**朝オッズ**、払戻は**確定配当**。勝率は画面と同じ E1 Isotonic（`ev_tan_pct`）。

## 答え: **79.1%**

全部買う 73.1% より **+6.0pt**。だが100%には届かない。

## 🔴 その +6.0pt は「勝率18%の床」が全部で、EVの寄与はゼロ

3つが同じ 79.1% に並んでいるのは丸めではない。生の払戻で検算した:

```
EV>1.00     N=716  的中 98  払戻合計 ¥56,650  回収 79.1201%  オッズ中央値 8.3倍
EV<=1.00    N=434  的中146  払戻合計 ¥34,320  回収 79.0783%  オッズ中央値 2.8倍
全体        N=1150 的中244  払戻合計 ¥90,970  回収 79.1043%  オッズ中央値 5.6倍
```

**買う側と買わない側の差は 0.04pt。** EVフィルタは1円も生んでいない。

### 機序（完全に特定できた）

Isotonic較正後の勝率は 18%以上の帯で**ほとんど一定**になる。
実際、EV>1.00 側と EV<=1.00 側で **p の中央値が 0.2357 と 0.2357 で完全に一致**する。

```
corr(EV, オッズ) = +0.9705     corr(EV, 勝率) = +0.0334
```

つまりこの帯の中では **EV = p × オッズ ≒ 定数 × オッズ** で、EV条件は
`odds > 1.0/0.18 = 5.56倍` という**純粋なオッズフィルタ**でしかない。

🔑 そしてオッズで割っても回収率が動かない。
**オッズ中央値が3倍（2.8→8.3倍）、的中率が2.5倍（33.6%→13.7%）違うのに、回収率は同じ。**
2026-08-18③「市場は全部の隅を同じ値段にしている」の、これまでで最も鮮明な実例。

⚠ これは 2026-08-31（本番8,546頭で EV>=1.0 が57.9% / EV<1.0 が75.0%）とは形が違う。
あちらは勝率の床が無いので EV が「人気薄を指す」方向に暴走していた。
勝率で床を張ると暴走は止まるが、**止まった先に何も残らない**。

## 🔴 対照群（市場）: 同じことを市場でやると AI より上

```
腕                    勝率>=18%      N      回収率   3本抜     95%CI
参考M 市場              示唆確率で      800    83.2%   80.7%   [75, 91]
E1 Isotonic（AI）     AI確率で      1150    79.1%   73.9%   [71, 88]
```

重なりで分けると向きがはっきりする:

```
AIだけが18%以上    707頭  回収 76.8%
両方が18%以上      443頭  回収 82.7%
市場だけが18%以上   357頭  回収 83.9%
```

**AIが市場から離れるほど回収率が下がる。** E-3（馬連 AI 60.5% vs 人気順 71.4%）・
2026-09-01（不人気馬 AI 72.9% vs 市場 73.0%）・GAP と同じ形に、また別経路で着地した。

★セルの人気内訳も「AI独自の発見」ではない: 2-3番人気 39.5% / 4-5番人気 34.1% /
6-9番人気 18.4% / 10番人気〜 **0.1%（1頭）**。実体は「中位人気を買う」。

## 18%は特別な値ではない

## 判定

- **答えは 79.1%**。全部買うより +6.0pt だが控除率（100%）には 21pt 足りない
- 🔴 **+6.0pt はすべて「勝率18%以上」の床から来ていて、EV条件の寄与は 0.04pt**
- 🔴 同じことを市場示唆確率でやると 83.2% で、AIより **+4.1pt 良い**
- ⚠ N=716・20開催日・CI[64, 95]。閾値を 9×3=27 セル見ている
- **採用しない。** 画面の必要オッズ列も「買い推奨」としては出さない方針のまま
