状態: **未測定**（この文書を書いた時点で勝率を1つも計算していない）
作成: 2026-10-16
きっかけ: ユーザー指示「危険な人気馬は1着にきてはならないを測ってくれ」

## 0. 🔴 最初に読むこと：これは独立した母集団ではない

**B期間（2025-01-05〜2026-10-12・6,077レース・83,547頭）は 2026-10-16 に
3着内率で既に読んでしまっている**（`danger/RESULTS.md`）。
そして **1着は3着内の部分集合**なので、この測定は

> 既に見たデータを、別の切り口でもう一度見る

ことになる。North Star #8 の「結果を見てから測定器を足さない」に正面から当たる形なので、
**この測定の結果を「新しい独立した証拠」として書かない**。
書いてよいのは「同じデータを1着で切り直すと、こういう数字になる」まで。

🔑 それでも測る理由は、**主張が違う**こと。
3着内の測定は「高い確率で3着内に来てはならない」を測って不採用になったが、
「1着に来てはならない」は**より弱い主張**で、同じデータでも通りうる。
通った場合に何と書けるか／書けないかを、先に決めておくのがこの文書の目的。

⚠ **測ったあとに期間・条件・閾値を変えて測り直さない。** 測定は1回。

## 2. 測定器（結果変数）

**勝率 = `place == 1` の割合。**

- 該当群: 条件に当たった市場1番人気
- 比較群: **同じレース群の市場1番人気のうち条件に当たらなかった馬**
  （3着内の測定と同じ定義。`danger/RESULTS.md` で「全馬をベースラインにすると
  ±1.6pt の系統誤差が入る」と確認済みなので、人気帯を揃えた比較群を使う）
- β = 勝率(該当) − 勝率(非該当)、単位 pt

既存の記録から読める参考値（**この測定の合格基準ではない**）:

| | 勝率 |
|---|---|
| 市場1番人気 全体 | **31.9%**（2026-08-03・603レース） |
| 朝の1番人気 | 26.5%（2026-08-03・約2,000レース） |
| 直前の1番人気 | 34.9%（同） |
| 全馬（1/頭数の平均） | 約 7% |

⚠ 「1番人気の勝率」は朝か確定かで 26.5〜34.9% と動く。
**B期間の非該当1番人気の実測値を比較群として使い、記録の 31.9% は参照のみ。**

## 3. 合格基準（結果を見る前に確定）

「1着に来ない」と商品に書けるかどうかは、**水準**で決める。差の大きさではない。

| # | 基準 | 合格線 |
|---|---|---|
| **1a** | **強い主張**「1着に来ない」と書ける水準 | 該当群の勝率 **10%未満** |
| **1b** | **弱い主張**「1番人気としては勝ちきれない」と書ける水準 | 該当群の勝率 **16%未満** |
| 2 | 標本 | N >= 300 |
| 3 | 安定性 | 前半(2025) / 後半(2026) **両方**で 1a または 1b を満たす |
| 4 | 層別 | 頭数層（〜9 / 10-13 / 14〜）とクラス層で**符号が反転しない** |
| 5 | 対照群A | レース内 `solo` シャッフル200回の帰無が0中心（`\|mean\| < 2*std/sqrt(200)`） |
| 6 | 対照群B | 注入の復元（経路・効果量とも `注入後 − 注入前 = 注入量`） |

### 閾値 10% / 16% の根拠（後から決めていない）

- **10%**: 全馬の平均勝率が約7%。「1番人気なのに全馬並み」まで落ちれば
  「来ない」と読者に言える水準。7% を少し上に丸めた値
- **16%**: 1番人気全体 31.9% の**半分**。
  3着内の測定で「68.5%→51.4% は半分以上来るので『来ない』とは書けない」と判定した
  のと同じ考え方を勝率に当てた（半分を割れば「勝ちきれない」と言える）

⚠ **1a も 1b も通らなければ、記事の文面は変えない**（いまの
「市場の支持ほどAIは評価していない馬」＋ 3着内の数字のまま）。
その場合**閾値を下げて書けるようにしない**。

## 4. 副次（判定に使わない）

- **単勝回収率**: 該当群を単勝で全部買った場合の回収率。
  ⚠ `tansho_payout` は保存済みの中間ファイルに無いので `data/history.db` から取り直す。
  **回収率は基準に入れない**（North Star #9: 的中と回収は別物。
  かつ単勝プール平均は控除率20%で80%なので、どう転んでも100%は超えない）
- **◎との重なり**: 該当群のうち `rl_rank == 1`（記事の◎自身）の割合と、
  ◎ / ◎以外での勝率。3着内では **88.2% が◎自身**だったので、勝率でも同じ分解を出す
- **`rl_rank>=2` の寄与**: 3着内では 10.0% を作っていたのは `solo_rank` ではなく
  `rl_rank>=2` だった。勝率でも同じ分解を出す
- **標準ゲート**（市場単独 / AI単独 / AI×市場）と方向別は、
  3着内の測定（`danger/RESULTS.md`）で既に出してあるので**再掲のみ**。
  1着のための新しい学習はしない（同じモデル・同じ3窓・同じ行を使う）

## 5. 使うデータと計算

- **既に保存してある行**（`danger/bperiod.py` が出力した `_rows.csv.gz`）を使う。
  **モデルの再学習はしない**（3窓・`best_iteration=10`・seed 42 のまま）
- 列: `place` が入っているので勝率はそのまま計算できる
- 変種は **`win`（本番相当：確定人気そのまま）を主**とする。
  ドリフト注入版（`drift`）は 3着内の測定で
  **「1番人気」の31.6%が実際には別の馬**という合成物だと分かっているので**副次扱い**、
  かつ「確定1番人気に揃えた場合」も併記する
