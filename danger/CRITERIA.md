# 事前登録カード：「危険な人気馬」の条件を測り直す

- 登録日: 2026-10-15
- 状態: **未測定**（測定の実施はユーザー判断待ち）
- きっかけ: ユーザー指示「危険な人気馬は高い確率で3着内にきてはならない。
  現状のロジックで頻繁に3着内に来るならみなおしが必要」

---

## 0. なぜ測り直すのか（現状の2つの問題）

### 問題① 実測そのものが「高い確率で来ない」を支えていない

現在の条件は `marks.DANGER_MAX_POP = 1` / `DANGER_MIN_SOLO = 6`
＝ **市場1番人気** かつ **市場を見ないAI単独の評価が6位以下**。

唯一の根拠は 2026-08-29 の walk-forward 実測で、**3着内率 68.5% → 51.4%**
（N=242・73開催日）。落ち幅17ptは本物だが、**51.4% は半分以上が3着内に来る**。
商品に「危険」と書いて読者が期待する水準ではない。
🔴 つまり「ロジックが悪化した」のではなく、**最初から 51.4% しか測れていない**。

### 問題② 条件に当たる馬の大半が、その記事の ◎ 自身だった

`data/danger_favorites.json`（本番の台帳・2026-10-10〜12 の11件）を分解した実測:

| | 3着内 |
|---|---|
| ◎ と同じ馬（`rl_rank == 1`） | **8/9** |
| ◎ ではない（`rl_rank >= 2`） | 1/2 |
| 全体 | **9/11** |

`danger_favorites()` は `rl_rank` を見ないので、**AI総合（市場込み）で1位＝
その記事が軸に推している馬**が、同じ記事で「危険」と名指しされる。
2026-10-12 京都9R で実機確認（12テイエムサンレーヴ が ◎ かつ 危険な人気馬）。

9/11 は p=0.514 の下で P(X>=9) = **4.0%**、範囲内 4/4 は P = **7.0%**。
⚠ **N=11 なのでこれ自体は証拠にならない**（North Star #7）。
記録する理由は、向きが一方に揃っていることと、②が測定なしで分かる構造だから。

## 1. 仮説

> 「市場1番人気 × 市場を見ないAIが下位」を**もっと強い条件に絞れば**、
> 3着内率を「高い確率で来ない」と書ける水準まで下げられる。

## 2. 🔴 着想の出所を先に開示する

**V2（◎ を除く）という案は、本番11件を見てから思いついた。**
そのため A期間・本番データで測ると選択汚染になる。
→ **測定は一度も読んでいない B期間（2025-01-01〜・5,932レース）で行う。**
（Betting Policy Step 1 で B期間を使わずに閉じたので丸ごと残っている）

## 3. 測る条件（**結果を見てから増やさない**）

| | 条件 |
|---|---|
| V0 | `pop == 1` かつ `solo >= 6`（現状） |
| V1a | `pop == 1` かつ `solo >= 8` |
| V1b | `pop == 1` かつ `solo >= 10` |
| V2 | `pop == 1` かつ `solo >= 6` かつ `rl_rank >= 2` |
| V3 | `pop == 1` かつ `solo >= 6` かつ `fit >= 6` |
| V4 | `pop <= 2` かつ `solo >= 6` |

6条件のみ。`solo` は `ability_margin` のレース内順位（市場非依存）、
`rl_rank` は総合、`fit` は `aptitude` のレース内順位。
🔴 **期間・閾値・母集団を測定後に動かさない。** 測定は1回。

## 4. 測定器（主張ごとに1つ・North Star #8）

| 主張 | 測定器 |
|---|---|
| 「高い確率で3着内に来ない」 | 条件に当たった市場1番人気の3着内率 |
| 「市場の言い換えではない」 | 市場単独 / AI単独 / AI×市場 の三者比較＋方向別 |
| 「警告の価値がある」 | その1番人気を**買わない**ことによる複勝回収率の差 |

## 5. 採用基準（**すべて満たさなければ不採用**）

1. 3着内率 **40%未満**（半分を明確に下回る。51.4%では「危険」と書けない）
2. N >= 300
3. 期間を前半/後半に割って**両方**で基準1
4. 市場人気を統制しても差が残る（1番人気の中での比較なので自動的に満たすが、
   オッズ帯で層別しても符号が揃うことを確認する）
5. 対照群A＝レース内シャッフル200回で帰無が0中心
   （`|mean| < 2*std/sqrt(200)`）/ 対照群B＝注入の復元（注入後 − 注入前 = 注入量）

## 6. 中止条件

- `solo_rank` を B期間で再現できない（学習/推論パリティが崩れる）場合は測らずに閉じる
- V0 の3着内率が B期間で 51.4% から大きく外れた場合、まず計測器を疑う
