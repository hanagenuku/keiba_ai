## 1. 仮説

市場1番人気のうち、**AI+市場の総合評価で1位にならなかった馬**（`rl_rank >= 2`）は
3着内率が低く、「消せる馬」として名指しできる水準に達している。

🔴 **事前の見込みは「不採用」**。理由: B期間では6条件すべてが基準1・2を同時に
満たさず、率が下がった条件（V1b・V2）はいずれも**前半と後半で崩れた**
（V2 は 2025年 50.0% → 2026年 6.5%）。本カードが測るのはその V2 の主成分である。

### 🔑 この計測器が `conf=55` のときのように壊れない理由

2026-11-25 の `RESULTS_BET_02_conf_step.md` は、本番の `conf`（**水準**＝
softmax→Harville で作る確率）を再現できず中止になった。
本カードが使うのは `rl_rank`（**順位**）と `popularity` だけで、
**順位はスコアの尺度に依存しない**。残差モデルの確率の水準がずれていても
順位は変わらない（CLAUDE.md §3「順位（AUC）は動かない」）。

## 5. 対照群（North Star #11）

| | |
|---|---|
| **A 並べ替え** | 市場1番人気の中で `rl_rank>=2` のラベルを**無作為に付け替える**（同じ頭数）× 200回。統計量は `Δ = 率(対象) − 率(1番人気すべて)`。合格は帰無が0中心＝`\|mean(Δ_shuffle)\| < 2*std/sqrt(200)` |
| **B 注入（オラクル）** | ラベルを「実際に3着内を外した1番人気」から同じ頭数だけ選んで付ける。合格は **率 = 0.00%**（±0.01）。本物の信号があればこの計測器は検出できる、の確認 |

## 6. 中止条件（1つでも発火したら率を読まずに止める）

2. 軸の複勝 AUC が **0.75〜0.82 の外**（`logic2026` の中止条件3と同じ線）
3. 対照群B が 0.00% を返さない

## 7. 合格したら何をしてよいか／いけないか

- ✅ してよい: 記事・アプリに**✕などの印で表示**し、「AIの総合評価で1位にならなかった
  1番人気」と事実を書く。実測の3着内率を必ず併記する
- 🔴 してはいけない: **買い目から外す**こと。
  「どの馬を代わりに買うか」は 2026-08-29 に測って
  **AIの推し 77.5% 対 避けた1番人気 75.9% ＝区別がつかない**（`danger/RESULTS.md` 末尾）。
  買い方を変えるなら別のカードが要る
- 🔴 してはいけない: 「来ない」「確実に消し」と書くこと。基準1を満たしても
  3着内率は0ではない（40%未満＝10頭に4頭は来る）
