# 結果：「市場の支持ほどAIは評価していない馬」は1着に来ないか

事前登録: `danger/CRITERIA_WIN.md`（`7717826`・測定前にコミット）
測定コード: `danger/winrate.py`（`85096ae`・**実行前にコミット**）
実行: 2026-10-16 ／ **測定は1回**
きっかけ: ユーザー指示「危険な人気馬は1着にきてはならないを測ってくれ」

## 🔴 結論：**不採用。1着でも「来ない」と書ける水準ではなかった**

本番の条件（V0 = 市場1番人気 かつ `solo_rank >= 6`）の **勝率 23.0%**。
カードが結果を見る前に宣言した合格線は
**1a「1着に来ない」= 10%未満 / 1b「勝ちきれない」= 16%未満**で、
**どちらも満たさない**。23.0% は「**4頭に1頭は勝つ**」水準である。

落ち幅そのものは本物（非該当1番人気 33.7% → 該当 23.0%・**−10.73pt**・
並べ替え P=0.0050）。3着内の測定（63.6% → 48.6%・−15.0pt）と同じ向き・同じ桁で
再現している。**足りないのは水準のほうで、これは3着内のときと同じ形。**

- 🔴 **`DANGER_MAX_POP=1` / `DANGER_MIN_SOLO=6` は1文字も変えていない。**
  「もっと絞れば書ける」を測定が支持していない（§2 で率そのものが通らない）

- 🔴 **同じ条件を定義・閾値・期間・結果変数を変えて測り直さない。**
  3着内（6条件）と1着（6条件）で**2つの結果変数を使い切った**

⚠ **1点だけ §7 から外れたことをしている。**
根拠文（`commentary.DANGER_BASIS`）に**勝率 23.0% を追記した**。
§7 は「変えない」と書いていたが、この追記は
**印を弱く見せる方向（4頭に1頭は勝つ、と読者に伝える）**であり、
結果を見て商品を良く見せる方向の書き換えではない。
ユーザーが「危険な人気馬の根拠は読者が一番欲しい情報」と明示しているため、

「良く見せる追記」をしない。**
