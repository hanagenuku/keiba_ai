## 🔴 「f_pace上位」の定義が2通りある（両方出す）

指示③→④を順番に読むと「10番人気以下の中での上位」、⑦を読むと「レース全体での上位」。
**どちらか一方を選ぶと結論が定義に依存する**ので、両方を並べて出す。

- **定義A**: レース全体の f_pace 上位k頭のうち、10番人気以下のもの
- **定義B**: そのレースの10番人気以下の馬の中での f_pace 上位k頭

## 🔴 先に置く対照群（これが無いと既に3回否定された話の焼き直しになる）

「10番人気以下 × AIが市場より上位」という切り口は**すでに否定されている**:
- 2026-08-03 / 08-31: AIが市場より強気なほど回収率が下がる（+6以上で41.4%）
- 2026-08-31: 不人気馬をAIが選んでも**市場人気で選ぶのと同じ**（72.9% vs 73.0%）

したがって今回の問いは「AI強気が効くか」ではなく
**「f_pace がそこに何かを足すか」**である。対照群は必ず併記する。

| 対照 | 何を潰すか |
|---|---|
| C0 | 10番人気以下 全体 |
| C1 | 10番人気以下 × AI>市場（**f_pace 条件なし**） ← f_pace の寄与を分離 |
| C2 | 10番人気以下 × f_pace上位（**AI条件なし**） ← AI条件の寄与を分離 |
| C3 | 10番人気以下 × AI>市場 × **f_pace下位**k頭 ← 符号が逆なら本物 |
| C4 | 同帯・同Nの無作為抽出（帯内シャッフル・200回） ← 偶然の幅を出す |

⚠ C4 は「偶然どれくらい振れるか」を出すためで、リーク検出には使えない（North Star #8）。

## 判定規則（⑧に対応・100%超を探さない）

**取り込み基準**（f_pace に情報があると言ってよい条件）:
1. 本命セルの **N ≥ 300**（探索期・確認期それぞれで）
2. 本命セル − C1（f_pace なし）の差が、**探索期と確認期で同符号**
3. その差が C4 の無作為分布の 5〜95%点の外にある（探索期・確認期とも）
4. C3（f_pace 下位）が逆符号

**採用基準**（買い方として使ってよい条件・North Star #9）:
5. 複勝ROI が確認期で **> 100%**
6. 上位3本の配当を抜いても > 100%
7. 日ブロック bootstrap の 95%CI 下限 > 100%

❌ 取り込み基準を満たさなければ、そこで打ち切って ⑩ には進まない。
✅ 取り込み基準（1〜4）を満たした場合のみ ⑩（XGB特徴量として投入）へ。
   ⚠ 採用基準（5〜7）は ⑩ とは別。⑩ は「精度が上がるか」で、買い方の話ではない。

## ⑩ の事前登録（進んだ場合のみ）

f_pace は**すでに134特徴量に入っている**（`f_pace` / `f_pace_fit` / `f_pace_x_style` ほか）。
したがって⑩は「新規追加」ではなく「**抜くと悪くなるか**」で測る。
- 腕: 本番134 / 134から展開系を抜いたもの / 134 + f_pace の交互作用列
- 基準: 3窓すべてで +0.002 以上（2026-08-27 は「展開系29列を全部抜いても −0.0001」）
