## 1. 仮説（主）

> 文書の順番待ちスコア S が高い馬は、複勝回収率が高い。

## 2. データ・母集団

- `data/history.db`（`horse_history` 166,403行 / `race_history` 12,131レース / 2023-01-07〜2026-09-27）
- 対象: `place>0` かつ `surface` が有効 かつ **その馬に過去走が1走以上ある**行
- 除外: 3着内なのに `fukusho_payout` が NULL/0 の行（629行）は**評価不能として除外**
  （2026-08-18③ の教訓: 0円として混ぜると実力を過小評価する方向に静かにずれる）
- **リーク防止**: S はそのレースより**前の日付**の走りだけから作る。
  同日の別レースも使わない。`place` / `agari3f` / 当該レースの結果は一切見ない

## 3. S の定義（文書の点数表そのまま・機械的に固定）

`prev` = 直前の1走 ／ `last3` = 直近3走（過去走のみ）
クラス順位 `新馬0 < 未勝利1 < 1勝2 < 2勝3 < 3勝4 < OP/オープン5`
小回り会場 = 中山・福島・小倉・函館・札幌

| 項目 | 点 | 機械的定義 |
|---|---:|---|
| 直近3走で3着以内2回以上 | +2 | `len(last3)>=2` かつ `sum(place<=3)>=2` |
| 同クラスで好走経験 | +2 | 同 `class_grade` の過去走が2走以上 かつ そのうち `place<=5` が1回以上 |
| 同距離で好走 | +1 | 同 `distance`（±0m）の過去走で `place<=3` が1回以上 |
| 同コースで好走 | +1 | 同 `(racecourse, surface, distance)` の過去走で `place<=3` が1回以上 |
| 前走が今回と近い条件 | +1 | `prev.surface == 今回` かつ `|prev.distance − 今回| <= 200` |
| 着順が安定 | +1 | `last3` が3走そろい、着順の母標準偏差 `<= 2.0` |
| 前走より条件好転 | +1 | `classrank(prev) > classrank(今回)`（降級） |
| 前走6着以下 | −2 | `prev.place >= 6` |
| 10週以上休養 | −2 | `今回date − prev.date >= 70日` |
| 小回りで後方脚質 | −1 | 今回が小回り会場 かつ `prev` の3角通過位置が下位30%（`corner_all` 1つ目 / `field_size`、`field_size` 欠損時は `race_history.num_finishers`、両方欠損なら項目不成立） |
| 大幅な条件悪化 | −2 | `classrank(prev) < classrank(今回)`（昇級） **または** `|prev.distance − 今回| >= 400` |

帯は文書の運用例そのまま: **`S<=3` / `4<=S<=6` / `S>=7`**。

## 4. 合格基準（すべて結果を見る前に確定）

### 中止条件（先に見る）
- **S 単独の複勝AUC < 0.50** → 向きが逆。以降の帯分析を採用根拠にせず**即中止**

### Primary
| # | 基準 | 合格線 |
|---|---|---|
| 1 | 単調性 | `S<=3` < `4-6` < `S>=7` の順に複勝回収率が増加 |
| 2 | 効果量 | `S>=7` 帯の複勝回収率 − 全馬 **>= +5.0pt** |
| 3 | N | `S>=7` 帯 **N>=2,000** |
| 4 | 市場比較ゲート | 市場人気3分位の**各分位内**で `S>=7` − `S<=3` の3着内率差が**全分位同符号**、かつ最小の分位でも **>= +2.0pt** |
| 5 | 頑健性 | 前半(2023-01〜2024-12)・後半(2025-01〜)の**両期間**で基準1・2が成立 |
| 6 | 採用（買える） | `S>=7` 帯の複勝回収率が **100%超** かつ 日ブロックbootstrap 2,000回の **95%CI下限 > 100%** |

- **基準1〜5 が通れば「第2段（レース選別）に進む価値がある」**
- **基準6 が通って初めて「そのまま買える」**
- 基準1〜5 のどれかが落ちたら**閉じる**。S の定義・閾値・期間を変えて測り直さない

### 標準ゲート（CLAUDE.md「そのほか 1.」）
- **市場単独 / S単独 / S×市場** の三者比較を必ず出す
- 方向別（S が市場より強気／一致／弱気）も出す。**S が強気な側で改善が出たらまず計測器を疑う**
  （2026-08-31 `corr(gap, 符号つき誤差) = -0.1213`）

### 対照群（North Star #11 の2つの形以外で書かない）
- **対照群A＝並べ替え分布**: レース内で S をシャッフル200回。
  合格は帰無が0中心 ＝ `|mean(Δ回収率)| < 2*std/sqrt(200)`。
  実測の Δ は並べ替え P で報告する。**1回の引きの大小比較は書かない**
- **対照群B＝注入の復元**: `S>=7` の馬だけ合成ラベルで3着内率を `p=+5.0pt` 押し上げ、
  計測器が帯差の変化として復元するか。合格は `注入後 − 注入前 = +5.0pt`（許容 0.2pt）

## 5. Secondary（符号の検査・採用判断には使わない）

11項目を1つずつ「その項目が成立した馬 vs しなかった馬」の複勝回収率で測り、
**文書の符号（+/−）と実測の符号が一致するか**を並べる。
⚠ これは11個の多重比較なので、**ここから新しい点数表を作らない**（結果を見てから
測定器を足さないこと。North Star #8）。

## 6. 落ちたときに書く文（先に決めておく）

> 文書の順番待ちスコアは、既存データで測った範囲では複勝回収率に
> 事前登録した大きさの効果を持たなかった。よってこれを推奨レース選別に使わない。
> ⚠ 「文書が間違っている」ではない。**この11項目の線形結合と閾値7/4では届かない**である。
