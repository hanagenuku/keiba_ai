```
テーブル   race_notes  (date, race_id, horse_num, notes_data JSON)
```

## Gate 0（30レース・3週末）— 実用性の確認だけ

Claudeが市場と違うことを言えるかは**測らない**。測るのは次の6点。

1. 発走前に情報を確定できるか
2. 取得時刻を保存できるか
3. 参照URLを保存できるか
4. 結果を見ずに記録できるか（**セッションを分ける**）
5. 🔑 **同じ情報を毎回同じ基準で分類できるか**
   → 同じ10レースを**別セッションで2回**判定し、一致率（Cohen's κ）を出す
6. 後から項目を追加・変更していないか（下記の凍結機構で担保）

## 🔴 採用の順序（ユーザー指示・2026-09-09 追記）

**探索期で有効に見えた項目を、そのまま「有効な情報」と確定しない。**

```
収集
 ↓ 探索期
「効いていそうなWeb情報」を選ぶ        ← ここは仮説の生成であって発見ではない
 ↓ 確認期
OOSで再現するか                       ← ここを通って初めて候補
 ↓
市場を超えるか（人気帯で統制した増分）
 ↓
最後に ROI
```

このプロジェクトは「AUCでは良さそう」「特定セルではROIが高い」「でもOOSでは消える」を
何度も経験している（2026-07-27 182.8%→71.3% / 08-15② 25マスで基準ゼロ /
08-29 in-sample 106.2%→walk-forward 77.5% / 08-24 F-4 条件別Δが r=−0.001）。

したがって記録する言い方は
- ❌「このWeb情報は統計的に効いた」
- ✅「**探索期で発見した情報が、確認期でも市場に対して追加情報を持っていた**」

ここまで到達して初めて**採用候補**とする。採用そのものはROIを見た後。

## 🔑 4項目のどれかが効くはず、と考えない（ユーザー指示）

```
追い切り評価 → 無効
追い切り短評 → 無効
陣営コメント → 無効
状態コメント → 無効
```

**これで全く構わない。** 目的はWeb情報をAIに追加することではなく、
**「市場が取り込めていないWeb情報が存在するか」を探すこと**。
全部無効なら「JRA公式無料データ＋一般Webの範囲に、市場が取りこぼしている
事前情報は無い」という結論が得られ、それは十分な成果。

逆に「追い切り評価そのものは無効だが、**特定の短評パターンだけ**市場に対して
情報を持つ」という結果が出るなら、それが今回の発見。

### 🔴 ただし「短評パターン」には無限の仮説生成の罠がある

生テキストを残して後からパターンを掘ると、**いくらでも仮説を作れる**。
2026-08-15②（25マス見れば偶然100%超が出る）と同じ構造。機構で塞ぐ:

| | |
|---|---|
| ① パターン抽出は**探索期のテキストだけ**を見て行う | 確認期のテキストは開かない |
| ② 抽出したパターン定義（正規表現・キーワード集合）を**確認期に入る前にファイルへ凍結**する | `webinfo/PATTERNS.json` + ハッシュ。FIELDS.json と同じ機構 |
| ③ 確認期では**凍結したパターンだけ**を当てる | 新しいパターンを思いついても足さない |
| ④ 探索期で試したパターンの**総数を必ず記録する** | 帰無分布の計算に要る（今日の地図と同じ） |

⚠ ②を破った瞬間に、この研究は「後付けで理由をつけた」ものになる。

## 評価方法（蓄積後・事前登録）

🔴 **単純な好走率ではなく、同程度の市場人気と比べた増分**で測る（ユーザー指示）。
これは今日のミスプライシング地図と同じ手法（`forecaster/mispricing.py`）。

```
対象     項目 F が値 v の馬
対照     同じ市場人気帯 × 同じ頭数帯 の全馬
測る量   実測3着内率 − 市場示唆3着内率        （＝人気で説明できない分）
```

| 段階 | 内容 |
|---|---|
| 探索期 | 蓄積の前半。ここ**だけ**を見て「効いていそうな項目」を選ぶ |
| 確認期 | 蓄積の後半。選んだ項目**だけ**を検定する |
| 帰無 | 乱数列で同じ計算をして、偶然出るスプレッドの分布を出す（今日は 95%点3.2pt・最大4.7pt） |
| 🔴 ROI | **最後**。着順で再現してから初めて見る |

⚠ 交互作用（例「距離延長＋前走不利」）を見る場合も、**探索期で決めて確認期で検定**する。
探索期を見ずに交互作用を後から思いつくのは禁止。
