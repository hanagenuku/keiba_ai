# L': 「実際に逃げた」を事前に予測できるか（2026-09-14）

ユーザーの指摘に対する測定。読み取りのみ・本番のモデル・DB・買い目には触れていない。

> ⚠ この +9〜+20pt は事前に使えません。これは「実際に逃げた馬」の残差で…
> 👈 **このようなところを事前に予測するのです。** スタートに不安はないか？
> ハナに立つスピードがあるか？他の馬と比べて先行力はあるか？
> この騎手は積極性があるから先行しそう？

**指摘は正しい。** 私の「事前に使えません」は言い過ぎだった。正しくは
「+15pt をそのまま取れるわけではない」で、その手前を予測するのが仕事。
そこで**予測そのものを作って**測った。

## Step 1 ✅ 先頭に立つ馬は当てられる（AUC 0.776）

159,800頭 / 11,634レース。学習 〜2025-06-30 / 検定 2025-07-01〜（50,342頭・3,814レース）。
特徴量はすべて**その馬の過去走のみ**（`shift().expanding()` で当該レースを除外）。

```
市場人気だけ            AUC 0.6148   ← 市場も部分的に知っている
枠・頭数・距離だけ         AUC 0.5962
過去の逃げ率だけ          AUC 0.7118
過去の通過位置           AUC 0.7409
騎手の逃げ率だけ          AUC 0.5683   ← 単独では弱い
全部                  AUC 0.7757
```
**提案は実行可能。** 先頭通過率 7.4% の事象を AUC 0.78 で当てられる。

## Step 2 🔴 予測できた「逃げやすさ」には市場残差が無い

市場残差 ＝ 実際の3着内 − 人気×頭数から期待される3着内（基準表は**学習期だけ**で作成）。

```
事後で切る（実際に逃げたか）
   実際に先頭   N= 3,702  複勝率41.2%  市場残差 +11.45pt
   それ以外    N=46,640  複勝率20.5%  市場残差  -0.94pt

事前で切る（予測した逃げやすさ・五分位）
   Q1低  実際に先頭 1.3%  複勝率12.1%  市場残差 -1.52pt
   Q2         2.8%      18.4%        +0.09pt
   Q3         4.2%      22.6%        +1.07pt
   Q4         8.1%      27.0%        +0.92pt
   Q5高      20.5%      30.3%        -0.72pt   ← 最も逃げそうな群がマイナス
```
**単調ですらなく、最大でも Q3 の +1.07pt。** 予測できる部分は市場が既に価格に入れている。

## Step 3 🔑 予測を揃えて割ると、残差は全部「実現」側にある

```
              逃げた                 逃げなかった            差
Q1低   N=  126 +12.68pt   N= 9,943 -1.70pt   +14.38pt
Q2    N=  277 +19.35pt   N= 9,791 -0.45pt   +19.80pt
Q3    N=  418 +15.48pt   N= 9,650 +0.44pt   +15.03pt
Q4    N=  817 +14.45pt   N= 9,251 -0.28pt   +14.73pt
Q5高   N=2,064  +8.31pt   N= 8,005 -3.04pt   +11.36pt
```
**どの予測帯でも、実際に逃げれば +11〜+20pt。** 残差は予測ではなく実現に乗っている。

## Step 4 🔴 買える単位で測ると期待値はマイナス

レース内で最も逃げそうと予測した1頭を買う（＝実際に運用できる形）:

```
N=3,814   的中(実際に先頭) 30.1%   複勝率30.8%   市場残差 -1.98pt
   → 実際に逃げた   N=1,148  複勝率42.1%  残差 +6.52pt
   → 逃げられなかった N=2,666  複勝率26.0%  残差 -5.64pt

期待値 = 0.301×(+6.52) + 0.699×(-5.64) = -1.98pt
損益分岐の的中率 = -b/(a-b) = 46.4%     （いま 30.1%）
```
🔑 **「逃げそうだったのに逃げられなかった」が効いている。** 市場はその馬を
先行力込みで買っているので、ハナを切れないと価格を下回る。

## 🔴🔴 Step 5 決定打: 予測が上手くなるほど取り分が減る

```
   Q1  実際に先頭  1.3%  →  逃げたときの残差 +12.68pt
   Q2          2.8%  →                +19.35pt
   Q3          4.2%  →                +15.48pt
   Q4          8.1%  →                +14.45pt
   Q5         20.5%  →                 +8.31pt

   corr(逃げやすさ, 逃げたときの残差) = -0.763
```
**価値は「意外な逃げ」に集中している。** 予測精度を上げると母集団が Q5 に寄り、
そこは取り分が最小（+8.31pt）。つまり**予測に成功するほど、成功の価値が消える**。

損益分岐 46.4% に届かせるには予測を 30%→46% に上げる必要があるが、
上げた先は取り分の小さい側なので、実際の損益分岐はもっと高い。

## 結論

**提案の各段は正しく、実行可能で、それでも通らない。**
① 予測できる（AUC 0.776）② しかし予測できる部分に残差が無い
③ 残差は実現側にしかない ④ 買うと −1.98pt ⑤ 予測を改善すると価値が縮む。

これは 2026-08-27 の「過去走から予測した位置取りでは AUC +0.0001」を、
**機序まで開いて再現した**もの。あのときは数字だけだったが、今回は
「なぜ 0 なのか」が見えている: **市場は公開データから予測できる分を価格に入れる。
残差は予測できない側に溜まる。**

⚠ 私が使わなかった角度: **馬ごとのテン（前半3F）は history.db に列が無い**
（レース単位の `first_3f` のみ・2025年以降93.8%）。ゲートの不安も列が無い。
これらを足せば AUC 0.776 は上がりうる。しかし Step 5 のとおり、
**上がった先は取り分が縮む側**なので、期待値の符号は変わりにくい。
